# EduAgent 演示 PPT 源材料摘要

## 项目定位

EduAgent 是一个以 LLM Wiki 为知识中枢、面向高等教育的个性化多 Agent 学习系统。项目不把大模型仅用于单轮问答，而是围绕学生画像、知识组织、资源生成、路径规划、练习反馈和 Agent 可观测形成完整学习闭环。

## 赛题契合

- 对话式学习画像：系统从自然语言中抽取专业、年级、学习目标、知识基础、认知风格、学习节奏、编程能力、每周学习时间等 8 个维度。
- 多智能体协同：后端使用 LangGraph 编排 Router、Profile、Planner、Doc、Quiz、Code、Media、Video、Tutor 等 Agent。
- 多模态资源生成：当前支持学习文档、结构化练习题、代码实践、思维导图、PPT 大纲/图片、动画分镜、拓展阅读和相关视频。
- 学习路径规划：基于课程知识图谱展开前置知识，结合画像和测验结果动态更新路径节点状态。
- 智能辅导：Tutor Agent 支持 Study Mode，以分步提示、理解检查和错误归因代替直接给答案。
- 学习效果评估：测验、错题、学习时长、路径进度和 Agent 运行事件进入分析仪表盘。
- 防幻觉和安全：LLM Wiki、RAG 检索、可信引用、低置信提示、讯飞安全护栏和本地规则共同约束输出。

## 已落地工程事实

- 前端：Next.js、React、TypeScript、Tailwind CSS；核心页面包含聊天、画像、资源中心、知识 Wiki、学习路径、学习分析和 Agent 可观测。
- 后端：FastAPI、SQLAlchemy、LangGraph、PostgreSQL/SQLite、Redis、MinIO 适配、本地资产存储。
- LLM：讯飞星火为主，DeepSeek 或 OpenAI 兼容客户端作为可配置补充，开发模式可回退模拟内容。
- 知识库：内置《人工智能导论》和《计算机网络》两门课程模板，支持课程资料上传、解析、切分、向量化、检索和图谱查询。
- 资源可信引用：Agent 生成资源携带 sources、confidence、来源片段和跳转 Wiki 的核对入口。
- 多模态导出：PPTX 导出、动画 HTML/字幕/可选旁白包、讯飞 TTS 资源朗读。
- 自动评测：`backend/tests/evals` 覆盖画像抽取、路由、RAG 命中、题目结构和内容安全，离线可运行。

## 典型演示链路

1. 学生用自然语言说明基础和目标。
2. Router 识别意图，Profile 提出画像候选变更，学生确认后写入。
3. Planner 拆解资源生成任务。
4. Doc、Quiz、Code、Media、Video、Tutor 等 Agent 并行或分层生成资源。
5. LLM Wiki 提供知识检索、前置知识、关联知识和可信来源。
6. 学生作答测验后，错题进入复习队列。
7. 学习路径根据目标、图谱和结果推进。
8. 分析页展示个人学习效果、资源沉淀和 Agent 运行链路。

## PPT 叙事主线

EduAgent 的创新点是把高等教育中的「资源搜索」与「单轮问答」升级成「可沉淀、可评估、可协同的智能学习中枢」。它通过 LLM Wiki 固定知识边界，通过多 Agent 拆解学习任务，通过动态画像驱动个性化，通过多模态资源和学习闭环提升学习效果。
