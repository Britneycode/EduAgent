# 05 · AI 工具与开源合规说明

## 一、AI 辅助工具选型

| 用途 | 工具/服务 | 说明 |
| --- | --- | --- |
| 主体 LLM（多 Agent 生成/路由/答疑） | 讯飞星火（Spark LLM） | 主模型，OpenAI 兼容 Chat Completions 接入 |
| 备用 LLM | DeepSeek | 主模型失败自动切换 |
| 兼容 LLM | 阿里云百炼（DashScope，qwen 系列） | 可选 OpenAI 兼容接入 |
| 语音识别 / 图片生成 | 讯飞 / 阿里云百炼（DashScope） | 资源朗读与 PPT 配图（可选） |
| 内容安全 | 讯飞内容审核 | 输入/输出护栏（凭证缺失时回退本地规则） |
| 相关视频搜索 | Tavily（限定 B 站域名） | 可选：VideoAgent 联网搜教学视频 |
| 智能体运行平台 | remio 睿妙 | 本赛道指定平台，承载 aApp/skill 语义端点 |
| 跨产品调用 | MCP（自研 `app/mcp_server.py`） | 标准库实现，零新增依赖 |

> 说明：作品在 remio 上运行时，语义理解/生成走 remio 平台能力（`run_prompt`/`rag`）；
> MCP 引擎侧沿用讯飞星火 + DeepSeek 双模型，二者为互补关系，不是替代关系。

## 三、开源合规声明

1. 本项目遵守上述各组件的开源许可证要求：保留版权声明、MIT/BSD-3-Clause 组件需随分发
   附带许可证文本；Apache-2.0 组件需注明修改并保留 NOTICE。
2. 未对任何开源组件进行源码级篡改或去除版权标识；所有依赖通过官方包管理器（uv/pnpm）锁定版本。
3. 自研代码（多 Agent 编排、RAG 混合检索、MCP 适配器、前端界面）为本团队原创，
   不含未声明开源的第三方代码。
4. LLM 生成内容均经 RAG 知识锚定并标注来源，不构成对第三方教材/论文的复制分发；
   演示数据为自建知识库。
