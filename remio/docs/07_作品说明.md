## 二、一句话定位

> 面向高校学生的**个性化多智能体学习助手**：先理解「你是谁、哪里薄弱、要学什么」，
> 再从结构化课程知识库中检索**可追溯**的知识，由 10 个分工明确的 Agent 协同产出
> 讲义、题目、代码、思维导图、PPT、拓展阅读、动画脚本，并对疑问做苏格拉底式引导答疑。

## 三、解决什么问题

高校课程学习中，「千人一面」是核心痛点：同一个知识点，不同基础、不同目标的学生，
拿到的却是同一份讲义、同一套题。单一问答式 AI 只能「答一题」，无法完成
**「画像 → 规划 → 多模态产出 → 答疑」**的闭环。

本作品用**多智能体融合**解决：不是让一个模型包办一切，而是 10 个分工明确的 Agent
各司其职、协同编排，围绕学生**个体画像**生成**个性化、多模态**的学习资源——
让学生用一句自然语言启动学习，三步内获得贴合自身基础、目标与时间投入的学习路径与资源。

## 四、核心功能

### 4.1 多智能体协同（10 个 Agent）

| Agent | 职责 | 端点 |
| --- | --- | --- |
| Router | 意图识别，路由到正确链路 | `route_intent`（E1） |
| Profile | 对话式构建 8 维学生画像 | `build_profile`（E2） |
| Planner | 复合任务分解，规划资源组合 | `plan_learning`（E3） |
| Doc | 基于 RAG 生成个性化讲义 | `generate_document`（E4） |
| Quiz | 生成多类型题并判题沉淀弱点 | `generate_quiz` / `grade_quiz`（E5） |
| Code | 生成可运行 Python 实操案例 | `generate_code`（E6） |
| Media | 思维导图 / PPT 大纲 / 配图 / 动画脚本 | `generate_mindmap` / `generate_ppt`（E7/E8） |
| Reading | 拓展阅读推荐（联网核实优先） | `generate_reading`（E9） |
| Tutor | 苏格拉底式答疑（三级兜底） | `tutor_answer`（E10） |
| SessionMaterial | 挂载学生自己的学习材料 | `attach_material`（E11） |

**编排规则**：Router 先行 → Profile 串行优先（其余依赖画像）→ Doc/Quiz/Code/Media 并行生成。

**8 维画像**：专业、年级、知识基础、学习目标、编程水平、认知风格、可投入时长、偏好资源类型。

**18 个端点**：11 个核心语义端点（E1–E11）+ 判题 / PPT 配图 / 薄弱点复习 / 动画分镜 / B 站视频 5 个扩展端点，连同主入口与内容事件订阅，与平台侧 `api.json` 对齐。

### 4.2 知识锚定与三级防幻觉兜底

生成内容以课程知识库为**事实边界**，三道防线：① 检索锚定（只依据命中片段生成）；
② 来源强制（`[来源：章节>小节]` 可回溯）；③ 不足显式化（证据不足时标注缺口，不编造）。

当课程知识库未命中时，按**三级兜底**逐级降级并显式告知来源，禁止静默切换：

1. **📚 课程知识库** —— `search_notes` 检索《计算机网络》课程资料，注入正文生成；
2. **📎 会话材料** —— 学生通过 E11 上传的笔记/课件作为兜底源；
3. **🌐 网络** —— 前两级均未命中才联网（仅引用实际抓取过的页面）。

锚定型端点用 `run_prompt(capabilities="none")` **物理禁止联网**，确保模型只能依据注入的知识作答。

### 4.3 多模态资源产出（7 类）

讲义、练习题、代码案例、思维导图、PPT 大纲、拓展阅读、动画分镜脚本，一次学习请求可并行产出多种资源。

### 4.4 学习资产沉淀与自动化

- 画像与错题弱点持久化到 remio 笔记《EduAgent 学生画像》，判题后自动回写；
- **订阅自动化**：画像 note 变化时，自动推送薄弱点自测题（`POST /_event` + `send_chat_message`）；
- 每日复习自测入口，一键回顾最近答错的知识点。

## 五、技术架构

```
学生输入 → 意图路由 → 画像理解 → 知识检索 → 多 Agent 协作 → 个性化资源 → 测验反馈 → 画像/路径更新
```

| 层 | 组成 | 说明 |
| --- | --- | --- |
| 交互层 | remio aApp 对话 + UI 组件 | 对话为主、卡片/选择/输入为辅 |
| 编排层 | Router / Profile / Planner 等 10 Agent | 串并行调度，形成学习闭环 |
| 知识层 | 课程知识库 + 混合检索 | 章节关联、来源引用、课程切换（多课程经 MCP 形态，`list_courses` 可列出） |
| 生成层 | `run_prompt` + 检索上下文注入 | 产出多类资源并回写弱点 |
| 跨产品层 | MCP 工具集（14 工具） | 知识检索与生成能力供其他智能体宿主调用 |

## 六、创新点

1. **画像贯穿的生成闭环** —— 画像不是一次性表单，而是驱动规划、讲义、练习、答疑的上下文，并在判题后持续更新。
2. **三级防幻觉兜底的工程落地** —— 课程库 → 会话材料 → 网络逐级降级、显式标注，含 remio 平台 `rag` 对 File 笔记失效时 `search_notes → read_note` 的可靠兜底链路。
3. **多智能体模块化协同** —— 教学任务拆分为职责明确的 Agent，可独立扩展与组合。
4. **双形态交付与跨产品复用** —— remio 原生 aApp 与 MCP 工具集共用同一引擎。

## 七、使用与演示

**一句话触发**：`我是计算机大一学生，基础一般，帮我复习 TCP 三次握手`

系统依次完成：建立/更新画像 → 检索课程资料 → 给出学习规划 → 生成讲义与练习 → 判题并记录薄弱点 → 苏格拉底式答疑。

**三种体验方式**：

- remio 内打开 aApp `eduagent-pro`（市场搜索「EduAgent」安装）；
- 跨产品调用：注册 MCP 后调 `route_intent` / `generate_quiz` / `list_courses`。
