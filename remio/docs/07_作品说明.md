# 作品说明 · EduAgent 个性化学习智能体

> 面向「2026 智能体 OPC · 金漪湖论剑 · 智能体融合创新赛道」

## 一、解决的问题

高校学习长期「千人一面」：同一个知识点，不同基础、不同目标的学生拿到同一份讲义、同一套题。单一问答 AI 只能「答一题」，无法完成「画像 → 规划 → 多模态产出 → 答疑」闭环，也缺可追溯来源、易幻觉。

## 二、核心功能

- **10 个协同 Agent**：Router 路由 → Profile 构建 8 维画像 → Planner 拆解，Doc/Quiz/Code/Media/Reading/Video 并行产出 7 类资源（讲义/题/代码/导图/PPT/拓展阅读/动画），Tutor 苏格拉底式答疑。
- **LLM Wiki 知识中枢**：内置《计算机网络》《算法设计与分析》两门课程，向量 + BM25 混合检索，多课程自动切换。
- **三级防幻觉兜底**：课程知识库 → 会话材料 → 网络逐级降级、显式标注来源，锚定端点物理禁网，保证可追溯。
- **学习闭环**：判题回写薄弱点，订阅自动化推送自测题，画像持续更新。

## 三、运行方式

双形态共用同一引擎：主力 remio 原生 aApp（已上架市场 id `eduagent-pro`，18 端点），一句自然语言即可触发全链路，如「我是计算机大一学生，帮我复习 TCP 三次握手」；另提供 MCP 工具集（14 工具，stdio 零依赖）供任何宿主跨产品调用。引擎为 Python 3.12 + LangGraph，`cd backend && uv sync` 安装，`pytest` 测试，`--self-test` 自检。

## 四、当前完成度

引擎与 MCP 已实现并自检通过；aApp 已上架市场，主路径（画像 → 规划 → 生成 → 答疑）可实测闭环；两门课程知识库与方案、演示、PPT、合规、评测文档就绪。剩余为录制演示视频、用户试用采集、评测在线指标补跑等环境 / 人工环节。
