# 02 · Demo 演示脚本（逐屏动线）

> 目标：3–5 分钟内走完"痛点 → 画像 → 路由 → 多 Agent 生成 → 答疑"全闭环，让评委
> 一眼看懂"多智能体协同 + 个性化 + 防幻觉"。

## 屏 0 · 开场（10 秒）

- 画面：作品名「EduAgent 个性化学习智能体」+「智能体融合创新赛道」。
- 口播：高校学习"千人一面"，一台问答 AI 完不成"画像→规划→多模态产出→答疑"闭环。
  我做的是 10 个 Agent 协同的个性化学习智能体。

## 屏 1 · 画像构建（30 秒）

- 输入："我是计算机专业大一学生，基础一般，目标是期末不挂科，想复习 TCP 三次握手"
- 系统：E1 路由识别到"建档 + 生成资料"；E2 弹出**画像确认卡**（专业/年级/基础/目标 4 项已更新）。
- 口播：Profile Agent 串行先行，因为它产出其余 Agent 都要依赖的画像。

## 屏 2 · 资源规划（20 秒）

- 系统：E3 列出「本轮学习计划」list：讲义 / 练习题 / 代码案例 / 思维导图 / 拓展阅读。
- 口播：Planner 把"复习 TCP 三次握手"拆成并行可执行的任务。

## 屏 3 · 多 Agent 并行生成（60 秒，这是重点）

- 依次/并列展示：
  - E4 讲义卡片（章节结构 + 文末 `[来源：运输层 > TCP连接管理]`）
  - E5 选择题（choice 组件，选错给解析）
  - E6 代码卡片（socket 建立连接示例 + 复制按钮）
  - E7 思维导图（三次握手状态流转）
  - E9 拓展阅读 list
- 口播：文档、题目、代码、导图**并行生成**；所有内容都来自知识库检索，带来源引用——这是防幻觉。

## 屏 4 · 苏格拉底式答疑（30 秒）

- 输入："为什么是三次握手而不是两次？"
- 系统：E10 答疑卡片（subtitle 标注 📚 课程知识库）以引导式反问 + 分步提示作答，末尾附来源行；
  再追问一个知识库没有的问题，展示降级到 📎 会话材料 / 🌐 网络并显式告知来源切换。
- 口播：Tutor 不是直接报答案，而是引导式答疑，知识仍然锚定在知识库上。

## 屏 5 · 自动化 + 跨产品（30 秒）

- 展示订阅：画像 note 更新 → POST /_event 自动推送薄弱点自测题（send_chat_message）；
  聊天菜单「🔁 每日复习自测」一键回顾。
- 展示 MCP：在另一个智能体客户端注册 `eduagent` MCP 工具集，调用 `generate_quiz`。
- 口播：同一个引擎还能以 MCP 形式在其它智能体产品里被调用。

## 屏 6 · 收束（10 秒）

- 回到"10 Agent 一张图"：Router → Profile → Planner → {Doc, Quiz, Code, Media, Reading, Tutor}。
- 口播：一句话收束——多 Agent 不是炫技，是让"个性化学习"真正变成一个可交付的闭环。
