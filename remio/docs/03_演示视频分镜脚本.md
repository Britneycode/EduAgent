## 拍摄提示

1. 实机部分用干净窗口（隐藏无关标签页），放大关键 UI 组件。
2. 涉及流式输出处，录屏 + 适当 1.2~1.5 倍速，保证节奏。
3. 旁白与字幕用中文；字幕与《02_Demo演示脚本》口播保持同义但不逐字照读。
4. 片尾标注：作品名、赛道、团队名、开源协议声明（见 `05` 文档）。
