# 题库覆盖统计

## 1. 用途
本页使用 Dataview 插件统计题库文档的类型分布、章节覆盖和相关知识点映射。

## 2. 全部题库文档

```dataview
TABLE topic AS "主题", summary AS "说明", status AS "状态"
FROM "计算机网络知识库/09_习题与解析"
SORT file.name ASC
```

## 3. 代码案例

```dataview
TABLE summary AS "说明", status AS "状态"
FROM "计算机网络知识库/10_代码案例"
SORT file.name ASC
```

## 4. 实验文档

```dataview
TABLE summary AS "说明", owner_agent AS "负责人"
FROM "计算机网络知识库/08_实验与工具"
SORT file.name ASC
```

## 5. 媒体资源

```dataview
TABLE doc_type AS "类型", summary AS "说明"
FROM "计算机网络知识库/11_媒体资源"
SORT file.name ASC
```
