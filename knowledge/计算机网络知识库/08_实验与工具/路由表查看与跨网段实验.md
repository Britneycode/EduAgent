# 路由表查看与跨网段实验

## 1. 实验目标
通过查看主机与路由器的路由表，理解路由表结构、默认网关与最长前缀匹配，并验证跨网段通信依赖三层转发。

## 2. 操作步骤
1. 查看本机路由表：Windows `route print`；Linux/macOS `ip route` 或 `netstat -rn`。
2. 识别默认路由（`0.0.0.0/0`）、直连路由与网关地址。
3. 在两端主机上执行 `ping` 与 `traceroute`（Windows `tracert`）验证跨网段路径。
4. 若可访问路由器管理接口，查看其路由表（如 `show ip route`），观察直连与静态/动态路由条目。
5. 记录每一跳的延迟与地址，对照拓扑验证路径。

## 3. 观察要点
- 跨网段通信时，报文先交给默认网关，由路由器逐跳转发。
- 最长前缀匹配决定目的网络选择哪条路由。
- traceroute 输出显示每一跳路由器地址，可验证转发路径。

## 4. 验收标准
- 能读出路由表核心字段（目的网络、掩码、网关/下一跳）。
- 能解释默认网关在跨网段通信中的作用。
- 能引用至少一个相关文档或事实卡。
