# 基础选择题

## 题集定位
围绕计算机网络核心概念设计的选择题，覆盖分层体系、IP 协议、TCP/UDP、DNS、HTTP 和网络安全。

## 1. 分层体系结构

### 题目 1
下列哪一层负责端到端的可靠数据传输？
A. 物理层  B. 数据链路层  C. 网络层  D. 运输层

**答案：D**
**解析：** 运输层（如 TCP）提供端到端通信服务。数据链路层只负责相邻节点间的帧传输。见 [[计算机网络知识库/01_基础理论/分层体系结构]]。

### 题目 2
在 OSI 模型中，负责数据加密和压缩的是哪一层？
A. 表示层  B. 会话层  C. 应用层  D. 运输层

**答案：A**
**解析：** OSI 七层模型中表示层负责数据表示、加密和压缩。TCP/IP 模型中这些功能通常由应用层处理。见 [[计算机网络知识库/01_基础理论/分层体系结构]]。

## 2. 网络层

### 题目 3
IP 地址 192.168.1.130/26 所在子网的网络地址是？
A. 192.168.1.0  B. 192.168.1.64  C. 192.168.1.128  D. 192.168.1.192

**答案：C**
**解析：** /26 表示前 26 位为网络前缀，每个子网 64 个地址。130 在 128-191 范围内，网络地址为 192.168.1.128。见 [[计算机网络知识库/04_网络层/子网划分]] 和 [[计算机网络知识库/99_附录/事实卡/子网划分]]。

### 题目 4
CIDR 记法 10.0.0.0/8 表示的地址块包含多少个 IP 地址？
A. 256  B. 65536  C. 16777216  D. 4294967296

**答案：C**
**解析：** /8 表示主机位 32-8=24 位，共 2^24=16,777,216 个地址。见 [[计算机网络知识库/04_网络层/CIDR与地址聚合]] 和 [[计算机网络知识库/99_附录/事实卡/CIDR]]。

### 题目 5
路由器转发 IP 数据报时，通常需要修改哪个字段？
A. 源 IP 地址  B. 目的 IP 地址  C. TTL  D. 协议字段

**答案：C**
**解析：** 路由器每转发一次通常将 TTL 减 1。源/目的 IP 地址保持不变（NAT 除外）。见 [[计算机网络知识库/04_网络层/IP协议]]。

## 3. 运输层

### 题目 6
TCP 使用什么机制实现流量控制？
A. 拥塞窗口  B. 滑动窗口和接收窗口  C. 慢开始  D. 停等协议

**答案：B**
**解析：** TCP 使用滑动窗口机制，接收方通过通告接收窗口（rwnd）控制发送方速率。拥塞窗口属于拥塞控制。见 [[计算机网络知识库/05_运输层/流量控制与拥塞控制]]。

### 题目 7
TCP 三次握手的主要目的是？
A. 验证服务器身份  B. 协商加密算法  C. 同步双方初始序号  D. 分配端口号

**答案：C**
**解析：** 三次握手的核心目的是同步双方的初始序号并确认双向通信能力。见 [[计算机网络知识库/05_运输层/TCP连接管理]] 和 [[计算机网络知识库/99_附录/事实卡/TCP三次握手]]。

### 题目 8
以下哪种应用最可能使用 UDP 而非 TCP？
A. 文件传输  B. 电子邮件  C. 实时视频通话  D. 网页浏览

**答案：C**
**解析：** 实时视频通话对延迟敏感，容忍少量丢包，适合 UDP。文件传输、邮件和网页浏览需要可靠性，通常使用 TCP。见 [[计算机网络知识库/05_运输层/UDP]] 和 [[计算机网络知识库/99_附录/事实卡/TCP与UDP区别]]。

## 4. 应用层

### 题目 9
DNS 递归解析器在解析域名时，首次查询的对象通常是？
A. 根域名服务器  B. 顶级域服务器  C. 权威域名服务器  D. 本地缓存

**答案：D**
**解析：** 递归解析器首先检查本地缓存，缓存未命中才逐级查询。见 [[计算机网络知识库/06_应用层/DNS]] 和 [[计算机网络知识库/99_附录/事实卡/DNS解析过程]]。

### 题目 10
HTTP 状态码 301 表示？
A. 请求成功  B. 永久重定向  C. 临时重定向  D. 服务器错误

**答案：B**
**解析：** 301 表示永久重定向，302 表示临时重定向，200 表示成功，500 表示服务器错误。见 [[计算机网络知识库/06_应用层/HTTP_HTTPS]]。

## 5. 网络安全

### 题目 11
HTTPS 中的 "S" 主要依赖哪个协议提供安全？
A. SSH  B. TLS  C. IPsec  D. SNMP

**答案：B**
**解析：** HTTPS = HTTP over TLS，TLS 提供加密、完整性保护和身份认证。见 [[计算机网络知识库/07_网络安全与无线网络/TLS_SSL]] 和 [[计算机网络知识库/99_附录/事实卡/HTTP与HTTPS]]。

### 题目 12
防火墙工作在 OSI 模型网络层和传输层时，主要依据什么信息做决策？
A. 应用层内容  B. IP 地址和端口号  C. MAC 地址  D. 用户身份

**答案：B**
**解析：** 包过滤和状态检测防火墙主要基于 IP 地址、端口号和协议类型做决策。见 [[计算机网络知识库/07_网络安全与无线网络/防火墙]]。
