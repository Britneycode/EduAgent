# 章节简答题

## 题集定位
按章节组织的简答题，用于检验学生对协议机制、层次关系和设计原理的理解。

## 1. 分层体系结构
**题目：** 简述分层体系结构的优缺点，并说明为什么互联网采用分层设计。
**参考要点：** 优点包括模块化、可替换性、易于标准化和故障定位；缺点包括跨层优化困难和封装开销。互联网分层使得不同厂商和组织可以独立开发各层协议。见 [[计算机网络知识库/01_基础理论/分层体系结构]]。

## 2. 数据链路层
**题目：** 描述以太网交换机收到一个帧后的处理过程。
**参考要点：** 记录源 MAC 和入端口对应关系；查表找目的 MAC；已知则转发到对应端口，未知或广播则泛洪。见 [[计算机网络知识库/03_数据链路层/MAC地址与交换机]] 和 [[计算机网络知识库/99_附录/事实卡/交换机转发]]。

## 3. 网络层
**题目：** 解释子网划分的目的，并说明如何计算一个子网的网络地址、广播地址和可用主机范围。
**参考要点：** 子网划分延长网络前缀，把大地址块分为多个逻辑子网。网络地址 = IP AND 掩码；广播地址主机位全 1；可用主机数通常 = 2^h - 2。见 [[计算机网络知识库/04_网络层/子网划分]] 和 [[计算机网络知识库/99_附录/事实卡/子网划分]]。

## 4. 运输层
**题目：** 比较 TCP 与 UDP 的特点，并各举一个典型应用场景。
**参考要点：** TCP 面向连接、可靠、字节流，适合文件传输、网页浏览；UDP 无连接、低开销，适合 DNS 查询、实时音视频。见 [[计算机网络知识库/05_运输层/TCP]] 和 [[计算机网络知识库/05_运输层/UDP]]。

## 5. 运输层（进阶）
**题目：** 说明 TCP 流量控制与拥塞控制的区别。
**参考要点：** 流量控制通过接收窗口防止压垮接收方；拥塞控制通过拥塞窗口防止网络过载。前者看接收端能力，后者看网络路径容量。见 [[计算机网络知识库/05_运输层/流量控制与拥塞控制]]。

## 6. 应用层
**题目：** 描述 DNS 域名解析的典型过程。
**参考要点：** 客户端请求递归解析器；递归解析器先查缓存；未命中则依次查询根、顶级域和权威服务器；结果缓存并返回。见 [[计算机网络知识库/06_应用层/DNS]] 和 [[计算机网络知识库/99_附录/事实卡/DNS解析过程]]。

## 7. 网络安全
**题目：** 简述 TLS 握手的基本过程和目的。
**参考要点：** 客户端发送 ClientHello（支持的密码套件和随机数）；服务器回复 ServerHello（选定套件、证书和随机数）；双方协商密钥；后续使用对称加密传输数据。目的是协商加密参数、验证服务器身份和生成会话密钥。见 [[计算机网络知识库/07_网络安全与无线网络/TLS_SSL]]。
