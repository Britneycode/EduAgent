# 数字证书

## 标准表述
数字证书由证书颁发机构（CA）签发，将公钥与域名绑定，包含域名、公钥、有效期、颁发者和数字签名。浏览器通过验证签名链确认服务器身份。

## 适用场景
讲解 HTTPS 握手、证书错误排查和安全选择题。

## 常见误解
误以为证书本身提供加密；证书只绑定身份，加密由 TLS 密钥协商完成。误以为自签名证书一定不安全（内网环境可用但不受公共信任）。

## 可验证依据
- - RFC 5280 - Internet X.509 Public Key Infrastructure Certificate and CRL Profile，定义 X.509 证书格式。
- RFC 6960 - X.509 Internet Public Key Infrastructure Online Certificate Status Protocol (OCSP)。
- 谢希仁《计算机网络》（第8版）第7.4节。
- 当前状态：`verified: true`（证书格式与 RFC 5280 一致）。
