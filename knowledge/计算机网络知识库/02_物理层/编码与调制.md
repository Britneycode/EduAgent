# 编码与调制

## 2. 核心概念

编码与调制是物理层把待传输数据变成适合在信道上传送的信号的两类手段。**编码**是数字信号到数字信号的变换（适用于基带传输），**调制**是数字信号到模拟信号的变换（适用于频带传输），**解调**则是调制的逆过程，从已调载波中恢复出数字信号。

## 3. 知识讲解

### 编码与调制的区别

- **基带传输**：不搬移信号频谱，把数字信号直接送到信道上（如以太网双绞线），用**编码**解决同步与直流分量问题；
- **频带传输**：把数字信号加载到高频模拟载波上传送（如无线、光纤的部分场景），用**调制**把数字信息映射到载波的幅度、频率或相位上。

这是学生最容易混淆的地方：编码是"数字→数字"，调制是"数字→模拟"，二者作用层次不同。

### 常见数字编码

- **NRZ（不归零编码）**：高电平表示 1、低电平表示 0，实现简单；缺点是连续多个 0 或 1 时没有电平跳变，接收方难以提取时钟同步，且存在直流分量。
- **NRZI（不归零反转编码）**：遇到 1 电平翻转、遇到 0 保持，减少直流分量，但仍可能出现长串无跳变。
- **曼彻斯特编码**：每个码元正中间都发生一次电平跳变，用跳变方向表示 0/1，自带时钟同步；代价是效率只有 50%（波特率是比特率的 2 倍），10BASE-T 即采用此编码。
- **差分曼彻斯特**：以码元边界是否跳变区分 0/1，抗干扰更好。
- **4B/5B 编码**：每 4 位数据映射为 5 位码元，保证足够多的跳变，效率提升到 80%，用于 100BASE-TX；更现代的标准还有 8B/10B、64B/66B。

### 常见调制方式

- **ASK（幅移键控）**：用载波幅度表示数据，1 与 0 对应不同幅度，抗干扰弱；
- **FSK（频移键控）**：用两个不同频率表示 0/1，实现简单，抗干扰优于 ASK；
- **PSK（相移键控）**：用载波相位表示数据，如 BPSK 用 0° 与 180° 表示 0/1；
- **QAM（正交幅度调制）**：同时改变载波的幅度与相位，用星座图上的点表示多个比特，如 16-QAM 每个符号携带 4 位，频谱效率高，但要求信道质量好。

## 4. 关键事实

- 曼彻斯特编码效率 50%，用于 10BASE-T；4B/5B 效率 80%，用于 100BASE-TX；
- 波特率是信号每秒变化的次数，比特率是每秒传输的比特数，在多进制调制中一个码元可携带多位，故比特率 = 波特率 × 每码元比特数；
- 调制的基本目标是把基带信号搬移到适合信道传输的频率，并提高频谱利用率。

## 5. 易混淆点

- **编码 vs 调制**：编码是数字→数字（基带），调制是数字→模拟（频带）。问"曼彻斯特编码是调制吗"——不是，是编码。
- **波特率 vs 比特率**：波特率是码元（信号）速率，比特率是数据速率；只有在二进制调制时二者数值才相等。
- **同步与直流**：曼彻斯特编码牺牲一半效率换来自同步，这是理解"为什么不用简单的 NRZ"的关键。

## 6. 例题与解析

**例题：** 什么是调制和解调？为什么无线信道需要调制？
**解析：** 调制是把数字基带信号加载到高频载波上（改变载波的幅度、频率或相位），解调是逆过程。无线信道直接传低频基带信号效率低、天线尺寸大且易受干扰，因此需要把信号搬移到高频频段再传输，这就是调制存在的意义。
