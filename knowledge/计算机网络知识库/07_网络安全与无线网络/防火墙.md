# 防火墙

## 1. 学习目标
- 理解防火墙的基本定义、作用范围和所在层次。
- 能够解释防火墙的关键机制和典型应用场景。
- 能够识别防火墙相关的常见误解。

## 2. 核心概念
防火墙是部署在网络边界的安全设备或软件，根据预定义规则控制进出流量。常见类型包括包过滤防火墙、状态检测防火墙、应用网关（代理防火墙）和下一代防火墙。

## 3. 知识讲解
包过滤防火墙基于 IP 地址、端口号和协议类型等网络层/传输层字段做出允许或拒绝决策。状态检测防火墙在此基础上跟踪连接状态（如 TCP 握手），可以区分合法响应包和伪造包。应用网关工作在应用层，可以检查应用协议内容并提供更细粒度控制，但性能开销更大。

## 4. 关键事实
- 包过滤防火墙速度快但无法检测应用层攻击。
- 状态检测防火墙能跟踪 TCP 连接状态，防止 SYN 洪泛等攻击。
- DMZ（非军事区）是防火墙保护下的半信任区域，常放置对外服务。

## 5. 易混淆点
- 防火墙不能防御所有攻击，如加密通道内的恶意流量、社会工程攻击和内部威胁。
- "端口关闭"不等于"安全"，应用漏洞可能通过开放端口被利用。


## 导师 Agent 教学提示
- 学生常见困惑：以为防火墙能防所有攻击。
- 诊断建议：问"防火墙能检测 HTTPS 加密流量中的恶意内容吗？"
- 个性化策略：防火墙像"小区门卫"——能查证件（IP/端口），但看不透加密包裹（加密流量）里的东西。

## 6. 例题与解析
**例题：** 比较包过滤防火墙和状态检测防火墙的工作原理和适用场景。
