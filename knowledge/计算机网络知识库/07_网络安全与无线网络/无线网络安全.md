# 无线网络安全

## 1. 学习目标
- 理解无线网络安全的基本定义、作用范围和所在层次。
- 能够解释无线网络安全的关键机制和典型应用场景。
- 能够识别无线网络安全相关的常见误解。

## 2. 核心概念
无线网络安全经历了 WEP → WPA → WPA2 → WPA3 的演进。WEP 使用 RC4 加密但存在严重漏洞，已被淘汰。WPA 作为过渡方案引入 TKIP。WPA2 使用 AES-CCMP 提供强加密。WPA3 进一步增强，引入 SAE（等效同时认证）替代 PSK 的四次握手。

## 3. 知识讲解
WPA2-PSK（个人模式）使用预共享密钥和四次握手生成会话密钥；WPA2-Enterprise（企业模式）使用 802.1X 和 RADIUS 服务器进行用户级认证。WPA3 引入了前向保密（即使密码泄露，过去的通信仍受保护）和更强的暴力破解防护。

## 4. 关键事实
- WEP 已完全不安全，不应在任何场景使用。
- WPA2-PSK 的安全性取决于密码强度和四次握手过程的完整性。
- WPA3-SAE 防止离线字典攻击，是家庭网络的推荐方案。

## 5. 易混淆点
- "设置了密码就安全"是常见误解；弱密码、WPS 漏洞和管理帧未加密都可能导致安全问题。
- 无线加密只保护无线链路段，有线侧和应用层安全需要额外措施。


## 导师 Agent 教学提示
- 学生常见困惑：以为设了 WiFi 密码就安全了。
- 诊断建议：问"WEP 为什么被淘汰？WPA2 的四次握手有什么作用？"
- 个性化策略：WiFi 密码像"门锁"——WEP 是弹簧锁（容易撬），WPA2 是防盗锁，WPA3 是智能锁（防暴力破解）。

## 6. 例题与解析
**例题：** 比较 WPA2-PSK 与 WPA2-Enterprise 的适用场景和安全机制差异。
