# 路由算法与协议

## 1. 学习目标
- 理解路由与转发的区别，掌握路由表的基本作用。
- 区分距离向量算法与链路状态算法的核心思想。
- 了解 RIP、OSPF、BGP 的适用范围与主要机制。
- 能够分析简单网络中的路由选择与环路问题。

## 2. 核心概念
路由算法解决"数据包从源到目的走哪条路径"的问题，由路由器基于路由表执行。路由表可由静态配置或动态路由协议维护。

## 3. 知识讲解

### 3.1 路由与转发
- **转发**：根据路由表把收到的分组从合适的接口送出去，逐跳进行。
- **路由**：计算并维护路由表的过程，决定全网路径。
- 路由表核心字段：目的网络、掩码、下一跳、出接口、度量值。

### 3.2 距离向量算法（RIP 为代表）
- 每台路由器只向邻居通告"我到各目的网络的距离"。
- 采用 Bellman-Ford 思想：`d(v) = min(d(u) + cost(u,v))`。
- **跳数**作为度量，RIP 最大跳数 15，16 视为不可达，因此仅适合小型网络。
- 典型问题：**慢收敛**与"计数到无穷"；通过毒性反转、水平分割缓解。

### 3.3 链路状态算法（OSPF 为代表）
- 每台路由器收集全网链路状态（与哪些邻居相连、代价多少），形成链路状态数据库。
- 每台路由器以自身为根运行 **Dijkstra 最短路径算法**，计算到全网的最短路径树。
- 优点：收敛快、支持代价度量、无慢收敛问题；适合中大型企业网。
- OSPF 通过区域（Area 0 骨干区域）划分缩小链路状态传播范围。

### 3.4 边界网关协议 BGP
- 用于**自治系统（AS）之间**的路由，是互联网骨干路由协议。
- 属于路径向量协议，通告的是"可达网络 + AS 路径"，便于策略控制。
- 更关注策略（选路、过滤、对等关系）而非单纯最短路径。

### 3.5 静态路由 vs 动态路由
- 静态路由：手工配置，简单、可控、开销小，适合拓扑稳定的小网络。
- 动态路由：自动适应拓扑变化，但占用带宽与计算资源。

## 4. 关键事实
- RIP 是距离向量协议，OSPF 是链路状态协议，BGP 是路径向量协议。
- OSPF 基于 Dijkstra 算法；RIP 基于 Bellman-Ford 算法。
- 默认网关本质上是主机侧的一条"默认静态路由"。

## 5. 易混淆点
- 不要把"路由"与"转发"混为一谈：路由是决策，转发是执行。
- RIP 的"跳数"不等于链路开销，它不考虑带宽与延迟。
- BGP 不在 AS 内部选路，而在 AS 之间按策略选路。
