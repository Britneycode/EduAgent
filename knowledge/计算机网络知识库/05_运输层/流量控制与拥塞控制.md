# 流量控制与拥塞控制

## 1. 学习目标
- 理解流量控制与拥塞控制的基本定义、作用范围和所在层次。
- 能够用分层模型解释流量控制与拥塞控制与相邻知识点的关系。
- 能够基于事实卡、实验或题目验证关键结论。

## 2. 核心概念
流量控制关注接收方，拥塞控制关注网络路径。

## 3. 知识讲解
区分 TCP 流量控制与拥塞控制，并介绍窗口机制。 学习时应先判断该主题属于哪一层，再分析它处理的数据单位、关键字段、典型流程和失效场景。对于 LLM/RAG 使用，本节优先提供稳定表述，详细推导、标准引用与实验截图在后续审核版本中补充。

## 6. 导师 Agent 教学提示
- 学生常见困惑：混淆流量控制和拥塞控制。
- 诊断建议：问"如果接收方处理很快但网络很堵，用哪个机制？"来检测理解。
- 个性化策略：流量控制像"你吃得慢我就少给你盛"，拥塞控制像"路上车多了大家都减速"。
