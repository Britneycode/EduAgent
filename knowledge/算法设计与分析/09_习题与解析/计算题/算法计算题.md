# 算法计算题

## 题集定位
训练手算能力：递归式求解、动态规划填表、图算法手工执行，每题附完整过程与答案。

## 1. 递归式与复杂度

### 题目 1
用 Master 定理求解 $T(n)=4T(n/2)+n$。

**解答：** $a=4,b=2$，$n^{\log_b a}=n^2$。$f(n)=n=O(n^{2-\epsilon})$（取 $\epsilon=1$），属情形 1，故 $T(n)=\Theta(n^{2})$。

### 题目 2
用递归树法求解 $T(n)=2T(n/2)+n\log n$。

**解答：** 第 $i$ 层有 $2^i$ 个规模 $n/2^i$ 的子问题，每层代价 $2^i\cdot (n/2^i)\log(n/2^i)=n(\log n - i)$。共 $\log n$ 层，总代价 $\sum_{i=0}^{\log n -1} n(\log n-i)=n\cdot\frac{\log n(\log n+1)}{2}=\Theta(n\log^2 n)$。

### 题目 3
求解 $T(n)=T(n-1)+n$，并说明它对应的分治/递归算法特征。

**解答：** 展开得 $T(n)=n+(n-1)+\cdots+1+T(0)=\Theta(n^2)$。对应"每次只把规模减 1、代价线性"的递归，如朴素的插入排序递归版、不均衡分区（最坏快排）的递归式 $T(n)=T(n-1)+O(n)$。

## 2. 动态规划填表

### 题目 4
物品：重量 $w=(2,3,4,5)$，价值 $v=(3,4,5,6)$，背包容量 $W=5$。给出 0-1 背包 DP 表并求最大价值与所选物品。

**解答：** 状态 $dp[i][w]=\max(dp[i-1][w],\ dp[i-1][w-w_i]+v_i)$（$w\ge w_i$）。

| i\w | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 1(w2,v3) | 0 | 0 | 3 | 3 | 3 | 3 |
| 2(w3,v4) | 0 | 0 | 3 | 4 | 4 | 7 |
| 3(w4,v5) | 0 | 0 | 3 | 4 | 5 | 7 |
| 4(w5,v6) | 0 | 0 | 3 | 4 | 5 | 7 |

最大价值 **7**，回溯得选物品 {1,2}（重 2+3=5，价值 3+4=7）。

### 题目 5
求 $X=\text{"ABCBDAB"}$ 与 $Y=\text{"BDCABA"}$ 的最长公共子序列长度，并写出一个 LCS。

**解答：** 填 $dp[7][6]$ 表（过程略），得 $dp[7][6]=4$，一个 LCS 为 **"BCBA"**（"BCAB" 亦为合法答案，长度均为 4）。回溯规则：$x_i=y_j$ 时取左上+1 方向，否则取上下较大者。

### 题目 6
矩阵连乘：$A_1(10\times 100), A_2(100\times 5), A_3(5\times 50)$，求最少标量乘法次数与最优加括号方式。

**解答：** 两种方案：$(A_1A_2)A_3$ 代价 $10\times100\times5 + 10\times5\times50 = 5000+2500=7500$；$A_1(A_2A_3)$ 代价 $100\times5\times50 + 10\times100\times50 = 25000+50000=75000$。最优为 **7500**，方案 $((A_1A_2)A_3)$。

## 3. 图算法手算

### 题目 7
有向图边（权）：$s\to a(2), s\to b(5), a\to b(1), a\to c(6), b\to c(2), c\to d(3), b\to d(7)$。用 Dijkstra 求 $s$ 到各点最短路。

**解答：**
- 取 $s$：$d(a)=2, d(b)=5$。
- 取 $a$：松弛 $b: \min(5, 2+1)=3$，$c: 2+6=8$。
- 取 $b$：松弛 $c: \min(8, 3+2)=5$，$d: 3+7=10$。
- 取 $c$：松弛 $d: \min(10, 5+3)=8$。
- 取 $d$。

结果：$d(a)=2,\ d(b)=3,\ d(c)=5,\ d(d)=8$；路径 $s\to a\to b\to c\to d$。

### 题目 8
无向图 5 个顶点 $V=\{1..5\}$，边（权）：1-2(1), 1-3(7), 2-3(5), 2-4(4), 3-4(2), 3-5(6), 4-5(3)。分别用 Kruskal 和 Prim（从 1 出发）求 MST，比较结果。

**解答：** Kruskal 按权排序：1-2(1)✓, 3-4(2)✓, 4-5(3)✓, 2-4(4)✓（连通 {1,2,4,5,3}），之后 2-3(5) 成环✗, 3-5(6)✗, 1-3(7)✗。MST 边集 {1-2, 3-4, 4-5, 2-4}，总权 **10**。
Prim 从 1：选 1-2(1)，候选 2-4(4)/2-3(5)/1-3(7)→选 2-4(4)，候选 3-4(2)/4-5(3)→选 3-4(2)，再选 4-5(3)。结果相同，总权 **10**。

### 题目 9
对边（权）：1-2(-4), 1-3(5), 2-3(3), 3-2(-2)（有向），说明 Dijkstra 为何失效，并用 Bellman-Ford 求源 1 的最短路。

**解答：** Dijkstra 先定 $d(2)=-4$，但经 3 的路径 $1\to3\to2=-4+5-2=-1> -4$？逐步算：实际 $d(3)=\min(5, -4+3)=-1$，$d(2)=\min(-4, -1-2)=-3$——$d(2)$ 后来变小，违反 Dijkstra "一旦出队不再更新"的假设，故失效。
Bellman-Ford：初始 $d=(0,\infty,\infty)$。第1轮：$d(2)=-4, d(3)=5$。第2轮：经2→3：$d(3)=\min(5,-4+3)=-1$；经3→2：$d(2)=\min(-4,-1-2)=-3$。第3轮：$d(3)=\min(-1,-3+3)=0$？$-3+3=0>-1$，不变。收敛：$d(2)=-3,\ d(3)=-1$。图中 2-3 环权 $3+(-2)=1>0$，无负环，算法正常终止。

## 4. 综合计算

### 题目 10
活动集合（起,止）：(1,4),(3,5),(0,6),(5,7),(3,9),(5,9),(6,10),(8,11),(8,12),(2,14),(12,16)。用"最早结束时间"贪心求最大兼容活动数。

**解答：** 按结束时间排序后依次选择：选 (1,4)；下一个起点 ≥4 的最早结束活动为 (5,7)；再选 (8,11)；再选 (12,16)。共选 **4** 个活动：(1,4),(5,7),(8,11),(12,16)。贪心策略在活动选择问题上可证最优。
