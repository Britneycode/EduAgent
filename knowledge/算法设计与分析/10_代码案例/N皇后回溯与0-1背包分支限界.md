# N 皇后回溯与 0-1 背包分支限界

## 1. 案例目标
同一解空间树，两种剪枝思路：回溯用约束剪可行性分支，分支限界再用目标上界剪非最优分支。

## 2. N 皇后（回溯 + 位运算/集合剪枝）

```python
def solve_n_queens(n: int) -> list[list[int]]:
    solutions: list[list[int]] = []
    cols = set()          # 已占用列
    diag1 = set()         # 行-列 常数（主对角线）
    diag2 = set()         # 行+列 常数（副对角线）
    board: list[int] = [] # board[r] = 该行皇后所在列

    def dfs(r: int):
        if r == n:
            solutions.append(board[:])
            return
        for c in range(n):
            if c in cols or (r - c) in diag1 or (r + c) in diag2:
                continue                      # 约束剪枝
            cols.add(c); diag1.add(r - c); diag2.add(r + c); board.append(c)
            dfs(r + 1)
            cols.remove(c); diag1.remove(r - c); diag2.remove(r + c); board.pop()

    dfs(0)
    return solutions

sols = solve_n_queens(8)
print(len(sols))   # 92
```

朴素解空间 $n^n$，约束剪枝后 8 皇后仅搜索少量结点即可得全部 92 解。

## 3. 0-1 背包（分支限界）

```python
import heapq

def knapsack_bnb(weights: list[int], values: list[int], W: int):
    n = len(weights)
    # 按单位价值降序预处理，使贪心上界更紧
    order = sorted(range(n), key=lambda i: values[i] / weights[i], reverse=True)
    suffix_best = [0] * (n + 1)           # 后缀的分数背包上界
    # 简化：用剩余物品总价值做松弛上界（更紧可换成分数背包上界）
    for idx in range(n - 1, -1, -1):
        i = order[idx]
        suffix_best[idx] = suffix_best[idx + 1] + values[i]

    best_val, best_take = 0, []
    # 结点: (-上界, 层, 已用容量, 已得价值, 已选列表)
    heap = [(-sum(values), 0, 0, 0, [])]
    while heap:
        neg_ub, depth, cap, val, take = heapq.heappop(heap)
        if neg_ub > -best_val or depth == n:   # 上界不优于当前最优 → 剪
            if depth == n and val > best_val:
                best_val, best_take = val, take
            continue
        i = order[depth]
        # 分支 1：装入物品 i
        if cap + weights[i] <= W:
            t2 = take + [i]
            if val + values[i] > best_val:
                best_val, best_take = val + values[i], t2
            heapq.heappush(heap, (-(val + values[i] + suffix_best[depth + 1]),
                                  depth + 1, cap + weights[i],
                                  val + values[i], t2))
        # 分支 2：不装入物品 i
        heapq.heappush(heap, (-(val + suffix_best[depth + 1]),
                              depth + 1, cap, val, take))
    return best_val, sorted(best_take)

print(knapsack_bnb([2, 3, 4, 5], [3, 4, 5, 6], 5))   # (7, [0, 1])
```

**两类剪枝：** 超重剪枝（约束）与"上界 ≤ 当前最优"剪枝（最优性）。上界越紧剪得越多：`suffix_best`（剩余总价值）是松弛上界，可替换为分数背包上界进一步提升效率。
