# 0-1 背包与完全背包

## 1. 案例目标
实现 0-1 背包的二维 DP 与滚动数组优化，以及完全背包，理解"枚举顺序决定物品可选次数"。

## 2. 0-1 背包：二维表

```python
def knapsack_01(weights: list[int], values: list[int], W: int):
    n = len(weights)
    dp = [[0] * (W + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for w in range(W + 1):
            dp[i][w] = dp[i - 1][w]                      # 不选物品 i
            if w >= weights[i - 1]:                      # 选物品 i
                dp[i][w] = max(dp[i][w],
                               dp[i - 1][w - weights[i - 1]] + values[i - 1])
    return dp[n][W], dp

def recover_items(weights, values, W, dp) -> list[int]:
    """回溯找出被选中的物品下标（0-based）。"""
    chosen, w = [], W
    for i in range(len(weights), 0, -1):
        if dp[i][w] != dp[i - 1][w]:
            chosen.append(i - 1)
            w -= weights[i - 1]
    return chosen[::-1]
```

时间 $O(nW)$，空间 $O(nW)$（伪多项式：$W$ 的数值大小决定表规模）。

## 3. 空间优化：滚动数组

```python
def knapsack_01_1d(weights: list[int], values: list[int], W: int) -> int:
    dp = [0] * (W + 1)
    for wi, vi in zip(weights, values):
        for w in range(W, wi - 1, -1):   # 关键：倒序，防止同件物品被重复选取
            dp[w] = max(dp[w], dp[w - wi] + vi)
    return dp[W]
```

**倒序**保证读取的 `dp[w-wi]` 仍是"上一行"（未考虑本物品）的值；若正序则同一物品可被多次装入——那正是完全背包。

## 4. 完全背包

```python
def knapsack_complete(weights: list[int], values: list[int], W: int) -> int:
    dp = [0] * (W + 1)
    for wi, vi in zip(weights, values):
        for w in range(wi, W + 1):       # 正序：物品可重复选取
            dp[w] = max(dp[w], dp[w - wi] + vi)
    return dp[W]
```

## 5. 验证

```python
if __name__ == "__main__":
    w, v, W = [2, 3, 4, 5], [3, 4, 5, 6], 5
    best, table = knapsack_01(w, v, W)
    print(best, recover_items(w, v, W, table))   # 7 [0, 1]
    print(knapsack_01_1d(w, v, W))               # 7
    print(knapsack_complete(w, v, W))            # 7（W=5 下：物品1×2 价值6，或物品1+物品2 价值7）
```

## 6. 讨论
1. 为什么 0-1 背包一维写法必须倒序、完全背包必须正序？
2. $O(nW)$ 是多项式时间吗？（讨论"伪多项式"与 NP 难的关系）
