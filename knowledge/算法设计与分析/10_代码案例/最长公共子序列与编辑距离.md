# 最长公共子序列与编辑距离

## 1. 案例目标
实现两个经典序列 DP：LCS（求相似结构）与编辑距离（求最小改动代价），掌握转移方程、回溯方案与滚动数组。

## 2. 最长公共子序列（LCS）

```python
def lcs(x: str, y: str) -> tuple[int, str]:
    m, n = len(x), len(y)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if x[i - 1] == y[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    # 回溯构造一个 LCS
    out, i, j = [], m, n
    while i > 0 and j > 0:
        if x[i - 1] == y[j - 1]:
            out.append(x[i - 1]); i -= 1; j -= 1
        elif dp[i - 1][j] >= dp[i][j - 1]:
            i -= 1
        else:
            j -= 1
    return dp[m][n], "".join(reversed(out))

print(lcs("ABCBDAB", "BDCABA"))   # (4, 'BCBA')  或 'BCAB' 等长解
```

时间/空间 $O(mn)$。

## 3. 编辑距离（Levenshtein）

```python
def edit_distance(a: str, b: str) -> int:
    m, n = len(a), len(b)
    # 滚动数组：只保留上一行
    prev = list(range(n + 1))            # dp[0][j] = j（插入 j 个字符）
    for i in range(1, m + 1):
        cur = [i] + [0] * n              # dp[i][0] = i
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                cur[j] = prev[j - 1]                 # 匹配，无代价
            else:
                cur[j] = 1 + min(prev[j - 1],  # 替换
                                 prev[j],      # 删除 a[i-1]
                                 cur[j - 1])   # 插入 b[j-1]
        prev = cur
    return prev[n]

print(edit_distance("kitten", "sitting"))  # 3
```

时间 $O(mn)$，空间优化后 $O(n)$。
