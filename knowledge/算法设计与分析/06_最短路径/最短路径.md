# 最短路径

## 1. 学习目标
- 理解单源最短路径与全源最短路径问题的区别。
- 掌握 Dijkstra 算法及其适用条件（非负权）。
- 掌握 Bellman-Ford 处理负权与检测负环。
- 掌握 Floyd-Warshall 的全源最短路求解。

## 2. 核心概念
最短路径问题分为单源（一个起点到所有点）与全源（所有点对）。不同算法在权值约束与复杂度上取舍。

## 3. 知识讲解

### 3.1 问题分类
- **单源最短路径**：从源点 s 到所有其他顶点的最短路径。
- **全源最短路径**：所有顶点对之间的最短路径。
- 权重可为负值，但若存在负权环则最短路径无定义。

### 3.2 Dijkstra 算法
- 适用：**非负权**有向/无向图。
- 思想：贪心 + 优先队列。每次从未确定顶点中选距离最小的，松弛其邻居。
- 复杂度：优先队列实现 `O((V+E) log V)`。
- 使用前提：所有边权非负；否则需 Bellman-Ford。
- 与 BFS 的关系：BFS 是无权图特例。

### 3.3 Bellman-Ford 算法
- 适用：**允许负权**，可检测负环。
- 思想：对每条边做 V-1 轮松弛；再做一轮，若仍能松弛则存在负环。
- 复杂度 `O(VE)`，适合边数少、含负权的场景。

### 3.4 Floyd-Warshall 算法
- 适用：**全源**最短路径（可含负权但不可有负环）。
- 思想：动态规划，`dp[k][i][j]` = 只经过前 k 个顶点中转的最短路径。
- 转移：`dp[i][j] = min(dp[i][j], dp[i][k] + dp[k][j])`。
- 复杂度 `O(V^3)`，实现极简，适合稠密小图。

### 3.5 算法选择
- 非负权单源 → Dijkstra。
- 负权单源/需检测负环 → Bellman-Ford。
- 全源/小图 → Floyd-Warshall。

## 4. 示例代码 / 伪代码
```python
import heapq

def dijkstra(graph, start):
    """graph: dict 顶点->[(邻居, 权重)]，边权非负。"""
    dist = {v: float("inf") for v in graph}
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return dist

def bellman_ford(edges, n, start):
    """edges: list[(u, v, w)]。返回 (dist, 是否有负环)。"""
    dist = [float("inf")] * n
    dist[start] = 0
    for _ in range(n - 1):
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            return dist, True  # 存在负环
    return dist, False
```

## 5. 关键事实
- Dijkstra 要求非负权；Bellman-Ford 允许负权并可检测负环。
- Floyd-Warshall 复杂度 `O(V^3)`，适合全源小图。
- 无权图最短路用 BFS（`O(V+E)`）即可。

## 6. 易混淆点
- Dijkstra 不能用于负权边，错误结果往往"看似合理"。
- 负权环存在时最短路无定义，Bellman-Ford 用来检测它。
- Floyd 的三层循环顺序：中转点 k 在最外层。
