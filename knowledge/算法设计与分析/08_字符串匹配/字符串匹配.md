# 字符串匹配

## 1. 学习目标
- 理解字符串匹配问题的定义。
- 掌握朴素匹配与 Rabin-Karp 的思想与复杂度。
- 掌握 KMP 算法与前缀函数。
- 能分析不同算法的适用场景。

## 2. 核心概念
在文本 T 中查找模式 P 的所有出现位置。经典算法从 O(nm) 的朴素匹配到 O(n+m) 的 KMP。

## 3. 知识讲解

### 3.1 朴素匹配
- 在 T 的每个位置尝试匹配 P，失败则右移一位。
- 最坏 `O(nm)`，简单但低效。

### 3.2 Rabin-Karp
- 用哈希值比较长度为 m 的窗口与模式。
- 利用滚动哈希：`O(1)` 从旧窗口推出新窗口哈希。
- 平均 `O(n+m)`，最坏因哈希冲突退化 `O(nm)`。
- 常配合素数取模；用于多模式匹配、查重等场景。

### 3.3 KMP 算法
- 核心：**前缀函数 π[i]** = 子串 P[0..i] 的最长相等真前后缀长度。
- 匹配失败时，利用 π 跳过不可能的位置，不回退文本指针。
- 复杂度 `O(n+m)`。
- 应用：子串查找、字符串周期、重复子串检测。

### 3.4 前缀函数的求法
- 递推：`π[i]` 由 `π[i-1]` 尝试扩展，失败则回退到 `π[π[i-1]-1]`。
- 与匹配过程结构一致，可复用相同逻辑。

## 4. 示例代码 / 伪代码
```python
def prefix_function(p):
    """p 的前缀函数。"""
    n = len(p)
    pi = [0] * n
    for i in range(1, n):
        j = pi[i - 1]
        while j > 0 and p[i] != p[j]:
            j = pi[j - 1]
        if p[i] == p[j]:
            j += 1
        pi[i] = j
    return pi

def kmp_search(text, pattern):
    """返回 pattern 在 text 中的所有起始下标。"""
    if not pattern:
        return []
    pi = prefix_function(pattern)
    res, j = [], 0
    for i, ch in enumerate(text):
        while j > 0 and ch != pattern[j]:
            j = pi[j - 1]
        if ch == pattern[j]:
            j += 1
        if j == len(pattern):
            res.append(i - j + 1)
            j = pi[j - 1]
    return res
```

## 5. 关键事实
- KMP 复杂度 `O(n+m)`，不回退文本指针。
- Rabin-Karp 平均快，最坏受哈希冲突影响。
- 前缀函数是 KMP 的核心，理解它就理解了 KMP。

## 6. 易混淆点
- Rabin-Karp 的哈希冲突可能导致"假匹配"，需二次校验。
- 前缀函数求的是"真前后缀"（不能是整个串）。
- KMP 不需要像 BM 那样从后往前匹配。
