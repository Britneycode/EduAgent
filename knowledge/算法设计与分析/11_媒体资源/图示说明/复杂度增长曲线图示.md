# 复杂度增长曲线图示

## 1. 图示 A：增长曲线族（单图）
- 横轴 n（0–50），纵轴操作数；
- 曲线：$\log_2 n$、$n$、$n\log_2 n$、$n^2$、$2^n$（后段截断或对数纵轴处理）；
- 视觉重点：$n^2$ 与 $2^n$ 的"起飞"位置标注箭头（n≈20 后 $2^n$ 爆表）；
- 配色建议：线性系冷色（蓝绿），指数系暖色（红橙）。

## 2. 图示 B：问题规模上限对照表（表格图）
以"1 秒可执行约 $10^8$ 次操作"为基准：

| 复杂度 | 1 秒可解规模 | 1 天可解规模 |
|---|---|---|
| $O(\log n)$ | ~$10^{24}$ | ~$10^{33}$ |
| $O(n)$ | $10^8$ | $8.6\times10^{12}$ |
| $O(n\log n)$ | ~$4\times10^6$ | ~$3\times10^{11}$ |
| $O(n^2)$ | $10^4$ | ~$9\times10^6$ |
| $O(n^3)$ | ~460 | ~$2\times10^4$ |
| $O(2^n)$ | ~26 | ~36 |
| $O(n!)$ | ~12 | ~15 |

设计要点：把 $O(2^n)$ 一行用红色高亮——"硬件翻 1000 倍，规模只多 10"。

## 3. 图示 C：Θ 记号夹逼示意（小图）
- $f(n)$ 曲线被 $c_1 g(n)$ 与 $c_2 g(n)$ 上下夹住（n ≥ n₀ 之后）；
- 垂直虚线标出 n₀，左侧虚化区表示"小规模不重要"。

## 4. 制图数据（Python 参考）

```python
import math
funcs = {
    "log n": lambda n: math.log2(n),
    "n": lambda n: n,
    "n log n": lambda n: n * math.log2(n),
    "n^2": lambda n: n ** 2,
    "2^n": lambda n: 2.0 ** n,
}
for n in (10, 20, 30, 50):
    print(n, {k: round(f(n), 1) for k, f in funcs.items()})
```

## 5. 使用建议
- 图示 A 用于第 1 章引入；图示 B 用于"为什么复杂度决定可行性"的论证页；
- 所有图注明"假设每秒 $10^8$ 次操作"，避免绝对数字争议。
