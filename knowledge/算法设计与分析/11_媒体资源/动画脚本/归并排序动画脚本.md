# 归并排序动画脚本

## 1. 脚本说明
时长约 60 秒；以数组 [38, 27, 43, 3, 9, 82, 10] 为例；风格参考可交互演示（如 visualgo），可直接交给媒体 Agent 或前端实现。

## 2. 分镜

### 镜头 1（0–8s）：分解阶段
- 数组横排展示；中线出现，数组被切成两半并上下错开（递归第一层）
- 每半继续切开，直到全部为单元素；画面呈倒立的二叉树，共 $\log n=3$ 层
- 字幕：「分解：不停对半切，直到每块只有 1 个元素——天然有序」

### 镜头 2（8–40s）：合并阶段
- 自底向上两两合并；每次合并突出显示**双指针**：
  - 两个指针（红/蓝圆点）分别指向左右子数组的队首
  - 每步较小者飞入下方结果区，指针右移
  - 示例关键合并：[27,38] 与 [43] → [27,38,43]；[3,9] 与 [10,82] → [3,9,10,82]；最终 [3,9,10,27,38,43,82]
- 右下角计数器实时累加比较次数（体现 $O(n)$ 每层）

### 镜头 3（40–52s）：复杂度总览
- 树形图逐层高亮：每层总代价 = n；层数 = log n
- 公式浮现：$T(n)=2T(n/2)+\Theta(n)=\Theta(n\log n)$

### 镜头 4（52–60s）：对照快排
- 小窗对照：快排先整后分 vs 归并先分后整
- 字幕：「归并：任何输入都 n log n，但要 O(n) 辅助空间」

## 3. 交互点（可选）
- 暂停/单步：合并过程中任意暂停查看双指针状态
- 输入自定义数组（≤16 个元素）
- 「最坏输入」按钮：展示归并不受输入影响（与快排对照）
