# 排序算法计时实验

## 1. 实验目的
1. 掌握用计时实验验证理论复杂度的方法；
2. 观察"输入分布改变最坏/平均行为"的现象（快排退化、插入排序在近有序数据上的优势）。

## 2. 实验环境
Python 3.10+（仅标准库），单文件脚本即可完成。

## 3. 实验内容

### 步骤 1：实现三种排序
实现插入排序 $O(n^2)$、归并排序 $O(n\log n)$、随机化快排（参考 [[归并排序与快速排序]]）。禁用内置 `sorted`。

### 步骤 2：构造四种输入分布

```python
import random

def gen(n: int, kind: str) -> list[int]:
    if kind == "random":
        return [random.randint(0, n) for _ in range(n)]
    if kind == "sorted":
        return list(range(n))
    if kind == "reversed":
        return list(range(n, 0, -1))
    if kind == "few_unique":          # 大量重复元素
        return [random.randint(0, 5) for _ in range(n)]
    raise ValueError(kind)
```

### 步骤 3：计时矩阵
对每种算法 × 每种分布 × n ∈ {1000, 5000, 20000} 计时（每组重复 5 次取中位数），输出表格。

```python
import time, statistics

def bench(fn, data, repeat=5):
    ts = []
    for _ in range(repeat):
        arr = data[:]
        t0 = time.perf_counter()
        fn(arr)
        ts.append(time.perf_counter() - t0)
    return statistics.median(ts)
```

### 步骤 4：观察与记录
预期现象：
- 插入排序在 `sorted` 输入上接近 $O(n)$（内层循环零次）；
- 无随机枢轴的快排在 `sorted`/`reversed` 上退化为 $O(n^2)$；
- 归并排序对四种分布均稳定 $O(n\log n)$，但常数因子大于快排。

## 4. 实验报告要求
1. 计时矩阵表 + 增长率折线图（n 对耗时，双对数坐标下斜率 ≈ 复杂度指数）；
2. 解释每个"反直觉"数据（如小 n 时插入排序更快）；
3. 结论：理论复杂度与实测的偏差来自哪里（常数因子、缓存、解释器）。

## 5. 思考题
1. 双对数坐标下为何能用斜率读出复杂度指数？
2. `few_unique` 分布上三向切分快排（3-way partition）收益多大？实现并验证。
