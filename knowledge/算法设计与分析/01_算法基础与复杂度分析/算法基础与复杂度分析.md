# 算法基础与复杂度分析

## 1. 学习目标
- 理解算法与算法的正确性、效率评价标准。
- 掌握 O、Ω、Θ 等渐近记号的含义。
- 能够分析循环与递归程序的时间复杂度。
- 掌握主定理求解递归方程。

## 2. 核心概念
算法是解决特定问题的有限、确定、有效步骤序列。评价算法主要看时间与空间复杂度。

## 3. 知识讲解

### 3.1 算法与渐近记号
- 时间复杂度描述运行时间随输入规模 n 的增长趋势。
- **O（上界）**：f(n) = O(g(n)) 表示 f 的增长不超过 g 的常数倍。
- **Ω（下界）**：f(n) = Ω(g(n)) 表示 f 的增长不低于 g 的常数倍。
- **Θ（紧界）**：f(n) = Θ(g(n)) 表示 f 与 g 同阶。
- 常见复杂度排序：`1 < log n < n < n log n < n^2 < 2^n < n!`

### 3.2 复杂度分析要点
- 忽略常数因子与低阶项：`3n^2 + 5n + 10 = O(n^2)`。
- 分析循环：嵌套循环相乘、顺序语句相加。
- 最坏情况 vs 平均情况：通常分析最坏情况。

### 3.3 递归与主定理
- 分治递归形如 `T(n) = aT(n/b) + f(n)`。
- **主定理**：比较 `n^(log_b a)` 与 `f(n)` 的增长关系：
  - 若 `f(n) = O(n^(log_b a - ε))`，则 `T(n) = Θ(n^(log_b a))`；
  - 若 `f(n) = Θ(n^(log_b a))`，则 `T(n) = Θ(n^(log_b a) log n)`；
  - 若 `f(n) = Ω(n^(log_b a + ε))` 且满足正则条件，则 `T(n) = Θ(f(n))`。
- 例：归并排序 `T(n) = 2T(n/2) + Θ(n)` → `T(n) = Θ(n log n)`。

## 4. 示例代码 / 伪代码
```python
def max_subarray_bruteforce(arr):
    """O(n^2) 暴力求最大子数组和（供复杂度对比）。"""
    n = len(arr)
    best = float("-inf")
    for i in range(n):
        s = 0
        for j in range(i, n):
            s += arr[j]
            best = max(best, s)
    return best
```

## 5. 关键事实
- 渐近记号只关心增长趋势，不关心常数倍与机器差异。
- 递归分析中主定理是快速求解的工具，不适用时可用递归树或代入法。

## 6. 易混淆点
- O 是上界而非精确复杂度；Θ 才是紧界。
- 不要把"平均情况复杂度"与"最坏情况复杂度"混为一谈。
- 2^n 与 n! 在竞赛与工程中通常视为不可接受。
