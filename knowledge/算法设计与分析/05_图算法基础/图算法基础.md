# 图算法基础

## 1. 学习目标
- 掌握图的两种表示：邻接矩阵与邻接表。
- 掌握 BFS 与 DFS 的遍历过程、复杂度与应用。
- 掌握拓扑排序及其前提（DAG）。
- 了解强连通分量的基本概念。

## 2. 核心概念
图由顶点集 V 与边集 E 组成。图算法是求解最短路径、最小生成树等问题的基础工具，其核心是 BFS 与 DFS 两种遍历。

## 3. 知识讲解

### 3.1 图的表示
- **邻接矩阵**：`O(V^2)` 空间，适合稠密图，判断边是否存在 O(1)。
- **邻接表**：`O(V + E)` 空间，适合稀疏图，是竞赛与工程主流。
- 有向图/无向图、带权图都需要在表示中体现方向与权重。

### 3.2 广度优先搜索（BFS）
- 使用队列，逐层访问，先访问距离近的顶点。
- 应用：无权图最短路径、连通分量、二分图判定。
- 复杂度 `O(V + E)`。
- BFS 生成树中，每个顶点首次被发现的路径即无权最短路径。

### 3.3 深度优先搜索（DFS）
- 使用栈（或递归），沿一条分支走到尽头再回溯。
- 记录发现时间与完成时间，可判断环、拓扑排序、强连通分量。
- 复杂度 `O(V + E)`。
- 递归实现注意深度过大的栈溢出（可用显式栈）。

### 3.4 拓扑排序
- 针对**有向无环图（DAG）**，给出顶点的一个线性次序，使每条边 u→v 中 u 在 v 之前。
- 方法一：Kahn 算法，不断删除入度为 0 的顶点。
- 方法二：DFS 后序的逆序。
- 应用：课程先修安排、任务调度。

### 3.5 强连通分量（SCC）
- 有向图中两两可达的最大顶点子集。
- Kosaraju 或 Tarjan 算法求解，基于 DFS。
- 应用：把有向图缩点成 DAG，简化问题。

## 4. 示例代码 / 伪代码
```python
from collections import deque

def bfs(graph, start):
    """graph: dict 顶点->邻居列表。返回各点到 start 的最短距离（无权）。"""
    dist = {v: -1 for v in graph}
    dist[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in graph[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

def topological_sort_kahn(graph):
    """Kahn 算法，graph 为 DAG。"""
    indeg = {v: 0 for v in graph}
    for u in graph:
        for v in graph[u]:
            indeg[v] += 1
    q = deque([v for v in graph if indeg[v] == 0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order  # 若长度小于顶点数，说明图有环
```

## 5. 关键事实
- BFS 用队列、DFS 用栈/递归，两者复杂度都是 `O(V + E)`。
- 拓扑排序仅对 DAG 有效；存在环则无拓扑序。
- 邻接表适合稀疏图，邻接矩阵适合稠密图。

## 6. 易混淆点
- BFS 求的是无权最短路径；带权最短路要用 Dijkstra/Bellman-Ford。
- DFS 的"完成时间"对拓扑排序与 SCC 很重要，别只关注访问顺序。
- 拓扑排序结果通常不唯一。
