# 贪心算法

## 1. 学习目标
- 理解贪心选择性质与最优子结构。
- 掌握活动选择、哈夫曼编码等经典贪心问题。
- 能判断一个问题是否适合贪心，并给出反例。

## 2. 核心概念
贪心算法每一步都做当前看起来最优的局部选择，并希望局部最优能导向全局最优。适用于具有贪心选择性质的问题。

## 3. 知识讲解

### 3.1 贪心 vs 动态规划
- 贪心：一步一选，不回退；实现简单、效率高，但**并非所有问题**都成立。
- DP：比较所有子问题解；保证正确但代价更高。
- 关键区别：贪心基于"贪心选择性质"，DP 基于"最优子结构 + 重叠子问题"。

### 3.2 活动选择问题
- 任务：在一组带开始/结束时间的活动中，选择最多互不重叠的活动。
- 贪心策略：按**结束时间最早**排序，每次选结束最早且与已选不冲突的活动。
- 该策略具有贪心选择性质与最优子结构，可证明最优。

### 3.3 哈夫曼编码
- 目标：给定字符频度，构造前缀码使总编码长度最短。
- 贪心策略：反复合并频度最小的两个节点，构造最优二叉编码树。
- 用最小堆实现，复杂度 `O(n log n)`。
- 哈夫曼编码是前缀码，无歧义解码。

### 3.4 其他经典贪心
- 分数背包（按单位价值排序取）——贪心最优。
- Dijkstra 最短路径、Prim/Kruskal 最小生成树——贪心思路（见后续章节）。
- 找零钱问题：贪心不一定最优（取决于币制）。

### 3.5 判断贪心是否可行
- 尝试构造反例。
- 若能证明"局部最优选择不会排除全局最优"，则可贪心。

## 4. 示例代码 / 伪代码
```python
import heapq

def activity_selection(activities):
    """activities: list[(start, end)]，按结束时间排序。"""
    activities.sort(key=lambda x: x[1])
    selected, last_end = [], -float("inf")
    for s, e in activities:
        if s >= last_end:
            selected.append((s, e))
            last_end = e
    return selected

def huffman(freqs):
    """freqs: dict 字符->频度，返回带权路径长度。"""
    heap = [[f, c] for c, f in freqs.items()]
    heapq.heapify(heap)
    total = 0
    while len(heap) > 1:
        a = heapq.heappop(heap)
        b = heapq.heappop(heap)
        merged = a[0] + b[0]
        total += merged
        heapq.heappush(heap, [merged, None])
    return total
```

## 5. 关键事实
- 活动选择按结束时间最早贪心；找零按币值贪心在标准币制下最优。
- 哈夫曼树带权路径长度最小，常用最小堆实现。
- 贪心正确性需要证明，不能仅凭直觉。

## 6. 易混淆点
- "分数背包"可贪心，"0-1 背包"贪心通常不最优（要 DP）。
- 活动选择按结束时间而非开始时间排序。
- 贪心的"局部最优"不等于"全局最优"，必须验证。
