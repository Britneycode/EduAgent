# 分治策略

## 1. 学习目标
- 理解分治的三步范式：分解、解决、合并。
- 掌握归并排序与快速排序的原理和复杂度。
- 掌握二分查找及其前提。
- 能用主定理分析分治算法。

## 2. 核心概念
分治把原问题分解为若干规模更小且结构相同的子问题，递归求解子问题后合并得到原问题的解。

## 3. 知识讲解

### 3.1 分治三步
1. **分解**：把问题划分为规模更小的子问题。
2. **解决**：递归求解子问题；规模足够小时直接求解。
3. **合并**：把子问题的解组合成原问题的解。

### 3.2 归并排序
- 分解：把数组从中间一分为二。
- 解决：递归对两半排序。
- 合并：线性合并两个有序数组。
- 复杂度：`T(n) = 2T(n/2) + Θ(n)` → `Θ(n log n)`，稳定排序，需要额外 O(n) 空间。

### 3.3 快速排序
- 选一个基准（pivot），划分数组使左边 ≤ 基准 ≤ 右边。
- 递归对左右部分排序。
- 平均 `Θ(n log n)`，最坏 `Θ(n^2)`（如已有序数组选首元素为基准）。
- 随机化选择基准可规避最坏情况；原地划分，空间 O(log n)。

### 3.4 最大子数组（分治版）
- 跨过中点的最大子数组 = 左半最大 + 右半最大向中间扩展。
- 递归：`T(n) = 2T(n/2) + Θ(n)` → `Θ(n log n)`（暴力为 `Θ(n^2)`）。
- 更优的 Kadane 线性算法也存在。

### 3.5 二分查找
- 前提：有序数组。
- 每次比较中值，排除一半区间。
- 复杂度 `Θ(log n)`，注意整数溢出与边界更新。

## 4. 示例代码 / 伪代码
```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    res, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            res.append(left[i]); i += 1
        else:
            res.append(right[j]); j += 1
    return res + left[i:] + right[j:]

def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if arr[mid] == target:
            return mid
        if arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

## 5. 关键事实
- 归并排序稳定、`Θ(n log n)`，但需额外空间。
- 快速排序平均最快，但最坏退化为 `Θ(n^2)`。
- 二分查找要求有序，是"分治思想"在有序结构上的应用。

## 6. 易混淆点
- 分治与动态规划都分解子问题，但分治子问题通常相互独立，DP 子问题重叠。
- 快速排序的"划分"结果取决于基准选择，不保证左右均衡。
