# 04 · 部署运行说明（金漪湖 · 智能体融合创新赛道版）

> 完整服务器部署细节见仓库 `docs/DEPLOYMENT.md`，本文只列参赛相关要点。

## 1. 文档目的

说明本地运行、环境变量、健康检查与部署边界，便于评审复现与判断可运行性。

## 2. 环境要求

| 类型 | 要求 |
| --- | --- |
| 后端 | Python 3.12 + uv（依赖见 `backend/pyproject.toml`） |
| 前端 | Node 20+ + pnpm |
| LLM | DeepSeek，或 OpenAI 兼容接口（任一） |
| 向量库 | Chroma（本地目录，`WIKI_KNOWLEDGE_DIR` 指向 `./knowledge/计算机网络知识库`） |

## 3. 本地运行

```bash
# 后端（首次会加载 BGE 向量模型并导入知识库，约 1~3 分钟）
cd backend && uv sync && uv run uvicorn app.main:app --reload --port 8000

# 前端
cd frontend && pnpm install && pnpm dev

# MCP 工具集（跨产品调用）
cd backend && uv run python -m app.mcp_server --self-test   # 自检
cd backend && uv run python -m app.mcp_server               # 以 MCP stdio 启动
```

## 4. 环境变量要点

模版见 `backend/.env.example`（如有）或 `app/core/config.py`。关键项：
`DEEPSEEK_API_KEY`（或 `OPENAI_COMPATIBLE_API_KEY`）、`WIKI_KNOWLEDGE_DIR`。
生产环境必须设 `JWT_SECRET_KEY` 且 `LLM_DEV_MODE=false`。

## 5. 健康检查

`GET /health` 返回 `llm_mode / llm_warning / vector_store`；`vector_store.count > 0`
表示知识库导入成功。生产部署已用 Docker Compose + Nginx + HTTPS（见 `docs/DEPLOYMENT.md`）。

## 6. 部署边界

- 独立 Web 应用：已部署 `https://xwz0219.top`（评测可直连体验）。
- remio aApp：需在 remio 客户端内安装到正式环境并发布市场（外部依赖）。
- MCP：以 stdio 方式注册到宿主，无需对外端口。
