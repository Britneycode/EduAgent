# 01 · 方案说明书（金漪湖 · 智能体融合创新赛道版）

> 面向「2026 智能体 OPC 创新大会 · 金漪湖论剑 · 智能体融合创新赛道」。
> 演示脚本与视频分镜见 `remio/docs/`；若需要 .docx，可用 pandoc 转换本文件。

## 一、需求分析

### 1.1 目标用户与痛点

| 用户 | 典型痛点 | 场景 |
| --- | --- | --- |
| 大一/大二学生 | 基础不牢，公共课"跟不上" | 考前复习、查漏补缺 |
| 备考学生 | 千人一面，资料不对口 | 考研/期末针对性刷题 |
| 薄弱点修复者 | 知道不会，但没人引导 | 就一个知识点反复问 |

核心命题浓缩：**同一份讲义、同一套题**是效率最大的浪费；个性化需要一个"闭环"
（画像→规划→多模态产出→答疑），单一问答 AI 完成不了这个闭环。需求研究采用
「赛道文本分析 + 权威公开资料 + 工程原型验证」方式，不虚构问卷样本量或统计比例。

### 1.2 功能需求（与多 Agent 映射）

| 功能 | 对应 Agent | 说明 |
| --- | --- | --- |
| 学习意图识别 | Router | 输入后最先路由 |
| 8 维学生画像 | Profile | 专业/年级/基础/目标/编程水平/认知风格/时长/偏好 |
| 资源规划 | Planner | 拆解并并行编排 |
| 讲义 / 题目 / 代码 / 导图 / PPT / 拓展阅读 / 动画脚本 / 教学视频 | Doc/Quiz/Code/Media/Reading/Video | 多模态资源（7 类） |
| 苏格拉底式答疑 | Tutor | 流式 + 引导 |
| 知识锚定 | LLM Wiki RAG | 防幻觉三防线 + 来源引用 |
| 多课程支持 | LLM Wiki | 内置人工智能导论 / 计算机网络 / 算法设计与分析，自动发现与切换 |

### 1.3 非功能需求

- **可用性**：对话为主、UI 为辅，主路径 3 步内见效。
- **稳定性**：LLM 失败可降级（正则路由 / 备用模型），SSE 流式不白屏；联网能力不可用时
  诚实降级为知识库作答并提示，不静默失败。
- **合规**：开源协议与 AI 工具标注见 `remio/docs/05_AI工具与开源合规说明.md`。
- **跨产品**：MCP 工具集（12 个工具）可在 remio 及其他智能体宿主调用
  （`backend/app/mcp_server.py`）。

## 二、系统设计与实现

### 2.1 系统定位

EduAgent 是面向高校学生的个性化多智能体学习系统，核心流程：

```
学生输入 → 画像理解 → LLM Wiki 检索 → 多 Agent 协作 → 个性化资源 → 测验反馈 → 画像/路径更新
```

一句话：不把大模型用于单轮问答，而是形成「画像—知识组织—资源生成—练习反馈」闭环。

### 2.2 多智能体架构（10 个协同 Agent）

| Agent | 职责 | remio 端点 |
| --- | --- | --- |
| Router | 意图路由 | `route_intent`（E1） |
| Profile | 8 维画像 | `build_profile`（E2） |
| Planner | 任务拆解 | `plan_learning`（E3） |
| Doc | 个性化讲义 | `generate_document`（E4） |
| Quiz | 多类型题 | `generate_quiz`（E5） |
| Code | Python 实操 | `generate_code`（E6） |
| Media | 导图/PPT/动画 | `generate_mindmap`（E7）/`generate_ppt`（E8）/`generate_animation`（可选） |
| Reading | 拓展阅读（联网优先） | `generate_reading`（E9） |
| Tutor | 答疑引导（两级：知识库→网络显式升级） | `tutor_answer`（E10） |
| Video | 教学视频（联网搜 B 站，可选） | `search_video`（可选端点） |

编排规则：Router 先行 → Profile 串行优先（其余依赖画像）→ Doc/Quiz/Code/Media 并行生成。
实现：LangGraph `StateGraph`（`backend/app/agents/orchestrator.py`），SSE 流式事件；
画像感知的 prompt 组装在 `common.py`，输出过滤在 `content_guard.py`。

### 2.3 LLM Wiki 知识中枢（防幻觉）

Wiki 是所有 Agent 的共享知识层（`backend/app/wiki/`），三个子系统：

1. **知识图谱** — 章节→知识点→概念的 DAG 依赖关系（`knowledge_graph.json`）；
2. **RAG 检索** — 向量（BAAI/bge-small-zh-v1.5）+ BM25 混合召回 + 规则 Rerank
   （`rag_engine.py`）；
3. **内容管理** — Agent 生成内容可回写、版本管理。

**多课程知识库**（`backend/knowledge/`，`courses.py` 自动发现注册）：

| 课程 | 目录 | 规模 |
| --- | --- | --- |
| 人工智能导论（AI101） | `ai_intro/` | 13 章，默认课程 |
| 计算机网络 | `计算机网络知识库/` | 全课程 8 章讲解 + 总纲/习题/代码案例/实验/媒体资源/附录，约 160 篇 Markdown |
| 算法设计与分析（ALG101） | `算法设计与分析/` | 10 章 + 五类习题 + 9 个代码案例 + 4 个实验 + PPT/动画/图示 |

**防幻觉三防线**：① 检索锚定（生成只依据检索片段，不足则标注）；② 强制
`[来源：章节>小节]` 引用；③ 输出过滤（`content_guard` 校验来源引用）。
在 remio 侧的落法见 `remio/aapp/eduagent-aapp-spec.md` §2：锚定型端点用
`run_prompt(capabilities="none")` 物理禁止联网，由 `search_notes` + `read_note`
注入知识库正文；E10 答疑以首行 `GROUNDED` / `INSUFFICIENT` 显式上报覆盖度，
升级联网必须显式发生。

### 2.4 三种落地形态

| 形态 | 用途 | 实现 |
| --- | --- | --- |
| 独立 Web 应用 | 完整体验 / 部署佐证 | FastAPI + Next.js，已部署 `https://xwz0219.top` |
| remio aApp/skill | 赛道原生作品 | `remio/aapp/eduagent-aapp-spec.md`（10 端点 E1–E10）+ `manifest.json` |
| MCP 工具集 | 跨智能体产品运行（加分项） | `backend/app/mcp_server.py`（12 工具，stdio JSON-RPC，零新增三方依赖） |

MCP 12 工具：`route_intent` / `search_knowledge` / `extract_profile` /
`generate_document` / `generate_quiz` / `generate_code` / `generate_mindmap` /
`generate_ppt` / `generate_reading` / `generate_animation` / `tutor_answer` /
`list_courses`（完整说明见 `remio/mcp/README.md`）。

### 2.5 界面与交互

遵循「对话为主、UI 为辅」：固定字段/互斥项用 `card`/`list`/`choice`/`input`/`button`/
`image`；解释、协商走对话。原 Web 端的画像雷达图、资源卡片为独立演示口径。

## 三、验收口径

**演示目标**（5 分钟内证明不是单轮问答）：8 维画像 → 10 Agent 协同闭环 → 7 类
个性化资源 → RAG 抗幻觉 → 三形态同引擎运行。动线按 `remio/docs/02_Demo演示脚本.md`
8 屏走，重点记忆点：**并行生成**与**苏格拉底答疑**。

| 检查项 | 预期 |
| --- | --- |
| 流式输出 | 答疑逐字出现，不白屏 |
| 来源引用 | 讲义/答疑末尾带 `[来源：章>节]` |
| 画像生效 | 建档后，后续生成资源难度/表达随画像变化 |
| 多资源 | 一次"复习一句话"能同时出 ≥5 类资源 |
| 多课程 | "换到算法课"后检索与生成切换到对应知识库 |
| 跨产品 | remio 外宿主可调 `generate_quiz` / `list_courses`（MCP） |

评审可任选一句触发语（如"我是计算机大一学生，帮我复习 TCP 三次握手"）走全链路，
或连 `https://xwz0219.top` 独立体验，或注册 MCP 后调 `route_intent` / `generate_quiz` /
`list_courses`。

## 四、创新点

1. 画像贯穿生成（资源因人而异）。
2. 多课程知识中枢（不止一门课，可扩展为课程平台）。
3. 三形态交付（独立 Web + remio 原生 + MCP 跨产品，共用同一引擎）。
4. 知识锚定防幻觉的工程落地（含 remio 平台 `rag` 对 File 笔记失效时的
   `search_notes → read_note` 兜底链路）。
5. Agent 可观测（运行事件记录，`learning_activities`）。
