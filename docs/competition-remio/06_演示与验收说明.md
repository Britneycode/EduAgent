## 1. 演示目标

在 5 分钟内证明本作品不是单轮问答，而是：
- 能识别学生差异并形成 **8 维画像**；
- 能以 **多智能体协同**完成画像→规划→多模态生成→答疑闭环；
- 能生成 **7 类**个性化资源（讲义/题/代码/导图/PPT/拓展阅读/动画）；
- 能基于知识库 **RAG 抗幻觉**（来源引用）；
- 能在 remio 原生 aApp 与 **MCP 跨产品**两种形态运行。

## 2. 演示动线

按 `remio/docs/02_Demo演示脚本.md` 的 8 屏走：痛点 → 画像 → 规划 → 并行生成 → 答疑 →
自动化/MCP → 收束。重点记忆点：**并行生成**与**苏格拉底答疑**两屏。

## 3. 验收检查点

| 检查项 | 预期 |
| --- | --- |
| 流式输出 | 答疑逐字出现，不白屏 |
| 来源引用 | 讲义/答疑末尾带 `[来源：章>节]` |
| 画像生效 | 建档后，后续生成资源难度/表达随画像变化 |
| 多资源 | 一次"复习一句话"能同时出 ≥5 类资源 |
| 跨产品 | remio 外宿主可调 `generate_quiz`（MCP） |

## 4. 异常处理口径

演示前提前验证 LLM 凭证与知识库向量 `count>0`；SSE 中断时 Nginx 已关缓冲并设 1h 超时。
LLM 异常降级到备用模型或正则路由，避免现场卡死。

## 5. 验收方式

评审可任选一句触发语（如"我是计算机大一学生，帮我复习 TCP 三次握手"）走全链路；
或连 `https://xwz0219.top` 独立体验；或注册 MCP 后调 `route_intent`/`generate_quiz`。
