## 为什么改写成 .md 而不是覆盖 .docx

- 环境未装 `python-docx`，无法无损重写 .docx 的表格/样式；
- 金漪湖赛道的提交要求是 **方案文档 + Demo + 演示视频（+决赛路演 PPT）**，已由
  `remio/docs/01–06.md` 承接；本目录保留的是**工程文档附录**，供"完成度/技术难度"佐证；
- Markdown 可直接进 Git 做版本管理，需要 .docx 时 `pandoc xx.md -o xx.docx` 一条命令转换。
