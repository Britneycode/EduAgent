# 02 · 系统开发说明书（金漪湖 · 智能体融合创新赛道版）

## 1. 文档目的

说明 EduAgent 的系统设计、开发实现、多 Agent 协同、remio 落地形态、界面与创新实践。
对应评审「技术实现难度（技术方案复杂度、工具调用深度、系统架构与稳定性）」。

## 2. 系统定位

EduAgent 是面向高校学生的个性化多智能体学习系统，核心流程：

```
学生输入 → 画像理解 → Wiki 检索 → 多 Agent 协作 → 个性化资源 → 测验反馈 → 画像/路径更新
```

一句话：不把大模型用于单轮问答，而是形成「画像—知识组织—资源生成—练习反馈」闭环。

## 3. 多智能体架构

| Agent | 职责 | remio 端点 |
| --- | --- | --- |
| Router | 意图路由 | `route_intent` |
| Profile | 8 维画像 | `build_profile` |
| Planner | 任务拆解 | `plan_learning` |
| Doc | 个性化讲义 | `generate_document` |
| Quiz | 多类型题 | `generate_quiz` |
| Code | Python 实操 | `generate_code` |
| Media | 导图/PPT/动画 | `generate_mindmap`/`generate_ppt`/`generate_animation` |
| Reading | 拓展阅读 | `generate_reading` |
| Tutor | 答疑引导 | `tutor_answer` |

编排规则：Router 先行 → Profile 串行优先 → Doc/Quiz/Code/Media 并行生成。
实现：LangGraph `StateGraph`（`backend/app/agents/orchestrator.py`），SSE 流式事件。

## 4. 知识中枢（防幻觉）

- 知识库：`backend/knowledge/计算机网络知识库/`（全课程结构化 Markdown）。
- 检索：向量 + BM25 混合召回 + 规则 Rerank（`backend/app/wiki/rag_engine.py`）。
- 三防线：`rag` 锚定 → `[来源：章>节]` 引用 → 输出过滤。

## 5. 两种落地形态

| 形态 | 用途 | 实现 |
| --- | --- | --- |
| remio aApp/skill | 赛道原生作品 | `remio/aapp/eduagent-aapp-spec.md` + `manifest.json` |
| MCP 工具集 | 跨智能体产品运行（加分项） | `backend/app/mcp_server.py`（12 工具，零新增依赖） |
| 独立 Web 应用 | Demo / 其他产品运行佐证 | FastAPI + Next.js，已部署 `https://xwz0219.top` |

## 6. 界面与交互

遵循「对话为主、UI 为辅」：固定字段/互斥项用 `card`/`list`/`choice`/`input`/`button`/
`image`；解释、协商走对话。原 Web 端的画像雷达图、资源卡片为独立演示口径。

## 7. 优化与创新

1. 画像贯穿生成（资源因人而异）。
2. 双形态交付（remio 原生 + MCP 跨产品）。
3. 知识锚定防幻觉的工程落地。
4. Agent 可观测（运行事件记录，`learning_activities`）。
