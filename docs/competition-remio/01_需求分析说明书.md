# 01 · 需求分析说明书（金漪湖 · 智能体融合创新赛道版）

> 面向「2026 智能体 OPC 创新大会 · 金漪湖论剑 · 智能体融合创新赛道」。
> 若需要 .docx，可用 pandoc 转换本文件。

## 1. 文档目的

说明 EduAgent 作为参赛作品的需求来源、目标用户、学习痛点、典型场景、功能与非功能
需求。本版重点回应赛道核心命题：**用「多智能体融合」解决真实场景问题**，对应评审
维度「完成度 / 可用性 / 赛道契合度 / 场景理解深度」。

## 2. 需求研究方法与证据边界

采用「赛道文本分析 + 权威公开资料 + 工程原型验证 + 后续一手调研」方式。不虚构
问卷样本量、访谈人数或统计比例；已有结论标注证据类型与适用边界。

## 3. 目标用户与痛点

| 用户 | 典型痛点 | 场景 |
| --- | --- | --- |
| 大一/大二学生 | 基础不牢，公共课"跟不上" | 考前复习、查漏补缺 |
| 备考学生 | 千人一面，资料不对口 | 考研/期末针对性刷题 |
| 薄弱点修复者 | 知道不会，但没人引导 | 就一个知识点反复问 |

核心命题浓缩：**同一份讲义、同一套题**是效率最大的浪费；个性化需要一个"闭环"
（画像→规划→多模态产出→答疑），单一问答 AI 完成不了这个闭环。

## 4. 功能需求（与多 Agent 映射）

| 功能 | 对应 Agent | 说明 |
| --- | --- | --- |
| 学习意图识别 | Router | 输入后最先路由 |
| 8 维学生画像 | Profile | 专业/年级/基础/目标/编程水平/认知风格/时长/偏好 |
| 资源规划 | Planner | 拆解并并行编排 |
| 讲义 / 题目 / 代码 / 导图 / PPT / 拓展阅读 | Doc/Quiz/Code/Media/Reading | 多模态资源 |
| 苏格拉底式答疑 | Tutor | 流式 + 引导 |
| 知识锚定 | Wiki RAG | 防幻觉三防线 |

## 5. 非功能需求

- **可用性**：对话为主、UI 为辅，主路径 3 步内见效。
- **稳定性**：LLM 失败可降级（正则路由 / 备用模型），SSE 流式不白屏。
- **合规**：开源协议与 AI 工具标注见 `05`。
- **跨产品**：MCP 工具集可在其他智能体宿主调用（`backend/app/mcp_server.py`）。

## 6. 技术—需求结合点

把「多 Agent」落到"个性化"这个可感知价值上：画像贯穿每个生成端点，让同一知识点
对不同学生产出不同难度/节奏/表达的资源——这是作品的技术创新点与赛道契合点。
