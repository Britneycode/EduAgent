# 03 · 测试说明书（金漪湖 · 智能体融合创新赛道版）

> 由 `docs/competition/03_测试说明书.docx`（讯飞口径）改写，切换为金漪湖 remio 赛道口径。

## 1. 文档目的

说明 EduAgent 的测试目标、范围、自动评测、手工验收与已知风险，支撑「完成度」
「可用性」与「稳定性」。本版增加 MCP 工具集与 remio 端点的验证维度。

## 2. 测试范围

| 范围 | 覆盖内容 |
| --- | --- |
| 路由 | 答疑 / 全量资料 / 纯出题 / 画像建档 四类意图判定 |
| Agent 生成 | 讲义/题/代码/导图/PPT/拓展阅读/动画 七类资源 |
| 知识中枢 | 混合检索命中率、来源引用、防幻觉过滤 |
| 流式 | SSE 逐字输出、心跳、异常降级 |
| MCP | 12 工具 schema、`tools/list`、`tools/call`、自检 |
| 部署 | 健康检查、向量库导入、持久化 |

## 3. 已验证项（现状）

| 项 | 证据 |
| --- | --- |
| MCP 自检 | `uv run python -m app.mcp_server --self-test` 通过（12 工具 + 4 组路由） |
| 路由正则 | 答疑/全量/纯出题/建档 四类判定正确 |
| 部署 | 已部署 `https://xwz0219.top`（HTTPS + 健康检查） |

## 4. 手工验收用例

| 输入 | 预期 |
| --- | --- |
| "什么是TCP三次握手" | 走答疑，流式 + 来源卡 |
| "帮我整理子网划分的笔记" | 出画像(可缺省) → 讲义+题+代码+导图 |
| "给我出几道HTTP练习题" | 只出题，`choice` 可判分 |
| "我是计算机大一学生" | 出画像确认卡，写入画像 note |

## 5. 自动评测建议

对 `route_intent` 用带标签样本集测路由准确率（LLM 路由 + 正则回退两条路径分别测）；
对 `search_knowledge` 用 `docs` 知识库内的 `RAG检索测试集` 测 top-k 命中与来源完整度。

## 6. 已知风险

- remio aapp-studio 落地需在客户端内真机联调（外部依赖）。
- LLM 免费额度并发受限：默认 `resource_concurrency=2`，生成较慢时属预期降级。
- 视频搜索依赖 Tavily 联网，未配置则 VideoAgent 不可用（非核心路径）。
