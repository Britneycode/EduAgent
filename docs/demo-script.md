# EduAgent 稳定演示脚本

> 更新时间：2026-05-02
> 对应样例数据：`backend/knowledge/ai_intro/demo_scenario.json`

本文档用于 10 分钟路演或答辩演示，目标是稳定跑通“注册登录 -> 画像 -> 资源 -> 测验 -> 路径 -> 评估仪表盘”的完整闭环。

## 演示前检查

1. 后端依赖和迁移：

```bash
cd backend
uv sync
uv run alembic upgrade head
```

2. 后端启动：

```bash
cd backend
uv run uvicorn app.main:app --reload --port 8000
```

3. 前端启动：

```bash
cd frontend
pnpm install
pnpm dev
```

4. 浏览器打开：

```text
http://localhost:3000
```

5. 快速健康检查：

```text
http://localhost:8000/health
```

演示优先使用真实讯飞星火凭证。若现场网络或凭证不可用，可临时启用 `SPARK_DEV_MODE=true` 完成页面和闭环展示，但需要说明此时 LLM 输出是开发模式模拟内容。

## 10 分钟流程

| 时间 | 页面 | 操作 | 讲解重点 |
|---:|---|---|---|
| 0:00-1:00 | `/register` 或 `/login` | 注册或登录演示账号 | 系统具备独立用户、会话和学习数据 |
| 1:00-2:00 | `/chat` | 输入画像提示词 | 系统从自然语言抽取专业、年级、基础、风格、节奏和学习时间 |
| 2:00-4:30 | `/chat` | 输入资源生成提示词 | Router/Profile/Planner/Doc/Quiz/Code/Media/Tutor 多 Agent 协作，资源卡并行生成 |
| 4:30-5:30 | `/chat` | 提交练习题答案，故意答错链式法则判断题 | 错题进入复习队列，测验反馈驱动后续路径 |
| 5:30-6:30 | `/path` | 创建或查看课程学习路径 | 路径基于 `ai_intro` 课程模板和知识图谱展开 |
| 6:30-7:30 | `/analytics` | 查看学习仪表盘和 Agent 可观测面板 | 展示学习时长、测验、错题复习、Agent 耗时和状态 |
| 7:30-8:30 | `/wiki` | 搜索“反向传播 链式法则 梯度” | 展示 RAG 命中、来源片段、课程级知识隔离 |
| 8:30-9:30 | `/profile` | 查看画像确认结果和变化轨迹 | 展示 Agent 候选更新经学生确认后写入画像 |
| 9:30-10:00 | `/chat` | 输入辅导模式追问 | Tutor 以分步提示解释为什么从输出层往前计算 |

## 固定输入

### 画像提示词

```text
我是计算机专业大三学生，机器学习基础一般，数学里的链式法则有点薄弱，每周大概能学6小时，想用图文结合的方式复习深度学习。
```

预期结果：

- 画像页出现“计算机专业”“大三”
- 聊天页出现 Agent 画像更新建议，点击确认后再写入画像
- 学习目标接近“复习”
- 认知风格接近“图文结合”
- 每周学习时间为 6 小时
- 机器学习或链式法则被识别为一般/薄弱

### 资源生成提示词

```text
请围绕人工智能导论里的反向传播算法，给我生成一套复习资料：先讲清楚直觉和链式法则，再给练习题、代码例子、思维导图和PPT。
```

预期结果：

- 聊天页出现流式状态和 Agent 状态
- 至少出现讲义、练习题、代码、思维导图或 PPT 等资源卡
- 资源卡带可信引用或低置信提示
- 若启用 TTS，可演示资源朗读；未启用时说明降级行为

### 测验提交口径

样例题和演示答案见 `backend/knowledge/ai_intro/demo_scenario.json`。演示时建议故意答错“链式法则”相关判断题，用于展示错题本和间隔复习。

如果真实 LLM 生成的题目与样例题不同，按页面上的实际选项提交。演示目标是形成“测验 -> 错题 -> 复习队列 -> 路径/仪表盘更新”的链路。

### 学习路径目标

```text
两周内掌握反向传播和损失函数优化
```

创建路径时选择《人工智能导论》。预期路径包含或关联：

- 机器学习基础
- 监督学习与模型评估
- 神经网络与深度学习基础
- 反向传播算法
- 损失函数与优化器

### Wiki 搜索词

```text
反向传播 链式法则 梯度
```

预期结果：

- 命中第 7 章“神经网络与深度学习基础”相关片段
- 结果显示来源标题、章节、片段和相关度
- 可说明所有 Agent 共享 LLM Wiki 作为知识中枢

### 辅导模式追问

```text
我还是不理解反向传播为什么要从输出层往前算，请用辅导模式一步步提示我。
```

预期结果：

- Tutor 不直接抛最终答案，而是先解释目标和已知条件
- 分步提示链式法则、误差传播和参数梯度
- 最后给一个理解检查或小结

## 讲解主线

1. EduAgent 不是单轮问答，而是围绕学习者状态组织学习过程。
2. 画像来自自然语言，不要求学生先填写长表单。
3. 多 Agent 不是展示概念，而是在一次请求中实际完成路由、画像、规划、资源生成、辅导和观测。
4. LLM Wiki 提供课程知识、来源引用和防幻觉约束。
5. 测验结果不是孤立分数，会进入错题复习、学习路径和仪表盘。
6. 学习画像和 Agent 可观测说明系统能把个人学习过程持续沉淀、解释和优化。

## 异常处理口径

- 星火凭证缺失：说明 `/health` 会提示 LLM 配置问题，开发模式可展示 UI 闭环。
- TTS 未启用：说明朗读接口保留能力边界，未配置时返回不可用。
- 安全护栏未启用：说明系统回退本地规则，真实凭证可启用讯飞审核。
- 资源生成较慢：先展示 SSE 状态和已出现的资源卡，再切到 Wiki/Analytics 讲解系统结构。
- 真实模型题目不同：使用页面实际题目，不强行对齐样例题。
