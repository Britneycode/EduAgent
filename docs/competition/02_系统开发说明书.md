# EduAgent 系统开发说明书

更新时间：2026-06-12

## 1. 文档目的

本文档说明 EduAgent 的系统设计、开发实现、前沿 AI 技术融合、用户界面、系统集成、优化策略和创新实践。文档重点回应比赛要求中的“智能体设计、开发、测试、部署全流程”和“前沿 AI 技术融合应用思路、实现方法、创新实践和用户体验提升策略”。

## 2. 系统定位

EduAgent 是面向高等教育场景的个性化多 Agent 学习系统。系统不把大模型仅用于单轮问答，而是围绕学生画像、知识组织、资源生成、学习路径、练习反馈和 Agent 可观测形成完整学习闭环。

一句话概括：

```text
学生输入 -> 画像理解 -> LLM Wiki 检索 -> 多 Agent 协作 -> 个性化资源 -> 测验反馈 -> 路径和画像更新
```

## 3. 技术栈

| 层级 | 技术 | 用途 |
|---|---|---|
| 前端 | Next.js, React, TypeScript, Tailwind CSS | 页面、交互、多模态资源展示 |
| 后端 | Python 3.12, FastAPI, SQLAlchemy | API 服务、业务逻辑、数据访问 |
| Agent 编排 | LangGraph | 多 Agent 状态图、条件分支、编排 |
| 数据库 | PostgreSQL 或 SQLite | 用户、会话、画像、资源、路径、测验数据 |
| 缓存 | Redis 或内存缓存 | RAG 检索缓存、热点数据缓存 |
| 向量检索 | 本地向量存储或 Chroma HTTP | Wiki RAG 检索 |
| 资产存储 | 本地资产存储，后续可替换 MinIO/S3 | Markdown/PPTX/动画包导出 |
| LLM | 讯飞星火为主，DeepSeek 或 OpenAI 兼容客户端为备用 | 路由、画像、资源生成、辅导 |
| 安全与多模态 | 讯飞安全护栏、讯飞 TTS | 输入输出审核、资源朗读 |

## 4. 总体架构

```text
Frontend (Next.js)
  |-- 聊天页 / 画像页 / 资源中心 / Wiki / 学习路径 / 分析页
  |-- SSE 流式消费、资源卡、Agent 状态、图谱和图表展示
  |
FastAPI Backend
  |-- Auth API / Chat API / Resource API / Wiki API / Learning API / Profile API
  |
Agent Orchestrator (LangGraph)
  |-- Router -> Profile -> Planner -> Doc/Quiz/Code/Media/Video/Tutor -> Finalize
  |
LLM Wiki
  |-- 课程知识图谱 / RAG 混合检索 / 来源片段 / 内容回写 / 课程隔离
  |
Data and Assets
  |-- 用户、会话、画像、资源、路径、测验、错题、Agent 事件、导出资产
```

核心代码位置：

- 后端入口：`backend/app/main.py`
- API：`backend/app/api/`
- Agent：`backend/app/agents/`
- Wiki/RAG：`backend/app/wiki/`
- 数据模型：`backend/app/models/`
- 前端页面：`frontend/src/app/`
- 前端组件：`frontend/src/components/`

## 5. 多 Agent 设计

| Agent | 职责 | 输入 | 输出 |
|---|---|---|---|
| Router Agent | 判断用户意图和任务类型 | 用户消息、会话上下文 | 路由决策 |
| Profile Agent | 抽取学生画像候选更新 | 对话、历史画像、学习反馈 | 待学生确认的 8 维画像更新 |
| Planner Agent | 将复合任务拆解为资源计划 | 用户请求、画像、课程上下文 | Agent 调度计划 |
| Doc Agent | 生成讲义、导图、拓展阅读 | 主题、画像、RAG 来源 | Markdown、Mermaid 等 |
| Quiz Agent | 生成练习题、解析和训练配置 | 主题、难度、画像 | 结构化题目 JSON |
| Code Agent | 生成代码案例 | 主题、画像、实践目标 | 可运行 Python 示例 |
| Media Agent | 生成 PPT、动画分镜、多媒体资源 | 主题、画像、资源计划 | PPT 大纲、动画脚本、可导出资源 |
| Video Agent | 检索相关学习视频 | 主题、课程上下文 | B站相关视频资源卡 |
| Tutor Agent | 提供即时辅导和 Study Mode | 问题、历史对话、画像 | 分步提示、理解检查、解释 |

编排特征：

- 串行阶段：Router、Profile、Planner 先形成任务理解和资源计划。
- 并行阶段：Doc、Quiz、Code、Media、Video 等资源 Agent 可并行或分层执行。
- 条件分支：Tutor 在答疑或 Study Mode 中触发，Video 在配置联网搜索能力后触发。
- 观测记录：Agent 运行事件写入 `agent_run_events`，用于分析页展示耗时、状态、错误和 LLM 调用信息。

## 6. 用户界面设计

UI 设计遵循 `DESIGN.md` 中的教育产品风格规范，并重点服务学习流程而非营销展示。

| 页面 | 功能 | 体验策略 |
|---|---|---|
| 聊天页 | 画像输入、资源生成、Tutor 辅导 | SSE 流式输出、Agent 状态、资源卡、可信引用 |
| 学习画像页 | 8 维画像展示和编辑 | 雷达图、变化轨迹、手动修正 |
| 资源中心 | 管理已生成资源 | 收藏、导出、局部重生成、代码运行、动画包导出 |
| Wiki 页 | 课程知识检索和图谱浏览 | 课程切换、RAG 来源、章节图谱 |
| 学习路径页 | 个性化路径规划 | DAG 依赖图、节点状态、课程隔离 |
| 学习分析页 | 学习效果和 Agent 可观测 | 测验、错题、近期活动、Agent 事件 |

## 7. 核心功能实现

### 7.1 学生画像

系统从自然语言、测验结果和学习行为中抽取画像维度。LLM 结构化抽取失败时，规则兜底保证基础可用性。Agent 抽取结果先作为候选变更展示，学生确认后才写入画像；画像也支持用户主动编辑和历史快照，避免系统长期沿用错误判断。

### 7.2 LLM Wiki 知识中枢

LLM Wiki 承担课程知识组织和防幻觉边界：

- 内置《人工智能导论》和《计算机网络》两门课程。
- 支持课程资料上传、解析、切分、向量化和检索。
- 支持章节树、前置知识、关联知识和知识图谱查询。
- 生成资源带 sources、confidence、来源片段和课程元数据。

### 7.3 多模态资源生成

系统当前支持或阶段支持以下资源：

- 课程讲义和拓展阅读
- 思维导图和 Mermaid 图
- 选择题、判断题、简答题等结构化练习
- Python 代码实操案例和受限沙箱执行
- PPTX 导出
- 动画分镜播放器和动画导出包
- 相关视频资源卡
- TTS 资源朗读

### 7.4 学习路径和效果评估

学习路径由课程知识图谱、画像和学习目标共同驱动。测验结果会进入错题复习和仪表盘，并可推动路径节点状态更新。

### 7.5 Agent 可观测与学习评估

学习分析页用于汇总学生学习时长、测验表现、待复习错题、路径进度和 Agent 运行事件。系统可展示每轮编排中的 Agent 节点、耗时、状态、模型调用和错误信息，帮助学生和评审理解多智能体协作过程。

## 8. 前沿 AI 技术融合

| 技术 | 融合方式 | 价值 |
|---|---|---|
| 讯飞星火 LLM | 作为主力推理与生成模型 | 满足赛事工具要求，支撑对话、画像和资源生成 |
| LangGraph | 编排多 Agent 状态图 | 将复合任务拆解为可观测、可扩展的协作流程 |
| RAG | 生成前检索课程知识 | 降低幻觉，提高教学内容可信度 |
| 知识图谱 | 管理课程章节、知识点和依赖 | 支撑路径规划、前置知识和关联推荐 |
| 讯飞安全护栏 | 可选输入输出审核 | 提升内容安全和合规边界 |
| 讯飞 TTS | 可选资源朗读和动画旁白 | 扩展多模态学习体验 |
| 混合检索与 Rerank | 向量 + BM25 + 轻量重排 | 改善课程知识命中率和来源质量 |

## 10. 优化策略与创新实践

### 10.1 工程优化

- 使用 SSE 避免长时间白屏。
- 将资源生成拆分为文档先行、其他资源并行生成。
- 使用缓存减少重复 RAG 检索开销。
- 记录 Agent 运行事件，便于演示和问题定位。
- 支持资源局部重生成，降低重跑整轮任务的成本。

### 10.2 用户体验优化

- 画像来自自然语言，减少长表单负担。
- 资源以卡片化方式展示，适配文档、题目、代码、导图、PPT 和动画。
- 可信引用面板让学生看到来源和置信度。
- Study Mode 通过分步提示促进理解，而不是直接给最终答案。
- 错题复习和学习路径把一次性问答变成长期学习闭环。

### 10.3 创新点

| 创新点 | 说明 |
|---|---|
| LLM Wiki 知识中枢 | 所有 Agent 共享知识边界，生成内容可引用、可回写、可沉淀 |
| 多 Agent 学习闭环 | 不止生成答案，而是完成画像、资源、练习、路径和反馈联动 |
| 可信生成机制 | RAG、来源片段、低置信提示和内容审核共同约束输出 |
| 可观测 Agent | 学生和评委可看到 Agent 链路、耗时、状态和错误 |
| 学生学习闭环 | 聚焦自主学习、画像确认、资源生成、测验反馈和路径推进 |
