## 4. 项目事实口径

为避免答辩材料和仓库文档不一致，提交时统一采用以下口径：

- 项目定位：EduAgent 是面向高等教育的个性化多 Agent 学习系统，不是单轮问答机器人。
- 核心架构：多 Agent 编排 + LLM Wiki 知识中枢 + 8 维动态学习画像。
- 当前课程：以《人工智能导论》为主课程，并以内置《计算机网络》课程验证多课程模板和课程隔离能力。
- Agent 角色：Router、Profile、Planner、Doc、Quiz、Code、Media、Video、Tutor。
- 资源类型：讲义、思维导图、练习题、代码案例、PPT、动画分镜/动画包、拓展阅读、相关视频。
- 讯飞能力：讯飞星火作为主 LLM；安全护栏和 TTS 可按凭证启用；未启用时有本地规则或不可用提示。
- 当前边界：已支持动画 HTML/字幕/可选 TTS 音频包，完整 MP4/WebM 文件生成、OCR 和生产级对象存储仍为后续增强项。
