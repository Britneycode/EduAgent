# EduAgent 演示与验收说明

更新时间：2026-06-12

## 1. 文档目的

本文档说明 EduAgent 的答辩演示路线、样例数据、页面检查点、讲解重点、异常处理和评审验收方式。稳定演示脚本位于 `docs/demo-script.md`，本文档在其基础上整理为参赛提交说明。

## 2. 演示目标

在 10 分钟内证明 EduAgent 不是单轮问答工具，而是具备以下能力的智能学习系统：

1. 能理解学生差异并形成 8 维画像。
2. 能用 LangGraph 编排多 Agent 协同。
3. 能生成至少 5 类个性化学习资源。
4. 能基于 LLM Wiki、RAG 和知识图谱约束内容。
5. 能把测验结果进入错题、路径和仪表盘。
6. 能展示学习反馈、画像确认和 Agent 可观测。
7. 能展示流式体验、可信引用和 Agent 可观测。

## 5. 10 分钟演示流程

| 时间 | 页面 | 操作 | 讲解重点 |
|---:|---|---|---|
| 0:00-1:00 | `/register` 或 `/login` | 注册或登录演示账号 | 系统具备独立用户、会话和学习数据 |
| 1:00-2:00 | `/chat` | 输入画像提示词 | 自然语言抽取专业、年级、基础、风格、节奏和学习时间 |
| 2:00-4:30 | `/chat` | 输入资源生成提示词 | Router/Profile/Planner/Doc/Quiz/Code/Media/Tutor 多 Agent 协作 |
| 4:30-5:30 | `/chat` | 提交练习题答案，故意答错链式法则判断题 | 错题进入复习队列，测验反馈驱动后续路径 |
| 5:30-6:30 | `/path` | 创建或查看课程学习路径 | 路径基于人工智能导论课程模板和知识图谱 |
| 6:30-7:30 | `/analytics` | 查看学习仪表盘和 Agent 可观测面板 | 展示学习时长、测验、错题复习、Agent 耗时和状态 |
| 7:30-8:30 | `/wiki` | 搜索“反向传播 链式法则 梯度” | 展示 RAG 命中、来源片段、课程级知识隔离 |
| 8:30-9:30 | `/profile` | 查看画像确认结果和变化轨迹 | 展示 Agent 候选画像经学生确认后写入 |
| 9:30-10:00 | `/chat` | 输入辅导模式追问 | Tutor 以分步提示解释为什么从输出层往前计算 |

| 页面 | 检查点 |
|---|---|
| `/chat` | SSE 状态流出现 Router/Profile/Planner/Doc/Quiz/Code/Media/Tutor 等 Agent 状态，资源卡包含可信来源面板 |

| `/resources` | 资源中心能看到已生成资源并支持复用、收藏和导出 |

## 7. 讲解主线

1. EduAgent 不是单轮问答，而是围绕学习者状态组织学习过程。
2. 画像来自自然语言和学习行为，不要求学生先填写长表单。
3. 多 Agent 不是概念展示，而是在一次请求中完成路由、画像、规划、资源生成、辅导和观测。
4. LLM Wiki 提供课程知识、来源引用和防幻觉约束。
5. 测验结果不是孤立分数，会进入错题复习、学习路径和仪表盘。
6. 画像确认、资源中心和 Agent 可观测说明系统能持续沉淀个人学习过程。

## 8. 异常处理口径

| 异常 | 说明口径 |
|---|---|
| 星火凭证缺失 | `/health` 会提示 LLM 配置问题；开发模式可展示 UI 闭环，但需说明 LLM 输出为模拟内容 |
| TTS 未启用 | 朗读接口保留能力边界，未配置时返回不可用 |
| 安全护栏未启用 | 系统回退本地规则，真实凭证可启用讯飞审核 |
| 资源生成较慢 | 先展示 SSE 状态和已出现资源卡，再切到 Wiki/Analytics 讲解系统结构 |
| Tavily 未配置 | 相关视频资源显示不可用提示，不影响核心资源生成 |
