# EduAgent 测试说明书

更新时间：2026-06-12

## 1. 文档目的

本文档说明 EduAgent 的测试目标、测试范围、自动评测、手工验收、演示链路验证、测试结果和已知风险。文档重点支撑比赛提交中的“测试说明书”和“充分的数据与案例支撑”要求。

## 2. 测试范围

| 范围 | 覆盖内容 |
|---|---|
| 后端单元测试 | Agent、服务、核心工具、Wiki、缓存、存储、安全、导出 |
| 后端 API 测试 | Auth、Chat、Resources、Profile、Learning、Wiki |
| 前端组件测试 | Chat、ResourceCard、AgentFlow、LearningPathGraph、AnimationPlayer 等 |
| 自动评测基线 | 画像抽取、路由、RAG 命中、题目结构、内容安全 |
| 手工验收 | 10 分钟演示闭环、页面检查点、异常处理 |
| 非功能验证 | 流式输出、可观测、可信引用、课程隔离、降级提示 |

## 3. 测试环境

| 项目 | 说明 |
|---|---|
| 操作系统 | Windows 开发环境，常规 Linux 环境也可运行 |
| 后端 | Python 3.12, uv, FastAPI |
| 前端 | Node.js, pnpm, Next.js |
| 数据库 | SQLite 可快速运行，PostgreSQL 更接近部署形态 |
| 可选基础设施 | Redis、MinIO、Chroma HTTP |
| 外部凭证 | 讯飞星火、安全护栏、TTS、Tavily 均可按需配置 |

## 6. 手工验收用例

| 编号 | 用例 | 步骤 | 预期结果 |
|---|---|---|---|
| TC-01 | 注册登录 | 访问 `/register` 或 `/login`，创建或登录演示账号 | 进入主页面，用户会话隔离正常 |
| TC-02 | 画像抽取与确认 | 在 `/chat` 输入画像提示词并确认候选更新 | 画像页显示基础、目标、风格、节奏等 |
| TC-03 | 多资源生成 | 输入反向传播资源生成提示词 | 出现 Agent 状态流和多类资源卡 |
| TC-04 | 可信引用 | 查看生成资源卡 | 资源展示来源、相关度、片段或低置信提示 |
| TC-05 | 练习反馈 | 提交练习题并故意答错链式法则判断题 | 错题进入复习队列，仪表盘显示待复习 |
| TC-06 | 学习路径 | 在 `/path` 创建两周学习目标 | 生成包含反向传播、损失函数与优化器等节点的路径 |
| TC-07 | Wiki 检索 | 在 `/wiki` 搜索“反向传播 链式法则 梯度” | 命中人工智能导论 ch07 相关知识片段 |
| TC-08 | 分析仪表盘 | 访问 `/analytics` | 显示学习时长、测验、错题、近期活动和 Agent 可观测 |
| TC-09 | Agent 可观测 | 访问 `/analytics` | 显示 Agent 运行链路、耗时、状态和错误信息 |
| TC-10 | Tutor Study Mode | 在聊天页启用辅导模式提问 | Tutor 分步提示，不直接只给最终答案 |

## 7. 演示链路验收

稳定演示脚本见 `docs/demo-script.md`，样例数据见 `backend/knowledge/ai_intro/demo_scenario.json`。

| 时间 | 页面 | 验收点 |
|---:|---|---|
| 0:00-1:00 | `/register` 或 `/login` | 用户认证和会话隔离 |
| 1:00-2:00 | `/chat` | 画像从自然语言抽取 |
| 2:00-4:30 | `/chat` | 多 Agent 资源卡并行生成 |
| 4:30-5:30 | `/chat` | 测验反馈和错题复习 |
| 5:30-6:30 | `/path` | 基于课程图谱的学习路径 |
| 6:30-7:30 | `/analytics` | 学习仪表盘和 Agent 可观测 |
| 7:30-8:30 | `/wiki` | RAG 命中、来源片段、课程隔离 |
| 8:30-9:30 | `/profile` | 画像确认结果和变化轨迹 |
| 9:30-10:00 | `/chat` | Study Mode 分步辅导 |

## 8. 非功能测试要点

| 项目 | 验证方式 | 预期 |
|---|---|---|
| 流式输出 | 观察聊天页资源生成过程 | 页面逐步显示状态和内容，无长时间白屏 |
| 响应降级 | 缺少 TTS/Tavily/安全护栏凭证时测试 | 返回清晰不可用提示或本地规则兜底 |
| 课程隔离 | 切换人工智能导论和计算机网络 | 检索、章节和路径按课程隔离 |
| 安全过滤 | 输入风险脚本、虚构引用等样例 | 内容安全评测通过，前端有风险提示 |
| 可观测性 | 查看 `/analytics` Agent 面板 | 可看到 Agent 名称、耗时、状态和错误 |
| 资产导出 | 导出 Markdown/PPTX/动画包 | 生成可访问资产 URL 或文件 |

## 9. 已知风险

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 外部 LLM 凭证缺失 | 真实生成不可用 | `/health` 提示状态，演示可启用开发模式但需说明 |
| 联网搜索凭证缺失 | 相关视频资源不可用 | 资源卡显示清晰不可用提示 |
| TTS 凭证缺失 | 资源朗读不可用 | 接口返回不可用状态，不影响核心学习链路 |
| 完整视频文件未生成 | 多模态展示有限 | 当前提供动画包，说明 MP4/WebM 为后续增强 |
| 真实调研数据未回收 | 需求数据支撑不足 | 使用案头研究和可回填模板，提交前可补真实问卷 |
| 生产级对象存储未完全接入 | 大规模文件管理能力有限 | 当前本地资产存储可演示，后续替换 MinIO/S3 |

## 10. 通过标准

参赛前建议满足以下最低标准：

1. `uv run pytest tests/evals -q` 通过。
2. 演示脚本中 10 分钟主链路可跑通。
3. README、参赛文档和 PPT 对课程、Agent、资源类型和能力边界描述一致。
4. 缺少外部凭证时，页面和 `/health` 能给出清晰提示。
5. 开源协议和 AI 工具使用说明位于显著位置。
