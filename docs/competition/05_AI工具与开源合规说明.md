# EduAgent AI 工具与开源合规说明

更新时间：2026-06-12

## 1. 文档目的

本文档说明 EduAgent 使用的 AI 工具、模型边界、AI Coding 辅助说明、开源依赖和合规措施。文档用于回应比赛要求中“若使用开源项目、前沿 AI 工具/框架，需在提交文档显著位置标注名称、来源及相关协议要求”和“开发过程中使用的其他 AI 辅助工具需选用科大讯飞相关工具”。

## 2. 讯飞相关工具

| 工具 | 用途 | 系统集成点 | 状态 |
|---|---|---|---|
| 讯飞星火大模型 | 主力 LLM，负责路由、画像、资源生成和辅导 | `backend/app/core/llm.py`, 各 Agent | 已集成 |
| 讯飞安全护栏 | 输入和输出内容审核 | `backend/app/core/xunfei_safety.py`, Content Guard | 可按凭证启用 |
| 讯飞在线语音合成 TTS | 资源朗读、动画旁白音频 | `backend/app/core/xunfei_tts.py` | 可按凭证启用 |

运行边界：

- 未配置星火凭证且未启用开发模式时，真实聊天生成会失败并提示配置问题。
- 安全护栏未启用时，系统保留本地规则兜底。
- TTS 未启用时，朗读接口返回不可用提示，不影响核心学习链路。
- OCR 当前不是核心链路，后续可作为图片资料导入增强项接入。

## 3. 备用模型和外部能力

| 工具 | 用途 | 边界 |
|---|---|---|
| DeepSeek | 备用 LLM 或容灾模型 | 不作为赛事主模型口径，配置启用后用于兜底 |
| OpenAI 兼容客户端 | 兼容性扩展 | 仅作为可配置补充 |
| Tavily | 检索 B站相关学习视频 | 未配置时相关视频资源返回不可用提示 |
| image2/视觉生成资产 | 答辩 PPT 视觉资产辅助 | 主要用于演示物料，不改变系统核心运行链路 |

## 4. AI Coding 工具说明

项目开发、审查和文档整理过程中使用过 AI 编程辅助工具帮助完成方案梳理、代码审查、文档生成和测试建议。所有 AI 生成或辅助生成内容均需经过人工复核，并以仓库测试、演示脚本和实际运行结果作为最终依据。

说明原则：

1. AI Coding 工具只作为开发效率工具，不替代团队对系统设计、代码质量和文档真实性的责任。
2. 与比赛核心功能相关的 AI 能力口径以讯飞星火、安全护栏和 TTS 为主。
3. 文档中不虚构用户调研数据、测试结果或外部工具能力。
4. 外部服务缺少凭证时，系统通过健康检查和前端提示暴露能力边界。

## 5. 开源依赖声明

完整开源协议清单见仓库根目录 `OPEN_SOURCE_LICENSES.md`。主要依赖包括：

| 类别 | 代表项目 | 协议说明 |
|---|---|---|
| 后端框架 | FastAPI, Uvicorn, SQLAlchemy, Alembic, Pydantic | 详见 `OPEN_SOURCE_LICENSES.md` |
| Agent 和 AI | LangGraph, LangChain 相关组件, Sentence Transformers | 详见 `OPEN_SOURCE_LICENSES.md` |
| 向量检索 | ChromaDB | Apache-2.0 |
| 前端框架 | Next.js, React, TypeScript, Tailwind CSS | 详见 `OPEN_SOURCE_LICENSES.md` |
| 测试工具 | Pytest, Vitest, Testing Library | 详见 `OPEN_SOURCE_LICENSES.md` |
| 包管理工具 | uv, pnpm | 详见 `OPEN_SOURCE_LICENSES.md` |

提交前建议人工核对：

```bash
cd backend
uv tree

cd ../frontend
pnpm list --depth 0
```

## 6. 数据与内容安全

| 风险 | 措施 |
|---|---|
| 生成内容幻觉 | RAG 检索、知识图谱约束、来源片段、低置信提示 |
| 不安全输入或输出 | 本地规则和可选讯飞安全护栏 |
| 代码执行风险 | 受限 Python 沙箱、AST 检查、导入限制、超时控制 |
| 用户数据混淆 | JWT 用户隔离、会话和资源按用户关联 |
| 外部服务不可用 | 健康检查、开发模式、清晰不可用提示 |
| 依赖协议遗漏 | `OPEN_SOURCE_LICENSES.md` 集中维护 |
