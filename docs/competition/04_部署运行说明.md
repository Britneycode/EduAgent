# EduAgent 部署运行说明

更新时间：2026-06-12

## 1. 文档目的

本文档说明 EduAgent 的本地运行、基础设施启动、环境变量配置、健康检查、常见问题和部署边界。文档用于参赛提交和评审复现。

## 2. 环境要求

| 类型 | 要求 |
|---|---|
| 操作系统 | Windows、macOS 或 Linux |
| 后端运行时 | Python 3.12 |
| Python 包管理 | uv |
| 前端运行时 | Node.js + pnpm |
| 可选容器 | Docker / Docker Compose |
| 推荐浏览器 | Chrome、Edge 或其他现代浏览器 |

## 3. 项目结构

```text
EduAgent/
  backend/     后端 FastAPI、Agent、Wiki、数据库模型和测试
  frontend/    前端 Next.js 页面、组件和测试
  docs/        演示脚本、评测说明和参赛文档包
  projects/    答辩 PPT 工程与视觉材料
  docker-compose.yml
  README.md
```

## 4. 基础设施启动

如需使用更接近比赛/部署形态的 PostgreSQL、Redis、MinIO，可运行：

```bash
docker compose up -d
```

停止基础设施：

```bash
docker compose down
```

说明：不启动 Docker 也可使用本地 SQLite 快速开发运行，但数据库一致性和对象存储能力会弱于完整基础设施。

## 5. 后端配置

进入后端目录：

```bash
cd backend
uv sync
```

复制环境变量示例：

```bash
cp .env.example .env
```

Windows PowerShell 可使用：

```powershell
Copy-Item .env.example .env
```

关键环境变量：

| 变量 | 用途 | 是否必需 |
|---|---|---|
| `DATABASE_URL` | 数据库连接，PostgreSQL 或 SQLite | 推荐配置 |
| `JWT_SECRET_KEY` | JWT 签名密钥 | 必需 |
| `SPARK_APP_ID` | 讯飞星火应用 ID | 真实 LLM 必需 |
| `SPARK_API_KEY` | 讯飞星火 API Key | 真实 LLM 必需 |
| `SPARK_API_SECRET` | 讯飞星火 API Secret | 真实 LLM 必需 |
| `SPARK_DEV_MODE` | 开发模式模拟内容 | 演示兜底可用 |
| `XUNFEI_SAFETY_*` | 讯飞安全护栏配置 | 可选 |
| `XUNFEI_TTS_*` | 讯飞 TTS 配置 | 可选 |
| `DEEPSEEK_ENABLED` | 启用 DeepSeek 备用模型 | 可选 |
| `TAVILY_API_KEY` | 相关视频联网检索 | 可选 |
| `WIKI_VECTOR_BACKEND` | 向量后端选择 | 可选 |

## 6. 数据库迁移

```bash
cd backend
uv run alembic upgrade head
```

若使用 SQLite 快速演示，可按 README 中的默认配置运行。若使用 PostgreSQL，需先确认 Docker Compose 中数据库已启动。

## 7. 启动后端

```bash
cd backend
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

健康检查：

```bash
curl http://127.0.0.1:8000/health
```

`/health` 会返回 LLM、向量库、缓存、视频搜索、安全护栏和 TTS 等状态。若 `llm_mode=dev`，表示当前使用开发模式模拟内容，答辩时需要主动说明。

## 8. 启动前端

```bash
cd frontend
pnpm install
pnpm dev
```

默认访问：

```text
http://localhost:3000
```

若 3000 端口被占用，可按 Next.js 输出使用替代端口。

## 9. 推荐演示启动顺序

1. 启动 Docker 基础设施：`docker compose up -d`。
2. 后端执行依赖安装和迁移：`uv sync`、`uv run alembic upgrade head`。
3. 启动后端：`uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000`。
4. 启动前端：`pnpm dev`。
5. 访问 `/health` 确认外部工具状态。
6. 按 `docs/demo-script.md` 跑通 10 分钟演示。

## 10. 常见问题

| 问题 | 可能原因 | 处理方式 |
|---|---|---|
| 登录后跳回登录页 | JWT 配置或前端 token 状态异常 | 检查 `JWT_SECRET_KEY`，清理浏览器本地存储后重试 |
| 聊天真实生成失败 | 未配置星火凭证且未启用开发模式 | 配置星火环境变量，或演示时启用 `SPARK_DEV_MODE=true` |
| 相关视频不可用 | 未配置 `TAVILY_API_KEY` | 保持不可用提示，或配置 Tavily |
| TTS 朗读不可用 | 未配置讯飞 TTS | 配置 TTS 凭证，或说明该能力可选 |
| RAG 检索异常 | 向量库未初始化或 Chroma 服务不可用 | 使用本地向量兜底，或启动 Chroma HTTP 服务 |
| 前端 CORS 报错 | API 地址或后端 CORS 配置不一致 | 检查前端环境变量和后端允许来源 |

## 11. 生产部署建议

当前仓库主要面向参赛演示和开发复现。若进入生产部署，建议补充：

- 独立 PostgreSQL、Redis、MinIO/S3 和 Chroma 服务。
- HTTPS、反向代理、日志采集和进程守护。
- 更细粒度的学习数据权限、资源配额和课程空间管理。
- 密钥托管和环境隔离。
- CI 质量门禁和自动部署流水线。
- 对 LLM 调用成本、限流、缓存命中率和失败率进行监控。
