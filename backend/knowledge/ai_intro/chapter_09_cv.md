# 第9章 计算机视觉基础

## 本章学习目标

完成本章学习后，你应该能够：

1. 了解计算机视觉的主要任务与应用场景
2. 理解图像在计算机中的数字化表示方式（像素、通道、色彩空间）
3. 掌握经典CNN架构（LeNet、VGG、ResNet）的核心设计思想
4. 了解目标检测的基本方法（两阶段与单阶段检测器）
5. 认识图像分割（语义分割、实例分割）的基本概念
6. 理解迁移学习的原理及其在视觉任务中的应用

## 核心概念

- **图像分类（Image Classification）**：给定一张图像，判断它属于哪个预定义类别。
- **目标检测（Object Detection）**：在图像中定位并识别多个目标对象，输出边界框和类别。
- **图像分割（Image Segmentation）**：对图像中的每个像素进行分类，标记其所属的物体或区域。
- **卷积核（Convolutional Kernel/Filter）**：小尺寸的权重矩阵，在图像上滑动进行特征提取。
- **特征图（Feature Map）**：卷积操作的输出，表示输入图像中某种局部模式的响应。
- **感受野（Receptive Field）**：输出特征图上一个像素对应输入图像的区域大小。
- **迁移学习（Transfer Learning）**：将在大规模数据集上预训练的模型迁移到新任务中使用。
- **数据增强（Data Augmentation）**：通过对训练图像进行变换来增加训练数据的多样性。

## 知识讲解

### 9.1 图像的数字化表示

计算机"看到"的图像与人类不同——它看到的是数字矩阵。

**灰度图像：**

- 一个二维矩阵，每个元素是一个0-255的整数，表示亮度
- 0 = 黑色，255 = 白色
- 例如：28×28的手写数字图像 = 28×28的矩阵

**彩色图像（RGB）：**

- 三个二维矩阵叠加（红、绿、蓝三个通道）
- 每个像素由3个值表示：(R, G, B)，每个值0-255
- 例如：224×224的彩色图像 = 224×224×3的张量

**为什么重要：** 理解图像的数值表示是理解所有计算机视觉算法的基础。当你知道图像就是一个数字矩阵时，"卷积核在图像上滑动"就变成了"矩阵在矩阵上做点积"——这就不再神秘了。

**其他色彩空间：**

- HSV（色相-饱和度-明度）：更接近人类对颜色的感知
- RGBA：在RGB基础上增加透明度通道
- 实际上，不同色彩空间适合不同的任务——HSV在颜色过滤中更鲁棒

### 9.2 经典CNN架构演进

CNN的发展史是一部不断突破深度和性能的历史。

**LeNet-5（1998，需人工核验）**

- 最早的CNN架构之一，用于手写数字识别
- 结构：2层卷积 + 2层池化 + 3层全连接
- 参数量：约6万
- 意义：证明了卷积网络在视觉任务上的有效性

**AlexNet（2012）**

- 在ImageNet竞赛中大幅领先传统方法，开启了深度学习革命
- 关键创新：使用ReLU激活函数、Dropout正则化、数据增强、GPU训练
- 参数量：约6000万
- 意义：证明了深度CNN在大规模图像识别上的巨大优势

**VGGNet（2014，需人工核验）**

- 核心思想：使用统一的3×3小卷积核堆叠多层
- 发现：两个3×3卷积的感受野等价于一个5×5卷积，但参数更少、非线性更强
- VGG-16有16层，VGG-19有19层
- 意义：证明了"更深的网络 + 更小的卷积核"是有效的设计原则

**ResNet（2015，需人工核验）**

- 核心创新：残差连接（Skip Connection / Shortcut Connection）
- 问题背景：网络太深时，训练误差反而增加（不是过拟合，是训练困难）
- 解决方案：让网络学习"残差" F(x) = H(x) - x，而非直接学习 H(x)

```
普通层：  x → [权重层] → H(x)
残差层：  x → [权重层] → F(x) + x    （跳跃连接）
```

- ResNet-50/101/152：分别有50/101/152层
- 意义：解决了深层网络的训练困难，使得训练数百层的网络成为可能

**为什么残差连接有效？**

直觉理解：如果某一层不需要做任何变换，残差连接可以让 F(x)=0，输出直接等于输入 x。这相当于"恒等映射"——网络可以轻松学会"跳过"某些层。在没有残差连接的网络中，每一层都必须学到有用的变换，否则就会成为"瓶颈"。

### 9.3 目标检测

目标检测不仅要识别图像中有什么，还要确定它们在哪里。

**核心概念：**

- **边界框（Bounding Box）**：用矩形框定位目标，通常表示为 (x, y, width, height) 或 (x₁, y₁, x₂, y₂)
- **IoU（交并比）**：预测框与真实框的重叠程度，IoU = 交集面积 / 并集面积
- **NMS（非极大值抑制）**：去除冗余的检测框，保留置信度最高的框

**两阶段检测器：**

- 代表：R-CNN系列（R-CNN → Fast R-CNN → Faster R-CNN，需人工核验各版本差异）
- 思路：先生成候选区域（Region Proposals），再对每个区域进行分类
- 优点：精度较高
- 缺点：速度较慢（两步串行）

**单阶段检测器：**

- 代表：YOLO系列、SSD
- 思路：直接在特征图上预测边界框和类别，一步到位
- 优点：速度快，适合实时应用
- 缺点：早期版本精度略低于两阶段方法

**YOLO的核心思想（You Only Look Once）：**

将图像划分为S×S的网格，每个网格单元同时预测边界框位置和类别概率。因为只看一次图像就能完成检测，所以速度极快。

### 9.4 图像分割

图像分割是比目标检测更精细的视觉任务——它要为每个像素打标签。

**语义分割（Semantic Segmentation）：**

- 将图像中的每个像素分类到某个类别（如道路、天空、建筑、行人）
- 不区分同类别的不同实例（两个行人被标记为同一类，但不区分"行人1"和"行人2"）
- 代表方法：FCN（全卷积网络）、U-Net

**实例分割（Instance Segmentation）：**

- 既要分类每个像素，又要区分同类别的不同实例
- "这个人"和"那个人"会被标记为不同的实例
- 代表方法：Mask R-CNN

**全景分割（Panoptic Segmentation）：**

- 语义分割和实例分割的统一——对所有像素进行分类，同时区分实例
- 是目前分割任务的前沿方向

### 9.5 迁移学习

迁移学习是深度学习中最实用的技术之一，特别适合数据有限的场景。

**核心思想：** 在大规模数据集（如ImageNet，含120万张图像、1000个类别）上预训练的模型已经学会了通用的视觉特征（边缘、纹理、形状），可以迁移到新任务中。

**迁移学习的两种策略：**

| 策略 | 做法 | 适用场景 |
|------|------|----------|
| 特征提取 | 冻结预训练模型的所有层，只训练最后的分类器 | 新数据非常少、新任务与原任务相似 |
| 微调（Fine-tuning） | 解冻部分或全部层，用新数据继续训练 | 新数据较多、新任务与原任务差异较大 |

**为什么迁移学习有效？**

CNN的浅层学习通用特征（边缘、颜色），深层学习任务特定特征。浅层特征在不同视觉任务间是通用的，因此可以复用。

**实际建议：** 在大多数实际视觉项目中，不要从零开始训练模型——使用预训练模型（如ImageNet上训练的ResNet）作为起点，通过微调来适配你的任务。这通常能以更少的数据和计算获得更好的性能。

### 9.6 数据增强

数据增强通过对现有训练图像进行随机变换来"创造"新的训练样本。

**常见增强方法：**

| 方法 | 说明 | 目的 |
|------|------|------|
| 随机翻转 | 水平/垂直翻转 | 增加方向多样性 |
| 随机旋转 | 旋转一定角度 | 增加角度多样性 |
| 随机裁剪 | 随机裁剪图像的一部分 | 模拟不同的拍摄距离和位置 |
| 颜色抖动 | 随机调整亮度、对比度、饱和度 | 增加光照变化 |
| 随机遮挡 | 随机遮挡图像的一部分 | 提高模型鲁棒性 |

**为什么重要：** 在数据有限的情况下，数据增强是最简单有效的防过拟合方法之一。它通过增加训练数据的多样性来提高模型的泛化能力。

## 关键公式或算法流程

**卷积操作（2D）：**

```
输出[i,j] = Σₘ Σₙ 输入[i+m, j+n] × 核[m,n] + bias

输出尺寸 = (输入尺寸 - 核大小 + 2×填充) / 步幅 + 1
```

**IoU（交并比）：**

```
IoU = |A ∩ B| / |A ∪ B| = 交集面积 / 并集面积

IoU > 0.5 通常被认为是正确的检测（常用阈值）
```

**残差块（Residual Block）：**

```
y = F(x, {Wᵢ}) + x

其中：
  x = 输入
  F = 需要学习的残差映射（通常2-3层卷积）
  y = 输出
```

```

## 易错点与常见误区

1. **误区：CNN只能处理图像。** CNN也被用于文本分类（TextCNN）、音频处理（一维卷积）、时间序列分析等。卷积操作不限于二维数据。

2. **误区：更深的网络总是比浅的好。** ResNet解决了深度问题，但不意味着无限增加深度就有收益。对于简单任务（如MNIST数字识别），几层的网络就足够了。

3. **误区：迁移学习只适用于图像。** 迁移学习在NLP中同样重要——BERT、GPT都是迁移学习的成功案例。核心思想是通用的：在大数据上学习通用特征，迁移到小数据任务。

4. **误区：数据增强可以替代真实数据。** 数据增强是有用的辅助手段，但不能完全替代多样化的真实数据。过度依赖增强可能导致模型学到不自然的模式。

5. **误区：目标检测和图像分割是一样的。** 目标检测输出边界框（矩形），图像分割输出像素级的分类（精确轮廓）。分割的信息粒度更细。

## 练习题

### 选择题

**1. 一个3×3的卷积核在一个5×5的图像上做步幅为1、无填充的卷积，输出特征图的大小是？**

A. 5×5
B. 3×3
C. 4×4
D. 7×7

> **答案：B**
> 解析：输出尺寸 = (5 - 3 + 0) / 1 + 1 = 3。所以输出是3×3的特征图。

**2. ResNet的核心创新——残差连接，主要解决了什么问题？**

A. 图像分辨率不足
B. 深层网络难以训练的问题
C. 目标检测的速度问题
D. 数据量不足的问题

> **答案：B**
> 解析：残差连接解决了深层网络的退化问题——网络加深后训练误差反而增加。通过跳跃连接，梯度可以直接流过，避免了梯度消失，使得训练非常深的网络成为可能。

**3. 在目标检测中，IoU（交并比）为0.7意味着什么？**

A. 检测框的70%在图像内
B. 预测框与真实框有70%的重叠区域
C. 检测置信度为70%
D. 检测速度为70%

> **答案：B**
> 解析：IoU = 交集面积/并集面积。IoU=0.7意味着预测框与真实框的重叠面积占它们合并面积的70%。IoU越高，检测越准确。

### 判断题

**1. 迁移学习只在新任务的数据量很少时才有用，数据充足时应该从零训练。（ ）**

> **答案：错误**
> 解析：即使用充足的数据，使用预训练模型作为初始化通常也能加速收敛并获得更好的性能。预训练模型学到的通用特征（边缘、纹理）在任何视觉任务中都有用。

**2. VGGNet使用多个3×3小卷积核的堆叠代替大卷积核，这样做没有实际好处，只是为了减少层数。（ ）**

> **答案：错误**
> 解析：使用多个3×3卷积核堆叠有三个好处：(1) 参数更少——两个3×3卷积的参数是2×(3×3)=18，而一个5×5卷积的参数是25；(2) 更多非线性——多加了激活函数，增强了表达能力；(3) 感受野相同——两个3×3卷积的感受野等于一个5×5卷积。

### 简答题

**1. 解释迁移学习的原理，为什么在ImageNet上预训练的模型能帮助解决其他视觉任务？**

> **参考答案：**
> CNN学习的特征具有层级结构：浅层学习通用的视觉特征（边缘、颜色、纹理），中层学习局部形状和部件，深层学习与特定任务相关的高级语义特征。前两层的特征在几乎所有视觉任务中都是通用的——无论你是在识别猫还是在检测肿瘤，边缘和纹理都是基础。因此，在ImageNet上预训练的模型已经学到了这些通用特征，将其迁移到新任务时，模型不需要从零学习这些基础特征，只需要用新数据微调深层的任务特定特征。这大幅减少了对新数据量和训练时间的需求。

**2. 比较两阶段检测器（如Faster R-CNN）和单阶段检测器（如YOLO）的优缺点，它们分别适合什么应用场景？**

> **参考答案：**
> 两阶段检测器（Faster R-CNN）：先生成候选区域再分类，精度高但速度慢。适合对精度要求高、对实时性要求不高的场景，如医学影像分析、卫星图像分析。
> 单阶段检测器（YOLO）：直接在特征图上预测，速度快但早期版本精度略低。适合需要实时处理的场景，如自动驾驶、视频监控、机器人视觉。近年来YOLO的新版本（如YOLOv8）在精度上已经接近两阶段方法。

# 垂直边缘检测器
kernel_v = torch.tensor([
    [-1, 0, 1],
    [-1, 0, 1],
    [-1, 0, 1]
], dtype=torch.float32).unsqueeze(0).unsqueeze(0)

# 应用卷积
conv_h = nn.Conv2d(1, 1, 3, bias=False)
conv_v = nn.Conv2d(1, 1, 3, bias=False)
conv_h.weight.data = kernel_h
conv_v.weight.data = kernel_v

output_h = conv_h(image)
output_v = conv_v(image)

print("原始图像:\n", image.squeeze().numpy())
print("\n水平边缘检测结果:\n", output_h.squeeze().detach().numpy())
print("\n垂直边缘检测结果:\n", output_v.squeeze().detach().numpy())
```

from torchvision import transforms

from PIL import Image

    '随机旋转': transforms.Compose([transforms.RandomRotation(30)]),
    '颜色抖动': transforms.Compose([

    ]),

        transforms.RandomResizedCrop(100, scale=(0.5, 1.0))
    ]),
}

fig, axes = plt.subplots(1, 5, figsize=(20, 4))
for ax, (name, transform) in zip(axes, augmentations.items()):

    ax.imshow(augmented)
    ax.set_title(name)
    ax.axis('off')

plt.suptitle('数据增强效果示例', fontsize=14)
plt.tight_layout()
plt.show()
