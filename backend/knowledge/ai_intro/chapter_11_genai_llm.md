# 第11章 生成式AI与大语言模型

## 本章学习目标

完成本章学习后，你应该能够：

1. 理解生成式AI与判别式AI的本质区别
2. 了解GPT和BERT的基本架构差异及各自的适用场景
3. 理解预训练-微调（Pre-train + Fine-tune）的训练范式
4. 掌握提示工程的基本方法（零样本、少样本、思维链）
5. 了解检索增强生成（RAG）的原理与作用
6. 认识大语言模型的能力边界与局限性（幻觉、偏见等）
7. 了解多模态大模型的基本概念

## 核心概念

- **生成式AI（Generative AI）**：能够生成新内容（文本、图像、音频、代码等）的AI系统。
- **判别式AI（Discriminative AI）**：专注于分类或预测的AI系统，区分不同类别而非生成新内容。
- **大语言模型（Large Language Model, LLM）**：基于Transformer架构、在海量文本上预训练的超大规模语言模型。
- **GPT（Generative Pre-trained Transformer）**：自回归语言模型，通过预测下一个词来生成文本。
- **BERT（Bidirectional Encoder Representations from Transformers）**：双向编码器，通过掩码语言模型理解上下文。
- **预训练（Pre-training）**：在大规模无标注数据上进行通用语言能力的学习。
- **微调（Fine-tuning）**：在特定任务的标注数据上对预训练模型进行适配。
- **提示工程（Prompt Engineering）**：通过设计输入提示来引导大模型生成期望的输出。
- **RAG（Retrieval-Augmented Generation）**：检索增强生成，结合外部知识库来提高生成的准确性和可靠性。
- **幻觉（Hallucination）**：大模型生成看似合理但实际不正确的内容。

## 知识讲解

### 11.1 生成式AI vs 判别式AI

| 特性 | 判别式模型 | 生成式模型 |
|------|-----------|-----------|
| 目标 | 学习 P(y\|x)——给定输入预测标签 | 学习 P(x) 或 P(x\|z)——生成新的数据 |
| 输出 | 类别标签、数值 | 文本、图像、音频等新内容 |
| 典型模型 | 逻辑回归、SVM、分类CNN | GPT、Stable Diffusion、GAN |
| 应用 | 图像分类、垃圾邮件检测 | 文本生成、图像生成、代码生成 |

**直觉理解：** 判别式模型像"考官"——它判断答案对不对；生成式模型像"作家"——它创造新的内容。

**为什么生成式AI引发了AI革命？** 因为它打破了AI只能"分析"的局限，让AI能够"创造"。从ChatGPT写文章到Midjourney画图，生成式AI正在改变内容创作的方式。

### 11.2 GPT与BERT：两种预训练范式

GPT和BERT代表了两种截然不同的预训练思路。

**GPT：自回归（Autoregressive）**

```
训练目标：预测下一个词
输入：  "今天天气"
输出：  "很好" → "，" → "适合" → "出去" → "玩"

特点：
  - 从左到右生成，单向注意力
  - 天然适合文本生成任务
  - 通过"预测下一个token"学习语言知识
```

**BERT：自编码（Autoencoding）**

```
训练目标：预测被遮盖的词
输入：  "今天[MASK]很好"
输出：  "[MASK]" = "天气"

特点：
  - 双向注意力，同时看左右上下文
  - 天然适合理解类任务（分类、问答、NER）
  - 通过"完形填空"学习语言知识
```

**架构对比：**

| 特性 | GPT | BERT |
|------|-----|------|
| 架构 | Transformer解码器 | Transformer编码器 |
| 注意力方向 | 单向（左到右） | 双向 |
| 预训练任务 | 下一个词预测 | 掩码语言模型 |
| 适合任务 | 文本生成、对话 | 文本分类、问答、NER |
| 代表模型 | GPT-4、ChatGPT | BERT、RoBERTa |

**关键洞察：** GPT系列模型之所以成为大语言模型的主流，是因为"预测下一个词"这个看似简单的目标，在足够大的数据和模型规模下，涌现出了惊人的通用能力——理解、推理、编程、翻译等。这就是所谓的"涌现能力"（Emergent Abilities）。

### 11.3 预训练-微调范式

大语言模型的训练通常分为两个阶段：

**阶段一：预训练（Pre-training）**

- 数据：海量无标注文本（互联网文本、书籍、代码等，规模可达数万亿token）
- 目标：学习通用的语言知识和世界知识
- 计算：需要数千个GPU训练数周到数月
- 结果：得到一个"基座模型"（Base Model），具备通用语言能力

**阶段二：微调（Fine-tuning）**

- 数据：特定任务的标注数据（规模通常远小于预训练数据）
- 目标：将通用能力适配到特定任务或对话场景
- 计算：远小于预训练
- 类型：
  - 指令微调（Instruction Tuning）：让模型学会"听指令"
  - RLHF（基于人类反馈的强化学习）：让模型输出更符合人类偏好

**为什么这个范式如此成功？**

1. 预训练阶段从海量数据中学习通用知识——这是数据效率最高的方式
2. 微调阶段用少量数据适配特定任务——大幅降低每个任务的数据需求
3. 一个预训练模型可以微调到无数不同的任务——这就是"迁移学习"的极致体现

### 11.4 提示工程

提示工程是使用大语言模型的关键技术——通过精心设计输入提示来引导模型生成期望的输出。

**基本方法：**

**零样本（Zero-shot）**

```
请将以下英文翻译为中文：
"The weather is nice today."
```
不提供任何示例，直接给出任务指令。

**少样本（Few-shot）**

```
将英文翻译为中文：
英文：Hello → 中文：你好
英文：Thank you → 中文：谢谢
英文：The weather is nice today. → 中文：
```
提供几个示例，让模型"模仿"完成任务。

**思维链（Chain-of-Thought, CoT）**

```
问题：一个商店有15个苹果，卖掉了8个，又进了12个，现在有多少个？

让我们一步一步思考：
1. 初始苹果数量：15个
2. 卖掉8个后：15 - 8 = 7个
3. 又进了12个：7 + 12 = 19个
答案：19个
```

通过引导模型"展示推理过程"来提高复杂推理任务的准确率。

**为什么提示工程重要？** 同一个模型，在不同的提示下可能给出完全不同质量的回答。好的提示可以让模型表现接近专业水准，差的提示可能让模型完全"跑偏"。

**提示工程的实用技巧：**

| 技巧 | 说明 |
|------|------|
| 明确任务 | "请对以下评论进行情感分析，输出正面/负面" |
| 提供上下文 | "你是一位资深Python开发者，请review这段代码" |
| 指定格式 | "请用JSON格式输出，包含name和score字段" |
| 分步骤引导 | "首先分析问题，然后给出解决方案，最后总结" |
| 给出示例 | 提供1-3个输入输出示例 |
| 设定约束 | "回答不超过200字""只使用以下术语" |

### 11.5 检索增强生成（RAG）

大语言模型虽然知识丰富，但有两个关键问题：(1) 知识有截止日期，不知道最新信息；(2) 可能"编造"事实（幻觉）。RAG是解决这两个问题的重要方法。

**RAG的基本流程：**

```
用户提问
  ↓
① 检索：在知识库中搜索与问题相关的文档片段
  ↓
② 增强：将检索到的文档片段作为上下文，与问题一起组成提示
  ↓
③ 生成：大模型基于增强后的提示生成回答

示例：
  问题："公司的年假政策是什么？"
  检索结果：[找到公司HR手册中关于年假的段落]
  增强提示："根据以下文档回答问题：[年假政策段落]。问题：公司的年假政策是什么？"
  生成回答：基于检索到的政策文档回答
```

**RAG的核心组件：**

| 组件 | 说明 |
|------|------|
| 文档处理 | 将文档切分为适合检索的小段落（Chunking） |
| 向量化 | 将文本转换为向量表示（Embedding） |
| 向量数据库 | 存储和检索向量（如FAISS、Pinecone） |
| 检索策略 | 相似度搜索、混合检索等 |
| 生成模型 | 基于检索结果生成回答的大模型 |

**为什么RAG重要？**

- 减少幻觉：回答基于检索到的真实文档，而非模型的"记忆"
- 知识可更新：只需更新知识库，无需重新训练模型
- 可追溯：可以指出回答来源于哪份文档
- 企业级应用的基础：私有知识库问答、文档分析

### 11.6 大模型的能力边界与局限性

**幻觉（Hallucination）**

大模型会生成看似合理但实际不正确的内容。这是因为它本质上是在做"概率预测"，而非"知识检索"——它倾向于生成"看起来合理"的文本，而不保证事实正确。

**幻觉的类型：**
- 事实性幻觉：编造不存在的论文、引用、数据
- 逻辑幻觉：推理过程中出现错误
- 忠实性幻觉：回答偏离了输入文档的内容

**其他局限性：**

| 局限性 | 说明 |
|--------|------|
| 知识截止 | 只知道训练数据截止日期之前的信息 |
| 上下文窗口限制 | 能处理的文本长度有限（尽管不断扩大） |
| 推理能力有限 | 在复杂数学推理和逻辑推理上仍有不足 |
| 偏见 | 训练数据中的偏见会被模型学习和放大 |
| 计算成本 | 训练和推理都需要大量计算资源 |
| 安全风险 | 可能被诱导生成有害内容 |

### 11.7 多模态大模型

多模态大模型能够同时处理和生成多种类型的数据（文本、图像、音频、视频等）。

**代表模型：**

- GPT-4V/GPT-4o：能理解图像和文本，生成文本
- Gemini：Google的原生多模态模型
- Claude：Anthropic的多模态模型

**多模态能力的意义：**

- 用户可以用图片提问："这张图片中的植物是什么？"
- 模型可以理解图表和文档中的视觉信息
- 可以实现更自然的人机交互

## 关键公式或算法流程

**自回归语言模型的训练目标：**

```
最大化：Σₜ log P(wₜ | w₁, w₂, ..., wₜ₋₁)

即最大化序列中每个词在给定前面所有词的条件下的对数概率
```

**RLHF（基于人类反馈的强化学习）流程：**

```
① 收集人类偏好数据：对同一问题的多个回答，人类标注哪个更好
② 训练奖励模型：学习预测人类的偏好分数
③ 强化学习优化：使用PPO算法，以奖励模型的分数为信号优化语言模型
```

**RAG检索的相似度计算（余弦相似度）：**

```
similarity(A, B) = (A · B) / (||A|| × ||B||)

其中A和B是文本的向量表示
```

## 示例

**示例：GPT的"预测下一个词"过程**

```
输入提示："人工智能的三大支柱是"
  ↓
模型计算每个可能的下一个词的概率：
  "数据" → 35%
  "算法" → 30%
  "算力" → 25%
  其他 → 10%
  ↓
采样选择："数据"
  ↓
输入变为："人工智能的三大支柱是数据"
  ↓
继续预测下一个词...
  ↓
最终生成："人工智能的三大支柱是数据、算法和算力"
```

## 易错点与常见误区

1. **误区：大模型"理解"了语言。** 大模型是在做极其复杂的模式匹配和概率预测，它是否真正"理解"仍有争议。它可能"知道"很多事实，但也可能自信地编造不存在的内容。

2. **误区：提示工程就是"写好问题"。** 提示工程远不止于此——它涉及角色设定、格式约束、示例提供、推理引导等多个维度，是一门需要实践的技艺。

3. **误区：RAG可以完全消除幻觉。** RAG能显著减少幻觉，但不能完全消除——模型仍可能误解检索到的内容，或在推理过程中出错。

4. **误区：更大的模型总是更好。** 模型越大能力越强，但也越贵、越慢。对于特定任务，经过精心微调的小模型可能比通用大模型更高效。选择模型需要在性能、成本和延迟之间权衡。

5. **误区：BERT和GPT是竞争关系。** 它们解决不同的问题：BERT擅长理解（分类、提取），GPT擅长生成。在实际应用中，应根据任务选择合适的模型。

## 练习题

### 选择题

**1. 以下哪个是GPT模型的预训练任务？**

A. 掩码语言模型（预测被遮盖的词）
B. 下一个词预测（自回归生成）
C. 句子相似度判断
D. 文本分类

> **答案：B**
> 解析：GPT是自回归模型，训练目标是预测序列中的下一个词。A是BERT的预训练任务。C和D是下游任务，不是预训练任务。

**2. RAG技术的核心目的是什么？**

A. 让模型参数更小
B. 让模型训练更快
C. 让模型生成更准确、有据可查的回答
D. 让模型能处理更长的文本

> **答案：C**
> 解析：RAG的核心目的是通过检索外部知识库来增强模型的生成质量，减少幻觉，让回答基于真实文档。虽然RAG也有助于处理最新信息（知识库可更新），但主要目的是提高准确性和可靠性。

**3. 在提示工程中，"思维链"（Chain-of-Thought）提示的主要作用是？**

A. 让模型回答更简短
B. 让模型展示推理过程，提高复杂推理任务的准确率
C. 让模型生成更长的文本
D. 让模型忽略不相关信息

> **答案：B**
> 解析：思维链通过引导模型"一步步思考"来提高推理任务的准确率。研究表明，在数学推理和逻辑推理任务上，思维链提示可以显著提升模型表现。

### 判断题

**1. 大语言模型的训练数据截止后，它就无法获取任何新信息了。（ ）**

> **答案：错误（基本正确但不完全准确）**
> 解析：纯模型本身确实不知道截止日期后的信息。但通过RAG技术，模型可以检索和利用最新的知识库内容。此外，也可以通过微调或持续训练来更新模型知识。所以说"完全无法获取"是不准确的。

**2. 提示工程中，给模型设定一个角色（如"你是一位资深医生"）对模型的输出质量没有影响。（ ）**

> **答案：错误**
> 解析：角色设定（Role Prompting）对模型输出有显著影响。设定了角色后，模型会倾向于使用该角色领域的专业术语、知识和语气。例如设定"资深医生"角色后，模型的回答会更专业、更谨慎。

### 简答题

**1. 比较GPT和BERT在架构、预训练任务和适用场景上的区别。**

> **参考答案：**
> 架构：GPT使用Transformer解码器（单向注意力，只能看到左边的词），BERT使用Transformer编码器（双向注意力，同时看左右两边）。
> 预训练任务：GPT的预训练任务是"下一个词预测"——从左到右生成文本；BERT的预训练任务是"掩码语言模型"——随机遮盖一些词，让模型根据上下文预测被遮盖的词。
> 适用场景：GPT天然适合生成任务（文本生成、对话、代码生成），BERT天然适合理解任务（文本分类、问答、命名实体识别）。现代大语言模型主要沿GPT路线发展，因为生成能力更具通用性。

**2. 解释RAG如何减少大语言模型的"幻觉"问题。**

> **参考答案：**
> 幻觉的本质是模型基于"概率"生成内容，而非基于"事实"。RAG通过以下方式减少幻觉：(1) 在回答前先检索相关的真实文档，为模型提供事实依据；(2) 在提示中明确要求"根据以下文档回答"，约束模型的回答范围；(3) 生成的回答可以追溯到具体的源文档，便于验证。但RAG不能完全消除幻觉——模型仍可能误解检索内容或在推理中出错。

### 实践题

**1. 使用OpenAI API或类似的大模型API，设计一个简单的问答系统。要求：(a) 使用零样本提示；(b) 使用少样本提示；(c) 使用思维链提示。比较三种方式在同一组问题上的回答质量。**

> **提示：** 准备5-10个涵盖不同难度的问题（事实性问题、推理问题、创意问题），分别用三种提示方式测试，记录并比较结果。

# 实验1：使用transformers库加载BERT并进行文本分类

from transformers import BertTokenizer, BertForSequenceClassification
import torch

# 加载预训练的BERT模型和分词器
tokenizer = BertTokenizer.from_pretrained('bert-base-chinese')
model = BertForSequenceClassification.from_pretrained('bert-base-chinese', num_labels=2)

# 编码输入文本
text = "这部电影真的很好看，强烈推荐！"
inputs = tokenizer(text, return_tensors='pt', padding=True, truncation=True)

# 前向传播
with torch.no_grad():
    outputs = model(**inputs)
    logits = outputs.logits
    prediction = torch.argmax(logits, dim=-1)

print(f"输入: {text}")
print(f"预测标签: {'正面' if prediction.item() == 1 else '负面'}")
print(f"原始logits: {logits}")
```

# 实验2：实现简单的文本嵌入与相似度搜索（RAG的核心步骤）

import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# 模拟知识库文档
documents = [
    "人工智能是计算机科学的一个分支，致力于创建能模拟人类智能的系统。",
    "机器学习是人工智能的核心技术，让计算机从数据中自动学习规律。",
    "深度学习使用多层神经网络来学习数据的高层特征表示。",
    "自然语言处理让计算机能够理解和生成人类语言。",
    "计算机视觉让机器能够理解和分析图像和视频内容。",
    "强化学习通过与环境交互来学习最优决策策略。",
    "Python是一种广泛使用的编程语言，特别适合数据科学和AI开发。",
    "张量是深度学习中的基本数据结构，类似于多维数组。",
]

# 创建TF-IDF向量化器（实际RAG中通常使用BERT等模型的嵌入）
vectorizer = TfidfVectorizer()
doc_vectors = vectorizer.fit_transform(documents)

def search(query, top_k=3):
    """简单的语义搜索"""
    query_vector = vectorizer.transform([query])
    similarities = cosine_similarity(query_vector, doc_vectors).flatten()
    top_indices = similarities.argsort()[-top_k:][::-1]
    
    results = []
    for idx in top_indices:
        results.append({
            'document': documents[idx],
            'similarity': similarities[idx]
        })
    return results

# 测试检索
query = "什么是深度学习？"
results = search(query)
print(f"查询: {query}\n")
print("检索结果:")
for i, r in enumerate(results, 1):
    print(f"  {i}. [相似度: {r['similarity']:.4f}] {r['document']}")

# 模拟RAG：将检索结果作为上下文
context = "\n".join([r['document'] for r in results])
rag_prompt = f"""根据以下参考信息回答问题。如果参考信息中没有相关内容，请说明。

参考信息：
{context}

问题：{query}
回答："""

print(f"\n--- RAG提示 ---")
print(rag_prompt)
```
