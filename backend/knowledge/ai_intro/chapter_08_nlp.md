# 第8章 自然语言处理基础

## 本章学习目标

完成本章学习后，你应该能够：

1. 了解自然语言处理的主要任务与应用场景
2. 掌握文本预处理的基本流程（分词、去停用词、词干化）
3. 理解词袋模型和TF-IDF的原理与局限性
4. 了解词嵌入（Word2Vec）的基本思想，理解"语义空间"的概念
5. 认识循环神经网络（RNN）处理序列数据的基本原理
6. 理解Transformer架构中自注意力机制的核心思想
7. 了解NLP典型任务：情感分析、文本分类、机器翻译、问答系统

## 核心概念

- **自然语言处理（NLP）**：让计算机理解、生成和处理人类自然语言的技术。
- **分词（Tokenization）**：将连续文本切分为独立的词或子词单元。
- **停用词（Stop Words）**：高频但信息量低的词（如"的""了""是"），通常在预处理中被移除。
- **词袋模型（Bag of Words, BoW）**：将文本表示为词的集合（忽略顺序），用词频向量表示。
- **TF-IDF**：一种统计方法，衡量一个词对文档的重要程度。
- **词嵌入（Word Embedding）**：将词映射为低维稠密向量，使语义相近的词在向量空间中距离相近。
- **循环神经网络（RNN）**：专门处理序列数据的神经网络，具有"记忆"能力。
- **Transformer**：基于自注意力机制的架构，是现代NLP的基础（GPT、BERT的核心）。
- **自注意力（Self-Attention）**：让序列中的每个位置都能"关注"到序列中所有其他位置的机制。

## 知识讲解

### 8.1 NLP的主要挑战

自然语言处理是AI中最困难的任务之一，因为自然语言具有以下特点：

| 挑战 | 说明 | 示例 |
|------|------|------|
| 歧义性 | 同一个词或句子有多种含义 | "他在银行工作"——金融机构还是河岸？ |
| 多样性 | 同一个意思可以有无数种表达 | "很开心"/"高兴极了"/"乐坏了" |
| 依赖上下文 | 词义依赖于语境 | "苹果很好吃" vs "苹果发布了新手机" |
| 世界知识 | 理解语言需要常识 | "他穿着泳衣走进了……" 海滩？办公室？ |
| 隐含意义 | 字面意思 ≠ 真实意思 | "这个方案真是'好'啊"（反讽） |

### 8.2 文本预处理流程

在将文本输入模型之前，需要进行一系列预处理步骤。

**标准流程：**

```
原始文本 → 分词 → 去停用词 → 词干化/词形还原 → 数值化
```

**分词（Tokenization）**

- 英文：按空格和标点分割，相对简单
- 中文：词之间没有空格，需要专门的分词工具（如jieba、pkuseg）
- 中文分词的难点："南京市长江大桥"——"南京市/长江大桥"还是"南京/市长/江大桥"？

**去停用词（Stop Word Removal）**

- 移除"的""了""是""the""is""a"等高频但信息量低的词
- 目的：减少噪声，降低特征维度
- 注意：并非所有任务都适合去停用词——情感分析中"不"是停用词但对情感极性至关重要

**词干化与词形还原**

- 词干化（Stemming）：粗略地去除词缀，如 "running" → "run"
- 词形还原（Lemmatization）：基于词典的精确还原，如 "better" → "good"
- 中文通常不需要这一步

### 8.3 文本表示方法

计算机无法直接处理文字，需要将文本转换为数值向量。

**词袋模型（Bag of Words）**

最简单的文本表示方法——将文本看作词的"袋子"（忽略顺序）。

```
文档1："我喜欢机器学习"
文档2："我喜欢深度学习"

词表：[我, 喜欢, 机器, 学习, 深度]

文档1的向量：[1, 1, 1, 1, 0]
文档2的向量：[1, 1, 0, 1, 1]
```

- 优点：简单、直观
- 缺点：忽略词序（"狗咬人"和"人咬狗"表示相同）、向量稀疏（维度=词表大小，通常数万维）、无法表示语义相似性

**TF-IDF（词频-逆文档频率）**

改进词袋模型——不仅看词频，还要考虑词的"信息量"。

```
TF(t, d) = 词t在文档d中出现的次数 / 文档d的总词数
IDF(t) = log(总文档数 / 包含词t的文档数)
TF-IDF(t, d) = TF(t, d) × IDF(t)
```

**直觉理解：** 一个词在当前文档中出现越多（TF高），且在整个语料库中出现越少（IDF高），它对当前文档越重要。例如，"机器学习"在一篇AI论文中TF-IDF很高，而"的"因为出现在几乎所有文档中，IDF很低。

### 8.4 词嵌入（Word Embedding）

词袋模型和TF-IDF产生的向量是高维稀疏的，且无法表示语义关系。词嵌入解决了这个问题。

**核心思想：** 将每个词映射到一个低维（如100-300维）的稠密向量，使得语义相近的词在向量空间中距离也相近。

**Word2Vec（Mikolov等，2013，需人工核验具体年份）**

Word2Vec有两种训练方式：

- **CBOW（连续词袋）**：用上下文词预测中心词。例如，给定"我 ___ 机器学习"，预测中间的词是"喜欢"。
- **Skip-gram**：用中心词预测上下文词。例如，给定"喜欢"，预测它周围可能出现的词。

**词嵌入的神奇特性：**

```
vec("国王") - vec("男人") + vec("女人") ≈ vec("女王")
vec("巴黎") - vec("法国") + vec("中国") ≈ vec("北京")
```

这些向量运算可以捕捉语义关系（性别、国家-首都等），说明词嵌入确实学到了有意义的语义表示。

**为什么重要：** 词嵌入是现代NLP的基石。从Word2Vec到后来的GloVe、ELMo、BERT，核心思想一脉相承——用向量表示语义。

### 8.5 循环神经网络（RNN）

文本是序列数据，词的顺序很重要。RNN专门设计来处理序列。

**RNN的核心思想：**

在处理序列的每一步，RNN不仅接收当前输入，还接收上一步的"隐藏状态"（记忆）。

```
hₜ = tanh(Wₓₓ xₜ + Wₕₕ hₜ₋₁ + b)
yₜ = Wᵧₕ hₜ + bᵧ

其中：
  xₜ = 第t步的输入（如第t个词的词嵌入）
  hₜ = 第t步的隐藏状态（"记忆"）
  hₜ₋₁ = 上一步的隐藏状态
```

**RNN的问题：**

- **短期记忆**：标准RNN难以捕捉长距离依赖。例如，在一段很长的文本中，RNN可能"忘记"开头提到的主语。
- **梯度消失/爆炸**：在反向传播时，梯度需要沿时间步逐层传递，经过多次相乘后可能消失或爆炸。

**LSTM和GRU：**

为解决上述问题，研究者提出了LSTM（长短期记忆网络）和GRU（门控循环单元），通过"门"机制控制信息的保留和遗忘。这些改进使得RNN能更好地处理长序列。

### 8.6 Transformer架构

2017年，论文"Attention Is All You Need"提出了Transformer架构（需人工核验），彻底改变了NLP的格局。

**核心创新：自注意力机制（Self-Attention）**

自注意力让序列中的每个位置都能直接"关注"到所有其他位置，解决了RNN必须逐步处理的瓶颈。

**自注意力的计算过程（简化版）：**

```
对于输入序列的每个词：
  1. 生成三个向量：Query(Q), Key(K), Value(V)
     Q = W_q × 词向量
     K = W_k × 词向量  
     V = W_v × 词向量
  
  2. 计算注意力分数：score = Q × Kᵀ / √d
     （d是向量维度，用于缩放）
  
  3. 归一化：attention_weights = softmax(score)
  
  4. 加权求和：output = attention_weights × V
```

**直觉理解：** 每个词通过Query去"查询"其他词的Key，得到注意力分数，然后用这些分数对Value加权求和。这就像在阅读时，每个词都会"回头看"前面的相关词来理解自己的含义。

**多头注意力（Multi-Head Attention）：**

同时运行多组独立的注意力计算（"头"），让模型能从不同角度关注信息。例如，一个头关注语法关系，另一个头关注语义关系。

**Transformer的其他关键组件：**

- **位置编码（Positional Encoding）**：因为自注意力本身不包含位置信息，需要额外添加位置编码
- **前馈网络（FFN）**：每个注意力层后接一个全连接前馈网络
- **残差连接和层归一化**：帮助训练更深层的网络

**为什么Transformer取代了RNN？**

| 特性 | RNN | Transformer |
|------|-----|-------------|
| 处理方式 | 顺序处理 | 并行处理 |
| 长距离依赖 | 困难（需要LSTM） | 直接建模 |
| 训练效率 | 低（无法并行） | 高（可并行） |
| 信息访问 | 只能访问已处理的部分 | 任意位置互相访问 |

## 关键公式或算法流程

**TF-IDF公式：**

```
TF-IDF(t, d, D) = TF(t, d) × IDF(t, D)

TF(t, d) = count(t in d) / |d|
IDF(t, D) = log(|D| / |{d ∈ D : t ∈ d}|)
```

**Word2Vec Skip-gram目标函数：**

```
最大化：Σₜ Σ₋ₖ≤ⱼ≤ₖ,ⱼ≠₀ log P(wₜ₊ⱼ | wₜ)

P(wₒ|wᵢ) = exp(v'ₒᵀ vᵢ) / Σw exp(v'wᵀ vᵢ)

其中 vᵢ 和 v'ᵢ 分别是词wᵢ的输入向量和输出向量
```

**自注意力计算：**

```
Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V
```

## 示例

**示例：TF-IDF计算**

假设语料库有3个文档：
- 文档1："机器学习是AI的核心"（5个词）
- 文档2："深度学习是机器学习的分支"（7个词）
- 文档3："学习很重要"（3个词）

计算"学习"在文档1中的TF-IDF：
- TF("学习", 文档1) = 1/5 = 0.2
- IDF("学习") = log(3/3) = 0（"学习"出现在所有文档中）
- TF-IDF = 0.2 × 0 = 0

计算"核心"在文档1中的TF-IDF：
- TF("核心", 文档1) = 1/5 = 0.2
- IDF("核心") = log(3/1) ≈ 1.1
- TF-IDF ≈ 0.2 × 1.1 = 0.22

"核心"比"学习"更能代表文档1的内容。

## 易错点与常见误区

1. **误区：分词对所有语言都一样简单。** 英文按空格分词相对简单，但中文、日文、泰文等语言没有天然的词边界，分词本身就是一个NLP难题。

2. **误区：词袋模型完全没用了。** 在某些简单任务（如垃圾邮件检测、简单的文本分类）中，TF-IDF + 逻辑回归仍然是很强的基线，不应忽视。

3. **误区：Word2Vec中每个词只有一个固定的向量。** 标准Word2Vec确实给每个词一个固定向量，无法处理一词多义。后来的ELMo和BERT通过上下文相关的词向量解决了这个问题。

4. **误区：Transformer能处理无限长的序列。** 标准Transformer的自注意力计算量是序列长度的平方（O(n²)），因此处理超长文本仍然有挑战。长文本需要特殊的稀疏注意力或分段处理技术。

5. **误区：RNN完全被Transformer淘汰了。** 在某些资源受限的场景（如嵌入式设备上的语音识别），轻量级RNN（如GRU）仍有优势。

## 练习题

### 选择题

**1. 在TF-IDF中，如果一个词出现在语料库的所有文档中，它的IDF值会怎样？**

A. 非常高
B. 非常低（趋近于0）
C. 等于1
D. 取决于词频

> **答案：B**
> 解析：IDF(t) = log(总文档数 / 包含词t的文档数)。当一个词出现在所有文档中时，IDF = log(N/N) = log(1) = 0。这正是"的""了""是"这类停用词的特征——它们出现在几乎所有文档中，IDF为0，对区分文档没有帮助。

**2. 以下哪个是Transformer相比RNN的核心优势？**

A. 参数量更少
B. 可以并行处理序列中的所有位置
C. 不需要训练数据
D. 只能处理英文文本

> **答案：B**
> 解析：RNN必须按顺序逐步处理序列（第t步依赖第t-1步的输出），无法并行。Transformer的自注意力机制可以同时计算所有位置之间的关系，大幅提高了训练效率。

**3. Word2Vec词嵌入能够捕捉以下哪种语义关系？**

A. 词性的变化
B. 语义类比关系（如"国王:男人 = 女王:女人"）
C. 精确的词义定义
D. 句子的语法结构

> **答案：B**
> 解析：Word2Vec的向量空间中存在有意义的线性关系。"国王-男人+女人≈女王"这个经典例子说明词嵌入能捕捉类比关系。但它不能给出精确定义或解析语法。

### 判断题

**1. 在文本预处理中，去停用词对所有NLP任务都是必要的。（ ）**

> **答案：错误**
> 解析：在某些任务中，停用词可能携带重要信息。例如，在情感分析中，"不"通常被列为停用词，但"不好"中的"不"对情感极性至关重要。在机器翻译中，停用词也需要保留。是否去停用词应根据具体任务决定。

**2. Transformer中的自注意力机制天然包含了词序信息。（ ）**

> **答案：错误**
> 解析：自注意力机制本身对输入的排列顺序是不变的（permutation invariant），即打乱输入顺序不会改变输出。因此Transformer需要额外添加位置编码（Positional Encoding）来注入位置信息。

### 简答题

**1. 比较词袋模型（BoW）和词嵌入（Word Embedding）的主要区别，从向量维度、语义表示能力和稀疏性三个方面分析。**

> **参考答案：**
> (1) 向量维度：BoW的向量维度等于词表大小（通常数万维），词嵌入通常只有100-300维。
> (2) 语义表示能力：BoW无法表示语义相似性（"开心"和"快乐"在BoW中是完全不同的维度），词嵌入能将语义相近的词映射到相近的向量（"开心"和"快乐"的向量距离很近）。
> (3) 稀疏性：BoW向量是高度稀疏的（大部分维度为0），计算效率低；词嵌入是稠密向量，每个维度都有值，表示更紧凑。

**2. 用通俗的语言解释Transformer的自注意力机制是如何工作的。**

> **参考答案：**
> 自注意力就像一个班级讨论。每个同学（词）都有三个角色：提问者（Query）、信息提供者（Key）和内容贡献者（Value）。当一个同学想理解自己的角色时，他会向所有其他同学提问（Query），每个同学用自己的标签（Key）来回应匹配程度，匹配度高的同学的贡献（Value）被更多采纳。最终，每个同学的"理解"是所有同学贡献的加权平均，权重由匹配程度决定。这样，每个词都能看到整个句子中所有其他词的信息，从而理解上下文。

```python
import jieba
import jieba.analyse

# 示例文本

机器学习是人工智能的核心技术之一，通过让计算机从数据中自动学习规律来实现智能。
深度学习是机器学习的一个子领域，使用多层神经网络来学习数据的高层次特征表示。
自然语言处理是人工智能的重要应用方向，目标是让计算机理解和生成人类语言。
"""

# 分词
words = jieba.lcut(text)
print("分词结果:", words)

# 去停用词
stopwords = {'的', '是', '一个', '和', '了', '在', '它', '来', '让', '从', '中', '通过'}
filtered = [w for w in words if w not in stopwords and len(w) > 1]
print("去停用词后:", filtered)

# TF-IDF关键词提取
keywords = jieba.analyse.extract_tags(text, topK=10, withWeight=True)
print("\nTF-IDF关键词:")
for word, weight in keywords:
    print(f"  {word}: {weight:.4f}")
```

```python
# 实验2：使用sklearn实现TF-IDF文本分类

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

print(f"准确率: {clf.score(X_test, y_test):.2f}")
```

```python
# 实验3：使用Gensim训练Word2Vec并探索词向量

from gensim.models import Word2Vec
import jieba

# 准备训练语料（实际应用中需要更大的语料库）
sentences = [
    "人工智能是计算机科学的重要分支",
    "机器学习是人工智能的核心技术",
    "深度学习是机器学习的子领域",
    "自然语言处理让机器理解语言",
    "计算机视觉让机器理解图像",
    "强化学习让机器学会决策",
]

# 分词
tokenized = [jieba.lcut(s) for s in sentences]

# 训练Word2Vec
model = Word2Vec(tokenized, vector_size=50, window=3, min_count=1, epochs=100)

# 探索词向量
print("'学习'的词向量（前10维）:")
print(model.wv['学习'][:10])

# 查找相似词
if '学习' in model.wv:
    similar = model.wv.most_similar('学习', topn=5)
    print("\n与'学习'最相似的词:")
    for word, score in similar:
        print(f"  {word}: {score:.4f}")
```

```python
# 实验4：实现简单的自注意力计算

import numpy as np

def self_attention(X, W_q, W_k, W_v):
    """
    简单的自注意力计算
    X: 输入矩阵 (seq_len, d_model)
    W_q, W_k, W_v: 投影矩阵
    """
    Q = X @ W_q  # (seq_len, d_k)
    K = X @ W_k
    V = X @ W_v
    
    d_k = Q.shape[1]
    scores = Q @ K.T / np.sqrt(d_k)  # (seq_len, seq_len)
    
    # Softmax
    exp_scores = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
    attention_weights = exp_scores / exp_scores.sum(axis=-1, keepdims=True)
    
    output = attention_weights @ V  # (seq_len, d_v)
    return output, attention_weights

# 示例：4个词，每个词3维
np.random.seed(42)
seq_len, d_model, d_k = 4, 3, 3
X = np.random.randn(seq_len, d_model)
W_q = np.random.randn(d_model, d_k) * 0.1
W_k = np.random.randn(d_model, d_k) * 0.1
W_v = np.random.randn(d_model, d_k) * 0.1

output, weights = self_attention(X, W_q, W_k, W_v)
print("注意力权重矩阵:")
words = ["我", "喜欢", "机器", "学习"]
for i, w in enumerate(words):
    row = [f"{weights[i,j]:.3f}" for j in range(4)]
    print(f"  {w}: {row}")
```
