# 第6章 监督学习与模型评估

## 本章学习目标

完成本章学习后，你应该能够：

1. 掌握线性回归的原理、求解方法和适用场景
2. 理解逻辑回归如何将线性模型应用于分类问题
3. 理解决策树的构建原理（信息增益、基尼指数）
4. 掌握K近邻算法的工作机制和距离度量
5. 掌握交叉验证、混淆矩阵等模型评估方法
6. 理解精确率、召回率、F1分数的含义与适用场景
7. 了解ROC曲线和AUC的概念

## 核心概念

- **线性回归（Linear Regression）**：用线性函数拟合数据，预测连续数值输出。
- **逻辑回归（Logistic Regression）**：在线性回归基础上加入Sigmoid函数，将输出映射到[0,1]区间用于分类。
- **决策树（Decision Tree）**：通过一系列条件判断（"如果…则…"）将数据逐步分类的树状模型。
- **K近邻（KNN）**：基于"近朱者赤"的思想——找到K个最近的邻居，投票决定分类。
- **混淆矩阵（Confusion Matrix）**：展示模型预测结果与真实标签对比情况的矩阵。
- **精确率（Precision）**：预测为正的样本中，真正为正的比例。
- **召回率（Recall）**：真实为正的样本中，被正确预测为正的比例。
- **F1分数**：精确率和召回率的调和平均数。
- **ROC曲线**：以假正率为横轴、真正率为纵轴绘制的模型性能曲线。
- **AUC**：ROC曲线下的面积，衡量模型的整体区分能力。

## 知识讲解

### 6.1 线性回归

线性回归是最基础的监督学习算法，也是理解更复杂算法的起点。

**模型形式：**

```
ŷ = w₁x₁ + w₂x₂ + ... + wₙxₙ + b = wᵀx + b

其中：
  x = [x₁, x₂, ..., xₙ]ᵀ  输入特征向量
  w = [w₁, w₂, ..., wₙ]ᵀ  权重向量（模型参数）
  b                        偏置项
  ŷ                        预测值
```

**训练目标：** 找到使均方误差（MSE）最小的权重w和偏置b。

**求解方法：**

- **正规方程（解析解）**：w = (XᵀX)⁻¹Xᵀy，直接计算最优参数。优点是精确，缺点是当特征维度很高时矩阵求逆的计算量大。
- **梯度下降（迭代解）**：从随机初始值出发，沿损失函数的负梯度方向逐步更新参数。优点是适合大规模数据，缺点是需要选择学习率和迭代次数。

**适用场景：** 预测房价、销售额、温度等连续数值。

**局限性：** 假设特征与输出之间是线性关系。如果实际关系是非线性的，线性回归的表现会很差。

### 6.2 逻辑回归

逻辑回归虽然名字中有"回归"，但实际上是一个分类算法。

**为什么不能直接用线性回归做分类？**

线性回归的输出是连续值（-∞到+∞），而分类需要的是概率（0到1之间）。逻辑回归通过Sigmoid函数解决这个问题。

**Sigmoid函数：**

```
σ(z) = 1 / (1 + e^(-z))

其中 z = wᵀx + b
```

Sigmoid将任意实数映射到(0, 1)区间，输出可以解释为"属于正类的概率"。

**决策规则：**

```
如果 σ(z) ≥ 0.5 → 预测为正类（标签=1）
如果 σ(z) < 0.5 → 预测为负类（标签=0）
```

**训练方法：** 使用交叉熵损失（而非MSE），通过梯度下降优化。

**为什么重要：** 逻辑回归是分类问题的"基准模型"。在工业界，由于其简单、可解释、训练快的特点，常作为第一个尝试的模型。

### 6.3 决策树

决策树是人类最容易理解的机器学习模型之一，因为它的决策过程与人类的思维方式非常接近。

**基本思想：** 通过一系列"问题"将数据逐步细分，直到每个子集足够"纯净"（同一类别）。

**构建过程：**

1. 从所有数据开始
2. 选择"最好"的特征和分裂点（使分裂后的子集最纯净）
3. 在该特征和分裂点处分裂数据
4. 对每个子集递归重复步骤2-3
5. 停止条件：子集完全纯净、达到最大深度、或子集太小

**如何选择"最好"的特征？**

- **信息增益（Information Gain）**：基于信息熵的概念。选择使分裂后信息熵减少最多的特征。
- **基尼指数（Gini Index）**：衡量数据集的不纯度。选择使分裂后基尼指数最小的特征。

**信息熵公式：**

```
H(S) = -Σᵢ pᵢ log₂(pᵢ)

其中：
  S = 数据集
  pᵢ = 第i类样本在S中的比例
```

信息熵越小，数据集越"纯净"（全是同一类）。

**决策树的优缺点：**

| 优点 | 缺点 |
|------|------|
| 可解释性强（"白盒"模型） | 容易过拟合 |
| 不需要特征标准化 | 对数据微小变化敏感 |
| 能处理非线性关系 | 贪心算法，不保证全局最优 |
| 能处理数值和类别特征 | 倾向于选择多值特征 |

**防止过拟合的方法：** 限制最大深度、设置最小叶子节点样本数、剪枝（预剪枝和后剪枝）。

### 6.4 K近邻算法（KNN）

KNN是最简单的机器学习算法之一，其核心思想是"物以类聚"。

**算法流程：**

```
1. 计算待分类样本与所有训练样本的距离
2. 找到距离最近的K个邻居
3. 对于分类：投票决定——K个邻居中出现最多的类别即为预测结果
4. 对于回归：取K个邻居的输出值的平均值
```

**关键选择：**

- **K值的选择**：K太小（如1）→ 过拟合（对噪声敏感）；K太大 → 欠拟合（边界模糊）
- **距离度量**：常用欧几里得距离，也可用曼哈顿距离、闵可夫斯基距离等

**KNN的优缺点：**

| 优点 | 缺点 |
|------|------|
| 简单直观，无需训练 | 预测时需要计算与所有样本的距离，计算量大 |
| 天然支持多分类 | 对高维数据效果差（维度灾难） |
| 不需要假设数据分布 | 对特征尺度敏感（需要标准化） |

### 6.5 模型评估方法

**混淆矩阵（Confusion Matrix）**

对于二分类问题：

|  | 预测为正 | 预测为负 |
|--|---------|---------|
| **实际为正** | TP（真正例） | FN（假负例/漏报） |
| **实际为负** | FP（假正例/误报） | TN（真负例） |

**关键指标：**

```
准确率 Accuracy = (TP + TN) / (TP + TN + FP + FN)
精确率 Precision = TP / (TP + FP)     "预测为正的里面，多少真的是正"
召回率 Recall = TP / (TP + FN)        "真实为正的里面，多少被找出来了"
F1分数 = 2 × Precision × Recall / (Precision + Recall)
```

**精确率 vs 召回率的权衡：**

- 高精确率、低召回率：宁可漏掉也不误报（如：推荐系统——宁可少推荐也不要推荐不相关的）
- 高召回率、低精确率：宁可误报也不漏掉（如：疾病筛查——宁可多查几个也不要漏掉患者）
- F1分数：精确率和召回率的调和平均，当两者都高时F1才高

**什么时候用什么指标？**

| 场景 | 推荐指标 | 原因 |
|------|----------|------|
| 类别平衡的分类 | 准确率 | 直观有效 |
| 类别不平衡 | F1分数、AUC | 准确率会误导（99%负样本时全预测负也有99%准确率） |
| 关注误报代价 | 精确率 | 如垃圾邮件过滤 |
| 关注漏报代价 | 召回率 | 如癌症筛查 |

### 6.6 ROC曲线与AUC

**ROC曲线的构成：**

- 横轴：假正率 FPR = FP / (FP + TN)
- 纵轴：真正率 TPR = TP / (TP + FN) = 召回率
- 通过改变分类阈值（不一定是0.5），得到不同的(FPR, TPR)点，连成曲线

**AUC（Area Under Curve）：**

- AUC = ROC曲线下的面积，取值0到1
- AUC = 1：完美分类器
- AUC = 0.5：随机猜测（对角线）
- AUC < 0.5：比随机还差（可能是标签反了）

**为什么AUC有用？** AUC衡量的是模型将正样本排在负样本前面的概率，与分类阈值无关，因此可以全面评估模型的排序能力。

## 关键公式或算法流程

**线性回归梯度下降更新规则：**

```
重复直到收敛：
    w := w - α × (1/n) × Xᵀ(Xw - y)
    b := b - α × (1/n) × Σᵢ(ŷᵢ - yᵢ)

其中 α = 学习率
```

**逻辑回归交叉熵损失：**

```
L = -(1/n) Σᵢ [yᵢ log(ŷᵢ) + (1-yᵢ) log(1-ŷᵢ)]
```

**信息增益计算：**

```
IG(S, A) = H(S) - Σᵥ (|Sᵥ|/|S|) × H(Sᵥ)

其中：
  S = 原始数据集
  A = 选择的特征
  v = 特征A的每个取值
  Sᵥ = 特征A取值为v的子集
```

## 易错点与常见误区

1. **误区：准确率是万能指标。** 在类别严重不平衡的数据集上（如99%负样本），一个全部预测为负的模型准确率就有99%，但它毫无用处。应该使用F1分数或AUC。

2. **误区：逻辑回归只能做二分类。** 逻辑回归可以通过一对多（One-vs-Rest）或softmax扩展来做多分类。

3. **误区：KNN中K越大越好。** K太大时，模型会趋向于预测多数类，失去区分能力。K值需要通过交叉验证来选择。

4. **误区：决策树不需要预处理数据所以可以直接用于任何数据。** 虽然决策树不需要标准化，但如果特征有大量缺失值或类别不平衡，仍然需要预处理。

5. **误区：ROC曲线在所有场景下都适用。** 在严重类别不平衡的情况下，PR曲线（精确率-召回率曲线）可能比ROC曲线更能反映模型的实际表现。

### 选择题

**1. 在医疗诊断场景中（检测罕见疾病），以下哪个指标最应该被优先关注？**

A. 准确率（Accuracy）
B. 精确率（Precision）
C. 召回率（Recall）
D. AUC

> **答案：C**
> 解析：在疾病筛查中，漏诊的代价远高于误诊的代价。高召回率意味着尽可能不漏掉真正的患者。虽然误诊（FP）也会造成困扰，但漏掉一个真正的患者（FN）后果更严重。

**2. 关于逻辑回归，以下说法正确的是？**

A. 逻辑回归的输出范围是(-∞, +∞)
B. 逻辑回归使用均方误差作为损失函数
C. 逻辑回归的输出可以解释为属于正类的概率
D. 逻辑回归只能处理线性可分的数据

> **答案：C**
> 解析：Sigmoid函数将输出映射到(0,1)，可解释为概率。A描述的是线性回归的输出。B错误，逻辑回归使用交叉熵损失。D不完全正确，逻辑回归可以处理非线性可分数据（通过特征工程），但决策边界始终是线性的。

**3. 决策树在选择分裂特征时，以下哪种情况信息增益最大？**

A. 分裂后两个子集各含50%的正样本
B. 分裂后一个子集全为正样本，另一个全为负样本
C. 分裂后两个子集都保持原始数据的类别分布
D. 无法判断

> **答案：B**
> 解析：信息增益衡量的是分裂后不纯度的减少量。B情况下两个子集完全纯净（熵为0），信息增益最大。A和C情况下子集不纯度较高，信息增益较小。

### 判断题

**1. 在KNN算法中，如果K=1，则模型一定不会出现欠拟合。（ ）**

> **答案：正确（但需注意）**
> 解析：K=1时，模型会完美拟合训练数据（每个训练点都是自己的最近邻），因此不会欠拟合。但K=1会导致严重的过拟合——模型对噪声极度敏感，泛化能力差。

**2. 一个分类器的AUC为0.8，意味着它的分类准确率为80%。（ ）**

> **答案：错误**
> 解析：AUC和准确率是完全不同的概念。AUC衡量的是模型将正样本排在负样本前面的概率，与分类阈值无关。准确率是特定阈值下的分类正确比例。AUC=0.8意味着随机选一个正样本和一个负样本，模型给正样本打的分数高于负样本的概率是80%。

### 简答题

**1. 比较线性回归和逻辑回归的异同点。**

> **参考答案：**
> 相同点：两者都使用线性函数 wᵀx + b 作为核心计算，都属于广义线性模型的范畴。
> 不同点：(1) 任务不同——线性回归用于回归问题（预测连续值），逻辑回归用于分类问题（预测类别概率）；(2) 输出不同——线性回归输出任意实数，逻辑回归通过Sigmoid将输出压缩到(0,1)；(3) 损失函数不同——线性回归用MSE，逻辑回归用交叉熵。可以说，逻辑回归是在线性回归基础上加了Sigmoid激活函数和交叉熵损失。

**2. 在什么场景下应该优先使用精确率而不是召回率作为优化目标？请举例说明。**

> **参考答案：**
> 当误报的代价高于漏报的代价时，应优先使用精确率。例如，在垃圾邮件过滤系统中，将正常邮件误判为垃圾邮件（FP）会导致用户错过重要信息，代价很高；而让一些垃圾邮件通过（FN）用户可以手动删除，代价较低。因此，系统应追求高精确率——"宁可放过一些垃圾邮件，也不要误杀正常邮件"。

```python
# 实验1：线性回归实现与可视化

import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

# 生成数据
np.random.seed(42)
X = np.random.uniform(1, 10, 50).reshape(-1, 1)
y = 3 * X.squeeze() + 5 + np.random.normal(0, 2, 50)

# 训练模型
model = LinearRegression()
model.fit(X, y)

print(f"学到的斜率 w = {model.coef_[0]:.2f}")
print(f"学到的截距 b = {model.intercept_:.2f}")

# 可视化
plt.scatter(X, y, color='blue', label='数据点')
plt.plot(X, model.predict(X), color='red', label='拟合直线')
plt.xlabel('X')
plt.ylabel('y')
plt.title('线性回归拟合结果')
plt.legend()
plt.show()
```

```python
# 实验2：逻辑回归与混淆矩阵

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix, classification_report, ConfusionMatrixDisplay

# 加载鸢尾花数据（取前两类做二分类）
iris = load_iris()
X, y = iris.data[:100], iris.target[:100]  # 仅前两类

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

model = LogisticRegression(max_iter=200)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

# 混淆矩阵
cm = confusion_matrix(y_test, y_pred)
disp = ConfusionMatrixDisplay(cm, display_labels=iris.target_names[:2])
disp.plot(cmap='Blues')
plt.title('逻辑回归混淆矩阵')
plt.show()

# 详细报告
print(classification_report(y_test, y_pred, target_names=iris.target_names[:2]))
```
