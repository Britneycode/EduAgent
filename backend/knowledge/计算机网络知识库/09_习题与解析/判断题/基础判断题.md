# 基础判断题

## 题集定位
围绕高频误解和易混淆概念设计的判断题，每题附纠错解释和相关事实卡引用。

## 1. 分层体系结构

### 题目 1
TCP/IP 模型与 OSI 模型的层次是一一对应的。（×）
**解析：** TCP/IP 模型通常为四层，OSI 为七层，不完全对应。教学中常用五层模型作为折中。见 [[计算机网络知识库/01_基础理论/分层体系结构]]。

### 题目 2
分层封装时，每一层都会添加自己的首部，有些层还会添加尾部。（✓）
**解析：** 数据链路层帧通常包含首部和尾部（如帧校验序列 FCS）。见 [[计算机网络知识库/01_基础理论/分层体系结构]]。

## 2. 数据链路层

### 题目 3
CRC 校验可以纠正传输中出现的比特错误。（×）
**解析：** CRC 用于差错检测，不负责纠错。检测到错误后通常丢弃该帧。见 [[计算机网络知识库/03_数据链路层/CRC校验]] 和 [[计算机网络知识库/99_附录/事实卡/CRC校验]]。

### 题目 4
交换机根据目的 IP 地址转发以太网帧。（×）
**解析：** 普通二层交换机根据目的 MAC 地址转发帧。三层交换或路由器才基于 IP 地址转发。见 [[计算机网络知识库/03_数据链路层/MAC地址与交换机]] 和 [[计算机网络知识库/99_附录/事实卡/交换机转发]]。

## 3. 网络层

### 题目 5
IP 协议提供可靠的端到端数据传输服务。（×）
**解析：** IP 提供无连接、尽力而为的数据报服务，不保证可靠、按序或不重复。见 [[计算机网络知识库/04_网络层/IP协议]] 和 [[计算机网络知识库/99_附录/事实卡/IP协议]]。

### 题目 6
子网掩码中连续的 0 表示网络前缀部分。（×）
**解析：** 子网掩码中连续的 1 表示网络前缀，连续的 0 表示主机部分。见 [[计算机网络知识库/04_网络层/子网划分]]。

### 题目 7
ARP 请求以广播方式发送，ARP 应答以单播方式发送。（✓）
**解析：** ARP 请求通常广播到整个局域网，应答单播回请求方。见 [[计算机网络知识库/04_网络层/ARP_ICMP_IGMP]] 和 [[计算机网络知识库/99_附录/事实卡/ARP]]。

### 题目 8
CIDR 中前缀越短，覆盖的地址范围越小。（×）
**解析：** 前缀越短，主机位越多，覆盖范围越大。/8 比 /24 覆盖范围大得多。见 [[计算机网络知识库/04_网络层/CIDR与地址聚合]]。

## 4. 运输层

### 题目 9
TCP 三次握手在所有抓包中一定表现为恰好三个报文段。（×）
**解析：** 实际抓包中可能出现 SYN+ACK 合并、重传、延迟确认等，导致可见报文数量不同。见 [[计算机网络知识库/05_运输层/TCP连接管理]] 和 [[计算机网络知识库/99_附录/事实卡/TCP三次握手]]。

### 题目 10
UDP 不提供任何差错检测能力。（×）
**解析：** UDP 首部包含校验和字段，可检测传输差错，但不提供重传机制。见 [[计算机网络知识库/05_运输层/UDP]]。

### 题目 11
TCP 流量控制的目的是防止网络拥塞。（×）
**解析：** 流量控制防止发送方压垮接收方；拥塞控制防止网络路径过载，二者关注对象不同。见 [[计算机网络知识库/05_运输层/流量控制与拥塞控制]] 和 [[计算机网络知识库/99_附录/事实卡/流量控制]]。

## 5. 应用层

### 题目 12
DNS 查询总是从根域名服务器开始逐级解析。（×）
**解析：** 递归解析器通常先查本地缓存，缓存未命中才逐级查询。见 [[计算机网络知识库/06_应用层/DNS]] 和 [[计算机网络知识库/99_附录/事实卡/DNS解析过程]]。

### 题目 13
HTTPS 改变了 HTTP 的请求方法和状态码语义。（×）
**解析：** HTTPS 在 HTTP 语义之上增加 TLS 加密，不改变 HTTP 方法和状态码含义。见 [[计算机网络知识库/06_应用层/HTTP_HTTPS]] 和 [[计算机网络知识库/99_附录/事实卡/HTTP与HTTPS]]。

### 题目 14
HTTP 是无状态协议，因此无法维持用户登录状态。（×）
**解析：** HTTP 本身无状态，但可通过 Cookie、Session、Token 等机制在应用层维持状态。见 [[计算机网络知识库/06_应用层/HTTP_HTTPS]]。

## 6. 网络安全

### 题目 15
防火墙可以防御所有网络攻击。（×）
**解析：** 防火墙主要控制进出流量，无法防御加密通道内的恶意流量、社会工程攻击和内部威胁。见 [[计算机网络知识库/07_网络安全与无线网络/防火墙]]。
