# 协议机制简答题

## 题集定位
以简答题形式考查路由、NAT、DHCP、FTP、邮件与 TCP 关键机制的表述与比较能力。

## 1. 路由机制

### 题目 1
简述距离向量算法与链路状态算法的核心区别。
**参考答案：**
距离向量算法（如 RIP）中，每台路由器只向邻居交换"到各目的网络的距离"，基于 Bellman-Ford 思想逐步收敛，实现简单但收敛慢、易产生计数到无穷。链路状态算法（如 OSPF）中，每台路由器收集全网链路状态并构建数据库，用 Dijkstra 算法计算最短路径树，收敛快、支持复杂度量，但开销更大。见 [[计算机网络知识库/04_网络层/路由算法与协议]]。

### 题目 2
为什么 RIP 不适合大型网络？
**参考答案：** RIP 以跳数为度量且最大跳数 15，超过即视为不可达；距离向量收敛慢，可能产生慢收敛与路由环路；不支持按带宽、延迟等复杂度量选路。因此仅适合小型或校园级网络。见 [[计算机网络知识库/04_网络层/路由算法与协议]]。

## 2. NAT 与 DHCP

### 题目 3
说明 NAPT 的基本工作过程。
**参考答案：** 内网主机用私有 IP 与源端口发起连接，NAPT 路由器把源地址改写为公网 IP 并分配新的端口，在 NAT 表中记录（内网IP:端口 ↔ 公网IP:端口）映射；公网回包到达后，路由器查表把目的改写回内网主机地址与端口并转发。见 [[计算机网络知识库/04_网络层/NAT]]。

### 题目 4
DHCP 四步交互流程各完成什么功能？
**参考答案：** Discover 客户端广播寻找服务器；Offer 服务器提议可用 IP 与租期；Request 客户端选择该服务器并请求地址；ACK 服务器确认，租约生效。见 [[计算机网络知识库/04_网络层/DHCP]]。

## 3. 应用层协议

### 题目 5
比较 FTP 主动模式与被动模式。
**参考答案：** 主动模式中服务器主动从 20 端口连接客户端指定的数据端口，需要客户端可达，NAT/防火墙环境下常失败；被动模式中客户端发送 PASV，服务器返回数据端口，客户端主动连接，避免服务器回连客户端，更适合 NAT 环境。见 [[计算机网络知识库/06_应用层/FTP与文件传输]]。

### 题目 6
SMTP、POP3 与 IMAP 在邮件系统中的分工是什么？
**参考答案：** SMTP 用于发送方与服务器之间及服务器之间的邮件推送；POP3 与 IMAP 用于客户端从收件箱服务器收取邮件。POP3 偏"下载到本地"（常删除服务器副本），IMAP 保留服务器端并支持多设备同步。见 [[计算机网络知识库/06_应用层/电子邮件协议]]。

## 4. 运输层机制

### 题目 7
TCP 如何区分流量控制与拥塞控制？
**参考答案：** 流量控制是端到端的，接收方通过通告接收窗口 rwnd 限制发送速率，防止接收方缓冲区溢出；拥塞控制是网络层面的，发送方维护拥塞窗口 cwnd，通过慢启动、拥塞避免、快重传/快恢复等机制探测并适应网络承载能力。发送窗口取 min(cwnd, rwnd)。见 [[计算机网络知识库/05_运输层/流量控制与拥塞控制]] 和 [[计算机网络知识库/99_附录/事实卡/流量控制]]。

### 题目 8
为什么 TCP 主动关闭方要进入 TIME_WAIT 状态？
**参考答案：** 主动关闭方在发送最后一个 ACK 后进入 TIME_WAIT（约 2MSL），保证对方可能重传的 FIN 能被确认，并让网络中迟到的重复报文段充分消亡，避免污染后续使用相同端口的新连接。见 [[计算机网络知识库/05_运输层/TCP连接管理]] 和 [[计算机网络知识库/99_附录/事实卡/TCP四次挥手]]。
