# 无线局域网基础

## 1. 学习目标
- 理解无线局域网基础的基本定义、作用范围和所在层次。
- 能够解释无线局域网基础的关键机制和典型应用场景。
- 能够识别无线局域网基础相关的常见误解。

## 2. 核心概念
无线局域网（WLAN）最常用的标准是 IEEE 802.11 系列（如 802.11a/b/g/n/ac/ax）。WLAN 使用无线电波作为传输介质，典型部署包括接入点（AP）和无线站点（STA）。

## 3. 知识讲解
无线网络使用 CSMA/CA（带冲突避免的载波侦听多路访问）而非 CSMA/CD，因为无线信道难以在发送时检测冲突。CSMA/CA 通过 RTS/CTS 机制和随机退避减少冲突。802.11 帧包含帧控制、地址字段（最多 4 个 MAC 地址）、序列控制和帧校验。

## 4. 关键事实
- CSMA/CA 不能完全消除冲突，只是减少冲突概率。
- 隐藏站问题和暴露站问题是无线网络特有的挑战。
- 无线信号受衰减、多径效应和同频干扰影响。

## 5. 易混淆点
- "无线 = 不安全"是过度简化；安全性取决于加密和认证机制，而非传输介质本身。
- 802.11 的 MAC 地址与以太网 MAC 地址格式相同，但地址数量和含义不同。


## 导师 Agent 教学提示
- 学生常见困惑：以为无线网络用 CSMA/CD。
- 诊断建议：问"无线网卡能同时发送和接收信号吗？这对冲突检测有什么影响？"
- 个性化策略：无线像"对讲机"——说话时听不到别人（无法检测冲突），所以要先"听"再"说"（CSMA/CA）。
