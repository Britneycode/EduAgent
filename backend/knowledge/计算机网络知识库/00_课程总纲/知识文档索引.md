# 知识文档索引

## 1. 用途
本页使用 Dataview 插件自动列出知识库中所有 `doc_type: knowledge` 的文档，支持按章节、难度、状态筛选，方便文档管理和质量审核。

## 2. 全部知识文档

```dataview
TABLE chapter AS "章节", difficulty AS "难度", status AS "状态", verified AS "已核验", owner_agent AS "负责人"
FROM "计算机网络知识库"
WHERE doc_type = "knowledge"
SORT chapter ASC, title ASC
```

## 3. 按章节统计

```dataview
TABLE length(rows) AS "文档数"
FROM "计算机网络知识库"
WHERE doc_type = "knowledge"
GROUP BY chapter
SORT key ASC
```

## 4. 未核验文档

```dataview
TABLE chapter AS "章节", owner_agent AS "负责人", last_reviewed AS "最后审核"
FROM "计算机网络知识库"
WHERE doc_type = "knowledge" AND verified = false
SORT last_reviewed ASC
```

## 5. 高难度文档

```dataview
TABLE chapter AS "章节", summary AS "摘要"
FROM "计算机网络知识库"
WHERE doc_type = "knowledge" AND difficulty = "hard"
SORT title ASC
```
