# 事实卡统计

## 1. 用途
本页使用 Dataview 插件自动统计事实卡的核验状态、风险等级和检索优先级，支持质量审核和缺口发现。

## 2. 全部事实卡

```dataview
TABLE summary AS "标准表述", verified AS "已核验", quality.factual_risk AS "风险", rag.retrieval_priority AS "优先级"
FROM "计算机网络知识库/99_附录/事实卡"
SORT title ASC
```

## 3. 核验状态统计

```dataview
TABLE length(rows) AS "数量"
FROM "计算机网络知识库/99_附录/事实卡"
GROUP BY verified
```

## 4. 高风险事实卡

```dataview
TABLE summary AS "标准表述", verified AS "已核验"
FROM "计算机网络知识库/99_附录/事实卡"
WHERE quality.factual_risk = "high"
SORT title ASC
```

## 5. 未核验事实卡

```dataview
TABLE summary AS "标准表述", quality.factual_risk AS "风险"
FROM "计算机网络知识库/99_附录/事实卡"
WHERE verified = false
SORT title ASC
```
