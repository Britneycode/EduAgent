# 子网划分计算器实验

## 1. 实验目标
练习使用子网划分计算器验证手工计算结果。

## 2. 实验环境
- 操作系统：Windows / macOS / Linux 均可。
- 工具：Wireshark、命令行终端。
- 数据记录：保存命令输出、截图、pcap 文件名与观察时间。

## 3. 操作步骤
1. 给定 IP 地址和子网掩码，手工计算网络地址、广播地址和可用主机范围。
2. 使用在线子网计算器或 Python 脚本验证结果。
3. 练习 CIDR 表示法转换和地址聚合。
4. 比较 VLSM 与固定长度子网划分。
5. 记录计算过程和易错点。
