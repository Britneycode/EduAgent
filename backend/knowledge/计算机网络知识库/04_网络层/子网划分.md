# 子网划分

## 1. 学习目标
- 理解子网划分的基本定义、作用范围和所在层次。
- 能够用分层模型解释子网划分与相邻知识点的关系。
- 能够基于事实卡、实验或题目验证关键结论。

## 2. 核心概念
子网划分通过延长网络前缀把地址块划分成多个逻辑子网。

## 3. 知识讲解
子网划分的核心操作是 IP 地址与子网掩码的按位与运算：

```text
IP 地址：    192.168.1.130 = 11000000.10101000.00000001.10000010
子网掩码：   255.255.255.192 = 11111111.11111111.11111111.11000000
网络地址：   192.168.1.128  = 11000000.10101000.00000001.10000000
```

**计算公式：**
- 网络地址 = IP AND 掩码
- 广播地址 = 网络地址 OR (NOT 掩码)
- 第一个可用主机 = 网络地址 + 1
- 最后一个可用主机 = 广播地址 - 1
- 可用主机数 = 2^h - 2（h 为主机位数）

**VLSM（可变长子网掩码）：** 允许在同一网络中使用不同长度的子网掩码，按需分配不同大小的子网，减少地址浪费。例如给一个 50 人的部门分配 /26（62 台主机），给只有 2 台路由器的点对点链路分配 /30（2 台主机）。

**易错提醒：**
- /30 子网只有 4 个地址，其中 2 个可用（常用于点对点链路）。
- 子网掩码必须是连续的 1 后跟连续的 0（如 255.255.255.192 合法，255.255.255.144 不合法）。
- 网络地址和广播地址不能分配给主机。
