# 路由算法模拟

## 1. 案例目标
分别用 Dijkstra 与 Bellman-Ford 计算一个简单网络中的最短路径，理解链路状态与距离向量两类路由算法。

## 2. 先修知识
- [[计算机网络知识库/04_网络层/路由算法与协议]]

## 3. 示例代码 / 伪代码
```python
import heapq

# 网络拓扑：节点 -> [(邻居, 代价), ...]
GRAPH = {
    "A": [("B", 1), ("C", 4)],
    "B": [("A", 1), ("C", 2), ("D", 5)],
    "C": [("A", 4), ("B", 2), ("D", 1)],
    "D": [("B", 5), ("C", 1)],
}

def dijkstra(graph, start):
    """链路状态（OSPF）思想：以 start 为根计算最短路径树。"""
    dist = {node: float("inf") for node in graph}
    dist[start] = 0
    prev = {}
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                prev[v] = u
                heapq.heappush(pq, (dist[v], v))
    return dist, prev

def bellman_ford(graph, start):
    """距离向量（RIP）思想：迭代松弛所有边。"""
    dist = {node: float("inf") for node in graph}
    dist[start] = 0
    for _ in range(len(graph) - 1):
        for u in graph:
            for v, w in graph[u]:
                if dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w
    return dist

print("Dijkstra 结果:", dijkstra(GRAPH, "A")[0])
print("Bellman-Ford 结果:", bellman_ford(GRAPH, "A"))
```

## 4. 运行与观察
- 两种算法在无负权图上得到一致的最短路径距离。
- Dijkstra 每次取当前最近节点（贪心 + 优先队列）；Bellman-Ford 全局迭代松弛所有边，更适合分布式逐跳通告（RIP 的 Bellman-Ford 思想）。
- 思考：若图中存在负权边，哪种算法会失效？
