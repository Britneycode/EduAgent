# 计算复杂度理论

## 1. 学习目标
- 理解 P 与 NP 的定义。
- 理解多项式时间归约与 NP 完全的概念。
- 认识典型 NP 完全问题。
- 理解 P ≠ NP 问题为什么重要。

## 2. 核心概念
计算复杂度理论按"求解所需时间"把问题分类：P 是可快速求解的，NP 是可快速验证解的，NP 完全是 NP 中最难的一类。

## 3. 知识讲解

### 3.1 P 类
- **P**：存在多项式时间算法求解的判定问题（如排序、最短路径）。
- 规模 n 增大时运行时间以多项式增长，视为"可有效求解"。

### 3.2 NP 类
- **NP**：存在多项式时间算法**验证**给定解的判定问题。
- 注意：NP 并非"非多项式"；它是"Non-deterministic Polynomial"。
- P ⊆ NP：能快速求解当然能快速验证。

### 3.3 NP 完全（NPC）
- 一个问题 Q 是 NP 完全的，当且仅当：
  1. Q ∈ NP；
  2. 所有 NP 问题都能多项式归约到 Q。
- 若某个 NPC 问题存在多项式算法，则 P = NP。
- 典型 NPC：SAT、0-1 背包（判定版）、旅行商（判定版）、图着色、Hamilton 回路。

### 3.4 多项式时间归约
- 问题 A 多项式归约到问题 B：存在多项式时间把 A 的实例转成 B 的实例，且保持答案一致。
- 意义：证明 B 至少和 A 一样难。
- 归约链：SAT → 3-SAT → 子集和 → 背包 等。

### 3.5 P 与 NP 问题
- "P = NP 吗？"是理论计算机科学最重要的开放问题。
- 工程启示：遇到 NPC 问题不追求最坏情况多项式解，而用启发式、近似算法、参数化算法或分支限界（小规模）。

## 4. 示例：归约直觉
- 判定版 0-1 背包："是否存在总价值 ≥ K 且重量 ≤ C 的选择"属于 NP。
- 若有人给你一个解（选了哪些物品），可多项式验证价值与重量。
- 通过把"子集和"归约到它，可证明它是 NPC。

## 5. 关键事实
- P ⊆ NP；是否 P = NP 未解决。
- NP 完全问题彼此可多项式归约，一个可解则全体可解。
- 工程上对 NPC 问题常用近似与启发式。

## 6. 易混淆点
- NP 是"可快速验证"，不是"需要指数时间"。
- 判定问题与优化问题要区分：NPC 通常指判定版。
- "归约方向"别搞反：A 归约到 B 说明 B 更难。
