# 最小生成树

## 1. 学习目标
- 理解最小生成树（MST）的定义。
- 掌握 Kruskal 算法与并查集实现。
- 掌握 Prim 算法及其优先队列实现。
- 能根据图的特点选择合适的 MST 算法。

## 2. 核心概念
给定带权无向连通图，最小生成树是连接所有顶点且总边权最小的无环边集（V-1 条边）。

## 3. 知识讲解

### 3.1 MST 性质
- 一棵 MST 恰好包含 V-1 条边，且连通所有顶点。
- **切割性质**：对任意切割，横跨切割的最小权边必属于某棵 MST。
- 基于切割性质可证明 Kruskal 与 Prim 的正确性。

### 3.2 Kruskal 算法
- 思想：按边权从小到大排序，依次加入不成环的边。
- 判环用**并查集**（Union-Find）。
- 复杂度：排序 `O(E log E)` + 并查集近乎 `O(E α(V))`。
- 适合边少（稀疏图）。

### 3.3 并查集
- 支持"查询是否同集合"与"合并集合"，路径压缩 + 按秩合并接近常数。
- 用于 Kruskal 中判断加入一条边是否会成环。

### 3.4 Prim 算法
- 思想：从一个顶点出发，每步贪心选择"连接已在树中顶点与未在树中顶点"的最小权边。
- 优先队列实现复杂度 `O(E log V)`。
- 适合稠密图。

### 3.5 算法选择
- 稀疏图（E 接近 V）：Kruskal 更简单高效。
- 稠密图（E 接近 V^2）：Prim 更优。

## 4. 示例代码 / 伪代码
```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1
        return True

def kruskal(n, edges):
    """edges: list[(u, v, w)]。返回最小生成树总权。"""
    edges.sort(key=lambda x: x[2])
    uf = UnionFind(n)
    total = 0
    for u, v, w in edges:
        if uf.union(u, v):
            total += w
    return total
```

## 5. 关键事实
- Kruskal 排序后贪心加边，用并查集判环。
- Prim 每步取"树到非树"的最小权边，用优先队列。
- 两算法都基于切割性质，均要求图连通。

## 6. 易混淆点
- MST 针对无向连通图；有向图的对应概念是"最小树形图"（不同算法）。
- Kruskal 是"加边"，Prim 是"加点"，思路方向不同。
- 存在负权边不影响 MST 算法正确性（与最短路不同）。
