# 归并排序与快速排序

## 1. 案例目标
实现两种 $O(n\log n)$ 分治排序，对照"分解—求解—合并"结构，理解两者递归式与最坏情况的差异。

## 2. 归并排序

```python
def merge_sort(a: list[int]) -> list[int]:
    if len(a) <= 1:
        return a
    mid = len(a) // 2
    left = merge_sort(a[:mid])   # 分解 + 递归求解
    right = merge_sort(a[mid:])
    return _merge(left, right)   # 线性合并

def _merge(left: list[int], right: list[int]) -> list[int]:
    out, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:   # <= 保证稳定性
            out.append(left[i]); i += 1
        else:
            out.append(right[j]); j += 1
    out.extend(left[i:] or right[j:])
    return out
```

递归式 $T(n)=2T(n/2)+\Theta(n)$，Master 定理情形 2 → $\Theta(n\log n)$，任何输入都成立；辅助空间 $O(n)$。

## 3. 快速排序（原地、随机枢轴）

```python
import random

def quick_sort(a: list[int], lo: int = 0, hi: int | None = None) -> None:
    if hi is None:
        hi = len(a) - 1
    if lo >= hi:
        return
    p = _partition(a, lo, hi)
    quick_sort(a, lo, p - 1)
    quick_sort(a, p + 1, hi)

def _partition(a: list[int], lo: int, hi: int) -> int:
    r = random.randint(lo, hi)      # 随机枢轴，避免有序输入退化
    a[r], a[hi] = a[hi], a[r]
    pivot, i = a[hi], lo
    for j in range(lo, hi):
        if a[j] < pivot:
            a[i], a[j] = a[j], a[i]
            i += 1
    a[i], a[hi] = a[hi], a[i]
    return i
```

递归式 $T(n)=T(k)+T(n-1-k)+\Theta(n)$：随机化后期望均衡，$E[T]=\Theta(n\log n)$；最坏（划分恒为 0/n-1）$O(n^2)$。空间 $O(\log n)$ 递归栈。

## 4. 对照实验

```python
import random, time
data = [random.randint(0, 10**6) for _ in range(50_000)]
for name, fn in [("merge", lambda: merge_sort(data)),
                 ("quick", lambda: quick_sort(list(data)))]:
    t = time.time(); fn(); print(name, f"{time.time()-t:.3f}s")
```
