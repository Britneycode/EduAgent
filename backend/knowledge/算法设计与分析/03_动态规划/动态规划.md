# 动态规划

## 1. 学习目标
- 理解动态规划的两大特征：最优子结构与重叠子问题。
- 掌握"状态定义 → 转移方程 → 边界 → 填表"的分析套路。
- 会解 0-1 背包、最长公共子序列与矩阵链乘。
- 能比较记忆化递归与自底向上填表的区别。

## 2. 核心概念
动态规划（DP）把原问题分解为相互重叠的子问题，用表格记录子问题解，避免重复计算，从而把指数级暴力降为多项式时间。

## 3. 知识讲解

### 3.1 两大特征
- **最优子结构**：问题的最优解包含其子问题的最优解。
- **重叠子问题**：递归求解时同一子问题被反复计算。
- 满足两者才适合 DP；子问题独立时优先考虑分治。

### 3.2 设计四步
1. **定义状态**：dp[i]（或 dp[i][j]）表示什么。
2. **写出转移方程**：如何由较小子问题推出较大子问题。
3. **确定边界/初值**。
4. **确定遍历顺序**：按依赖方向填表。

### 3.3 0-1 背包
- 物品 i（重量 w_i，价值 v_i），背包容量 C，每件最多取一次。
- 状态 `dp[i][c]` = 前 i 件物品在容量 c 下的最大价值。
- 转移：`dp[i][c] = max(dp[i-1][c], dp[i-1][c - w_i] + v_i)`（c ≥ w_i）。
- 空间可优化为一维数组，容量逆序遍历避免覆盖。

### 3.4 最长公共子序列（LCS）
- `dp[i][j]` = s1 前 i 个与 s2 前 j 个字符的 LCS 长度。
- 若 `s1[i-1] == s2[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`；
- 否则 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`。
- 复杂度 `O(mn)`。

### 3.5 矩阵链乘
- 求给一系列矩阵相乘的最少标量乘法次数（决定加括号顺序）。
- `dp[i][j]` = 第 i 到 j 个矩阵的最少乘法次数。
- 转移枚举分割点 k：`dp[i][j] = min(dp[i][k] + dp[k+1][j] + p[i-1]*p[k]*p[j])`。
- 区间 DP 的典型：先小后大枚举区间长度。

## 4. 示例代码 / 伪代码
```python
def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [0] * (capacity + 1)
    for i in range(n):
        for c in range(capacity, weights[i] - 1, -1):
            dp[c] = max(dp[c], dp[c - weights[i]] + values[i])
    return dp[capacity]

def lcs(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```

## 5. 关键事实
- 0-1 背包：一维优化时容量逆序；完全背包则正序。
- LCS 复杂度 `O(mn)`，空间可优化为两行滚动数组。
- 区间 DP（矩阵链乘）按区间长度从小到大填表。

## 6. 易混淆点
- 贪心只做局部最优决策，不回溯；DP 综合比较所有子问题解。
- 记忆化递归与自底向上填表结果一致，前者"懒"后者"全"。
- 背包的"0-1"（每件至多一件）与"完全"（每件无限）转移不同。
