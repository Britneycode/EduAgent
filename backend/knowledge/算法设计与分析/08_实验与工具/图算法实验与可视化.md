# 图算法实验与可视化

## 1. 实验目的
1. 熟悉 networkx 建模无向/有向带权图；
2. 运行最短路、MST 等算法并与手算结果核对；
3. 可视化 MST 与最短路树，建立图算法的几何直觉。

## 3. 实验内容

### 步骤 1：建模与基础算法

```python
import networkx as nx
import matplotlib.pyplot as plt

G = nx.Graph()
edges = [(1,2,1),(1,3,7),(2,3,5),(2,4,4),(3,4,2),(3,5,6),(4,5,3)]
G.add_weighted_edges_from(edges)

print(nx.shortest_path(G, 1, 5, weight="weight"))      # [1, 2, 4, 5]
print(nx.shortest_path_length(G, 1, 5, weight="weight"))  # 8
print(nx.minimum_spanning_tree(G).edges(data=True))    # MST
print(list(nx.bfs_tree(G, 1).nodes()))                 # BFS 序
print(list(nx.dfs_tree(G, 1).nodes()))                 # DFS 序
```

### 步骤 2：可视化 MST 与最短路树

```python
def draw_highlight(G, highlight_edges, title):
    pos = nx.spring_layout(G, seed=42)
    nx.draw_networkx(G, pos, node_color="#cfe8ff")
    nx.draw_networkx_edge_labels(
        G, pos, edge_labels=nx.get_edge_attributes(G, "weight"))
    nx.draw_networkx_edges(G, pos, edgelist=highlight_edges,
                           edge_color="red", width=2.5)
    plt.title(title); plt.axis("off"); plt.show()

mst = nx.minimum_spanning_tree(G)
draw_highlight(G, list(mst.edges()), "Minimum Spanning Tree")

path = nx.shortest_path(G, 1, 5, weight="weight")
draw_highlight(G, list(zip(path, path[1:])), "Shortest Path 1→5")
```

### 步骤 4：随机图规模实验
生成 $n\in\{100, 500, 1000\}$、密度 5% 的随机图，实测 Dijkstra（堆）与 Bellman-Ford 的耗时差距，验证 $O(m\log n)$ 与 $O(nm)$。

```python
import random, time
G2 = nx.gnm_random_graph(500, 12_500, seed=1)
for (u, v) in G2.edges():
    G2[u][v]["weight"] = random.randint(1, 100)

t0 = time.perf_counter()
nx.single_source_dijkstra(G2, 0, weight="weight")
print("dijkstra", time.perf_counter() - t0)

t0 = time.perf_counter()
nx.single_source_bellman_ford(G2, 0, weight="weight")
print("bellman-ford", time.perf_counter() - t0)
```
