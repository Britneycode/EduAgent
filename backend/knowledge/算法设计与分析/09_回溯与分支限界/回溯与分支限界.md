# 回溯与分支限界

## 1. 学习目标
- 理解回溯法的"构造解 + 约束剪枝"框架。
- 掌握八皇后、0-1 背包的回溯求解。
- 理解分支限界法与回溯法的区别。
- 了解旅行商等 NP 难题的搜索求解思路。

## 2. 核心概念
回溯法系统化地枚举候选解，在枚举过程中遇到不满足约束的分支立即剪枝回溯；分支限界法在回溯基础上用界限函数剪去不可能优于当前最优解的分支。

## 3. 知识讲解

### 3.1 回溯法框架
- 在解空间树（子集树/排列树）上做深度优先搜索。
- 三要素：**路径**（已选决策）、**选择列表**、**结束条件**。
- 剪枝：不满足约束或不可能更优的分支直接剪掉。

### 3.2 八皇后
- 逐行放置皇后，约束：不同列、不同对角线。
- 用数组记录每行皇后所在列，O(1) 判断冲突。
- 复杂度指数级，但剪枝后规模可控。

### 3.3 0-1 背包（回溯）
- 对每件物品尝试取/不取，形成子集树。
- 剪枝：剩余容量不足、或"当前价值 + 剩余物品上界"不超过已知最优则剪枝。
- 相比 DP 的 O(nC)，回溯适合 C 很大、n 较小的场景。

### 3.4 分支限界法
- 广度优先（或最佳优先）搜索解空间树。
- 用**界限函数**（上界/下界）估计分支可能达到的最优值。
- 若某分支的界限不优于当前最优，则不再展开。
- 典型应用：旅行商问题（TSP）、分配问题。

### 3.5 回溯 vs 分支限界
- 回溯：深度优先 + 约束剪枝，追求找到全部解或可行解。
- 分支限界：优先搜索 + 界限剪枝，常用于求最优解。

## 4. 示例代码 / 伪代码
```python
def n_queens(n):
    res = []
    cols = [0] * n  # cols[r] = 第 r 行皇后所在列

    def valid(r, c):
        for i in range(r):
            if cols[i] == c or abs(cols[i] - c) == r - i:
                return False
        return True

    def dfs(r):
        if r == n:
            res.append(cols[:])
            return
        for c in range(n):
            if valid(r, c):
                cols[r] = c
                dfs(r + 1)

    dfs(0)
    return res  # 全部八皇后布局
```

## 5. 关键事实
- 回溯的关键是剪枝条件的设计，决定算法实际性能。
- 0-1 背包可用 DP（容量维）也可回溯（物品维），各有适用场景。
- TSP 是 NP 难题，分支限界只能应对中等规模。

## 6. 易混淆点
- 回溯是"深度优先 + 剪枝"，分支限界常为"最佳优先 + 界限剪枝"。
- 剪枝不等价于贪心：剪枝仍保证不漏解，贪心可能放弃最优。
- 回溯求所有解，分支限界求最优解是常见误解（回溯也可求最优）。
